### Hallmark：让Claude Code/Cursor生成「去AI味」设计的开源技能

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/Nutlope/hallmark
- **TitleEN**：Hallmark: Anti-AI-slop Design Skill for Claude Code & Cursor

Together AI发布开源设计技能Hallmark，专为Claude Code、Cursor和Codex打造。它内置20种主题、4种布局动词，并通过57项「AI味检测」门控+自我批判机制，拒绝LLM训练中形成的默认套路，让AI生成的UI看起来真正有设计感。

- **EN**：Together AI released Hallmark, an open-source design skill for Claude Code, Cursor, and Codex. It runs 57 anti-slop test gates and a self-critique pass before emitting any UI, refusing the on-distribution defaults baked into LLM training. Ships with 20 themes and 4 layout macros.

- **来源**：Hacker News
- **链接**：https://github.com/morluto/rea

开源项目REA是一个专为AI Agent设计的MCP服务器，赋予Agent对二进制代码进行逆向工程分析的能力。这对安全研究、漏洞挖掘、CTF等场景极具价值，也是MCP生态向安全工程领域延伸的典型案例。

### LightMem-Ego：手机/可穿戴设备上的轻量级终身记忆系统

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.11487
- **TitleEN**：LightMem-Ego: Lightweight Streaming Multimodal Memory for Wearable AI

论文提出LightMem-Ego，一个运行在手机/可穿戴设备上的流式多模态记忆系统，持续捕获第一人称视觉与音频，实现长期经历的累积、组织与检索。对开发者意义：为端侧AI助理提供了真正可用的「持久化个人记忆」技术路线，无需依赖云端。

- **EN**：LightMem-Ego is a lightweight streaming memory system for phones and wearables that continuously captures egocentric video/audio and enables long-term experience retrieval. For developers, it offers a viable on-device persistent memory architecture for personal AI assistants—no cloud required.

### Long-Horizon-Terminal-Bench：专测Agent长任务执行极限的新基准

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.08964
- **TitleEN**：Long-Horizon-Terminal-Bench: New Benchmark Testing Agent Limits on Long Tasks

新基准Long-Horizon-Terminal-Bench包含46个跨9类别的长时域终端任务，引入密集奖励评分（而非只看最终结果），能更真实衡量Agent在数小时级任务中的中间进展。对Claude Code、Codex等编程Agent的真实能力评估意义重大。

- **EN**：Long-Horizon-Terminal-Bench introduces 46 long-horizon terminal tasks across 9 categories with dense reward-based grading—moving beyond pass/fail to capture intermediate progress. Directly relevant for evaluating coding agents like Claude Code and Codex on real multi-hour workflows.
