### 混合决策模型学会判断何时值得深度思考

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.16961
- **TitleEN**：Models Learn When Deep Reasoning Pays

论文提出“零次或完整思考”机制：模型对简单问题只进行一次前向计算，遇到值得推理的任务才展开完整思考。对开发者而言，这种按需分配推理预算的方法有望同时降低延迟与Token成本，并保留复杂任务的效果。

- **EN**：The paper proposes a zero-or-full reasoning strategy: a model answers easy queries in a single forward pass and activates lengthy autoregressive reasoning only when worthwhile. For developers, this offers a practical way to reduce latency and token costs on routine tasks while preserving deeper reasoning for difficult cases.

### 经验交接强化学习让Agent持续吸取失败教训

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.16409
- **TitleEN**：Experience Handoff Improves Agent Learning

研究提出Experience-Handoff强化学习，将Agent执行过程中的错误日志、环境反馈等细粒度经验整理后交给后续尝试，而不是只保留一个分数。对开发者而言，这能让Agent更有效利用失败轨迹，改善复杂任务的调试与持续优化。

- **EN**：Experience-Handoff reinforcement learning passes detailed information from failed trials, such as error logs and environment feedback, into later rollouts instead of reducing each attempt to a scalar reward. This gives developers a more efficient way to train agents from failure traces and improve debugging, planning, and long-horizon task performance.
