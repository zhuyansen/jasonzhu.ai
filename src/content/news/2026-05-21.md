### TBN Protocol：AI Agent 的运行时治理基础设施

- **板块**：Skills 生态
- **来源**：Hacker News
- **链接**：https://news.ycombinator.com/from?site=tbn-protocol.io
- **TitleEN**：TBN Protocol Proposes Runtime Governance Infrastructure for AI Agents

TBN Protocol 提出 Agent 运行时治理标准——在 Agent 执行过程中实时检查权限、审计行为、阻断越权操作。这是对前两天 HF 论文「Agent Harness 安全盲区」的工程化回应：光看最终输出对不对不够，过程必须可治理。生产环境跑 Agent 的团队值得关注。

- **EN**：TBN Protocol introduces a runtime governance standard for Agents — checking permissions, auditing behavior, and blocking unauthorized actions during execution in real time. It's an engineering-level response to recently identified Agent security blind spots: correct final output isn't enough; the entire process must be governable. Worth watching for any team running Agents in production.
