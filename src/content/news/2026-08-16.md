### Maglev：固定内存 Transformer，让超长上下文推理彻底告别 OOM

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.02870
- **TitleEN**：Maglev: Fixed-Memory Recurrent Transformer for Long-Context Inference

Maglev 提出一种「滑动递归记忆」Transformer 架构：用固定大小的内存替代无限增长的 KV Cache，训练时仍可并行，推理时内存占用恒定。对开发者意味着：超长对话、超长文档处理不再因内存爆炸而崩溃，是解决大模型长上下文部署成本的新路径。

- **EN**：Maglev introduces a recurrent Transformer with fixed-size memory that replaces ever-growing KV caches. It stays parallelizable during training but uses constant memory at inference. For developers, this means long-context processing — think 100k+ token conversations — without the memory blowup that currently makes deployment costly or impossible.

### 「思维束搜索」：让推理模型把算力花在最值得的路径上

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.08020
- **TitleEN**：Thought-Level Beam Search: Smarter Compute Allocation for Reasoning Models

当前大推理模型（LRM）的测试时算力扩展存在严重浪费：要么无脑并行采样，要么顺序搜索。本文提出「思维级束搜索」，将推理过程形式化为受约束的算力分配问题，在固定算力预算内优先探索最有前途的推理路径。对开发者的意义：同等 token 预算下显著提升复杂推理准确率，降低 API 成本。

- **EN**：Current reasoning models waste test-time compute by blindly sampling or sequentially searching. This paper formalizes reasoning as a constrained compute allocation problem and proposes thought-level beam search to prioritize the most promising partial trajectories. For developers: better accuracy on hard reasoning tasks within the same token budget — directly translating to lower API costs.
