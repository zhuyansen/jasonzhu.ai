### 反事实执行：堵住 Text-to-SQL 强化学习漏洞

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.34363
- **TitleEN**：Counterfactual Execution Prevents Reward Hacking in Text-to-SQL Agents

单一数据库评估会让错误的 SQL 查询因数据缺失漏洞而“碰巧过关”。该论文用代码自动生成隐藏的边缘测试库，仅当所有库结果一致才给奖励。对开发者而言，这能低成本消除生产环境中数据库智能体的静默 Bug。

- **EN**：Standard Text-to-SQL reinforcement learning rewards queries on a single database, letting buggy SQL pass by luck when edge-case rows are missing. By verifying queries against hidden, code-generated counterfactual databases, this approach helps developers prevent silent production query errors.

- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.21155
- **TitleEN**：EditRecBench Tests Whether LLMs Can Anticipate User Edits

模型生成内容后用户常需反复提修改意见。作者基于 480 万真实对话构建基准，评测大模型能否主动预测下一步编辑意图。对 AI 产品开发者而言，这为打造“免反复提示、主动给建议”的交互体验提供了评估标尺。

- **EN**：Users frequently follow up AI outputs with tedious revision requests. Built from WildChat-4.8M logs, EditRecBench evaluates whether LLMs can proactively anticipate these edit requests beforehand, giving AI product developers a practical benchmark to reduce user review friction and build smarter assistants.

- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.33093
- **TitleEN**：AIChipBench Evaluates LLM Agents on Automated AI Accelerator Design

硬件状态更新哪怕有一处微小错误，也会在数个周期后引发输出崩溃。该基准测试智能体为 Qwen3.5、Gemma 4 等模型编写可综合 RTL 硬件代码的能力，揭示了 AI 辅助芯片设计与底层硬件验证的新门槛。

- **EN**：A tiny state-update bug in hardware design can corrupt outputs several decoding steps later, slipping past basic tests. AIChipBench tasks LLM coding agents with writing synthesizable RTL decoders for Qwen3.5, Gemma 4, and Llama 3.2, helping hardware engineers measure agent reliability.

### 反事实世界模型：用历史轨迹推演替代动作提升 RL 效果

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.29259
- **TitleEN**：Counterfactual World Models Improve RL by Transforming Past Trajectories

在高度随机的复杂环境中，让智能体从零幻想全新轨迹极易失真。论文提出基于真实观测轨迹直接推演“换个动作会怎样”，剥离环境随机噪声干扰。对开发者而言，这大幅提升了复杂场景下智能体策略训练的样本效率与稳定性。

- **EN**：Imagining completely new trajectories often fails when environments are noisy and unpredictable. This paper proposes counterfactual world models that condition on real observed trajectories to simulate alternative actions under identical environmental randomness, helping RL developers improve policy sample efficiency and stability.

### Entangle：让机器人仅看人类演示视频跨任务泛化

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.28732
- **TitleEN**：Entangle Scales Human-Video In-Context Learning for Robotic Manipulation

用人类操作视频做上下文提示时，机器人策略常因时间不对齐而走捷径。Entangle 解决了这一对齐与注意力捷径难题，无需更新参数即可跨场景泛化，为具身智能开发者降低真实机器人遥操作数据采集成本指明了方向。

- **EN**：Teaching robots new tasks via human demonstration videos often fails because models take initial-scene shortcuts instead of tracking actions over time. Entangle resolves temporal alignment issues for world-action models, helping robotics developers generalize across unseen tasks without expensive teleoperation data.
