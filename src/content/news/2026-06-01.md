### Harness：为 Claude Code 一键生成专属 Agent 团队架构

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/revfactory/harness

Harness 是 Claude Code 的「团队工厂」插件，只需用自然语言描述项目，它就能自动设计 Agent 团队、定义各角色职责、并生成对应 Skills。支持英/中/日语指令，六种预置团队架构可选，是目前最接近「AI 工程师组队」体验的 Claude Code 扩展。

- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.21781

### 论文：视觉语言模型的空间感知存在系统性缺陷，「远=上方」是幻觉根源

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.30161

研究发现主流 VLM 在表征空间关系时存在「垂直-距离纠缠」：模型倾向于把「远处」和「上方」混为一谈，这是统计捷径而非真正的 3D 理解。对做多模态 Agent、机器人视觉或空间推理应用的开发者是重要警示：现有 VLM 的空间判断不可过度信任。

### LLM 政治偏见新研究：同一议题左右立场回答不对称，一致性训练可改善

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.22771

研究识别出 LLM「隐性政治偏见」的 7 类表现方式，并提出两个量化指标衡量情感一致性与帮助性一致性。「一致性训练」可显著降低这种系统性偏差。对出海做内容/社媒 AI 产品的开发者而言，这类偏见可能直接影响用户信任与合规风险。
