### AgentDebugX：专为 LLM Agent 打造的开源「失败溯源」调试框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.18754
- **TitleEN**：AgentDebugX: Open-Source Toolkit for Debugging and Recovering LLM Agent Failures

LLM Agent 出错时最难的问题是：报错的那一步往往不是真正出错的那一步。AgentDebugX 提出「检测→归因→恢复→重跑」闭环调试框架，通过多轮对话做根因分析，帮开发者快速定位 Agent 链路中的真实故障点。对正在生产环境部署多步 Agent 的开发者来说，这个工具极具实用价值。

- **EN**：LLM agents fail silently—the step that crashes is rarely where the bug originated. AgentDebugX introduces a closed-loop debugging framework (Detect→Attribute→Recover→Rerun) with multi-turn root-cause diagnosis. Highly practical for developers running multi-step agents in production who need reliable failure tracing.

### SkewAdam：针对 MoE 模型结构差异的分层优化器，显著节省训练显存

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.19058
- **TitleEN**：SkewAdam: Tiered Optimizer Slashes Memory for Mixture-of-Experts Training

训练 MoE 模型时，优化器状态（AdamW 的一二阶矩）占用的显存往往比模型权重本身还大——以 6.78B MoE 为例，权重 12.6GB 但优化器状态高达 50.6GB。SkewAdam 针对 MoE 内部「主干层、专家层、路由层」的梯度分布差异，分配不同精度状态，大幅降低显存占用，让有限算力训练更大 MoE 成为可能。

- **EN**：Training MoE models is memory-dominated by optimizer states—50.6GB of AdamW moments for just 12.6GB of weights in a 6.78B model. SkewAdam assigns different state precision to MoE's dense backbone, experts, and router based on their gradient statistics, dramatically cutting memory usage and making larger MoE models trainable on constrained hardware.
