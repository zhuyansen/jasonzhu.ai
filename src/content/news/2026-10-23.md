- **来源**：Latent Space
- **链接**：https://www.latent.space/p/claude-mods
- **TitleEN**：Claude Mods Reimagines the Agent Harness

Claude Mods提出一种“面向人”的智能体交互层：不再只让Harness适配机器和工具，而是围绕人的注意力、决策与工作流组织任务。它预示着Skills生态将从提示词扩展到完整的人机协作界面。

### OpenAI推出Decisions API，让应用低成本调用专用决策模型

- **板块**：AI 工具动态
- **来源**：OpenAI Blog
- **链接**：https://openai.com/index/decisions-api
- **TitleEN**：OpenAI Launches a Low-Cost Decisions API

OpenAI发布Decisions API，定位是快速、聚焦且低成本的应用决策接口，适合分类、路由、审核等无需长篇生成的任务。它让开发者可以把简单判断从通用大模型调用中拆出，降低延迟与推理成本。

- **EN**：OpenAI has launched the Decisions API for fast, focused, and low-cost decisions inside applications. It targets tasks such as classification, routing, and moderation that do not require long-form generation. Developers can use it to separate lightweight judgments from general-purpose model calls, reducing latency and inference costs.

### 1Password推出代理登录，智能体可代办但看不到密码

- **板块**：AI 工具动态
- **来源**：TechCrunch AI
- **链接**：https://techcrunch.com/2026/10/22/1password-launches-a-way-for-ai-agents-to-log-in-on-your-behalf-without-seeing-your-password/
- **TitleEN**：1Password Lets Agents Log In Without Password Access

1Password推出面向AI智能体的登录能力，代理可以代表用户进入个人账户，却无法直接读取或暴露底层密码。该机制解决了智能体执行真实操作时的凭证泄露风险，是代理走向支付、办公和个人服务自动化的重要基础设施。

- **EN**：1Password has introduced a way for AI agents to log into personal accounts on a user’s behalf without exposing the underlying password. The design addresses credential leakage as agents begin performing real-world actions, creating important infrastructure for safer automation across payments, productivity, and consumer services.

### 工具输出被压缩后，智能体为何会答错？新研究给出实测

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.26836
- **TitleEN**：Study Shows Retrieved Tool Output Can Hurt Agent Accuracy

研究在可复现的地球化学模拟任务上测试智能体发现：即使模型算出了正确结果，把冗长工具输出移出上下文、改为按需检索，也可能让最终答案出错。对开发者而言，节省Token不能只看成本，还必须验证关键信息是否被正确取回。

- **EN**：A study using a deterministic geochemistry simulator found that agents can compute the correct result yet answer incorrectly when long tool outputs are moved out of context and retrieved on demand. For developers, the lesson is that context compression must be evaluated for information recovery and answer accuracy, not only token savings.

### FrontierCS 2测试智能体能否在真实代码库里做计算机研究

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.29932
- **TitleEN**：FrontierCS 2 Tests Agents on Open-Ended CS Research

FrontierCS 2构建48项开放式计算机科学研发任务，让智能体进入已有代码仓库，补全被删除的论文贡献，并以作者发布的真实实现作为标准。它比只评估单段代码更接近真实研发，可帮助团队判断智能体是否具备持续研究与迭代能力。

- **EN**：FrontierCS 2 introduces 48 open-ended computer science research tasks in which agents work inside existing repositories and reconstruct deleted paper contributions. Grounding evaluation in the authors’ released implementations makes it more realistic than single-program benchmarks and helps teams assess sustained research and iteration capabilities.
