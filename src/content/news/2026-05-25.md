### Anthropic 官方 Claude Code 插件目录正式上线

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/anthropics/claude-plugins-official
- **TitleEN**：Anthropic Launches Official Claude Code Plugin Directory

Anthropic 亲自维护的 Claude Code 插件精选目录正式开放，收录经过筛选的高质量插件。这标志着 Claude Code 生态从散乱的第三方 MCP 服务器，走向有官方背书的插件市场。安装前仍需自行审查信任度，Anthropic 不对插件内容做兜底保证。

- **EN**：Anthropic has opened a curated, officially maintained plugin directory for Claude Code, listing vetted high-quality plugins. This marks a shift from a fragmented third-party MCP server landscape toward an officially endorsed plugin marketplace. Users are still advised to independently assess trust before installing, as Anthropic does not guarantee plugin content.

### Understand-Anything：任意代码库秒变可交互知识图谱

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/Lum1104/Understand-Anything
- **TitleEN**：Understand-Anything Turns Any Codebase Into an Interactive Knowledge Graph

开源工具，可将任意代码库、知识库或文档转换为可探索、可搜索、可提问的交互式知识图谱，原生支持 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等主流 AI 编码工具。对大型项目的 Agent 上下文理解有直接帮助，是 CodeGraph 之外的另一条路径。

- **EN**：This open-source tool converts any codebase, knowledge base, or documentation into an explorable, searchable, interactive knowledge graph. It natively supports Claude Code, Codex, Cursor, Copilot, and Gemini CLI. It directly improves agent context comprehension on large projects and offers an alternative approach to tools like CodeGraph.

### AutoRubric-T2I：无需人工标注，文生图对齐有了规则驱动奖励模型

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.17602

现有文生图奖励模型依赖大规模人工偏好数据，成本高且评分标准不透明。AutoRubric-T2I 用 VLM 自动生成评分规则，无需人工标注即可对图像质量和提示词对齐度打分。对开发者意义：可低成本搭建自定义图像生成质量评估流水线，适合独立开发者做产品质控。
