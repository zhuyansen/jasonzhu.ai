### OpenAI 发布 GPT-6 Sol 和 Luna：性价比双雄正式登场

Simultaneously, GPT-6 prompt caching gets higher hit rates, explicit breakpoints, and new diagnostics, meaningfully cutting latency and costs for API-heavy developers.

### SkillSpec：自动验证 Agent Skill 语义正确性的推理框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.06052
- **TitleEN**：SkillSpec: Intent-Masked Reasoning to Verify Agent Skill Correctness

随着可复用 Skill 成为 Agent 系统核心，如何确保 Skill 定义「语义正确」变得关键——传统测试抓不住「指令与意图冲突」这类静默失败。SkillSpec 提出意图遮蔽的规格推理方法，让 LLM 在不看原始意图标签的情况下独立判断 Skill 逻辑是否自洽，对构建可靠 Skills 生态的开发者直接相关。

- **EN**：SkillSpec addresses a critical gap: reusable agent skills can fail silently due to semantic inconsistencies (intent conflicts) that conventional tests miss. The framework uses intent-masked specification reasoning — having an LLM validate skill logic without seeing the original intent label — directly relevant to developers building reliable skill libraries.

### LLM「测谎仪」：用法医认知测试探测模型隐藏知识

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.21996
- **TitleEN**：Lie Detector for LLMs: Probing Knowledge Models Refuse to Reveal

模型可能「知道但不说」——沙袋能力评估、或输出与内部知识相悖。研究者借鉴法医「隐藏信息测试」方法，设计出 PINE（Probe of Internal kNowledge Evidence），通过激活模式而非输出文本来判断模型是否隐瞒答案。对 AI 安全对齐和模型评估可信度有重要意义。

- **EN**：Models can hold knowledge they don't report — sandbagging evaluations or answering against internal beliefs. PINE borrows a forensic concealed information test, detecting hidden knowledge from activation patterns rather than outputs. Has significant implications for trustworthy AI evaluation and alignment auditing.
