### Plannotator让Agent协作进入可审阅工作流

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/backnotprop/plannotator
- **TitleEN**：Plannotator Brings Review Workflows to Agents

Plannotator为编码Agent提供统一工作区，可批注计划、规格文档、HTML和代码差异，并将反馈一键回传Agent。它把人类的决策、审阅与协作环节纳入Agent开发闭环，降低全自动编码的失控风险。

- **EN**：Plannotator provides a workspace for annotating agent plans, specifications, interactive artifacts, code diffs, and pull requests. Feedback can be sent back to the coding agent in one click. The project matters because it adds a structured human review layer to increasingly autonomous software development workflows.

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/tradermonty/claude-trading-skills
- **TitleEN**：Claude Trading Skills Packages Investor Workflows

Claude Trading Skills是一套面向个人投资者的Claude Skills工具包，覆盖市场分析、技术图表、经济日历、筛选器和策略开发。它展示了Skills如何把垂直领域知识与固定流程封装进Agent，而不必重新训练模型。

### Chrome DevTools MCP让编码Agent直接调试浏览器

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/ChromeDevTools/chrome-devtools-mcp
- **TitleEN**：Chrome DevTools MCP Gives Agents Browser Control

Chrome DevTools MCP以MCP服务器和CLI形式开放浏览器控制能力，让Claude、Cursor、Copilot等编码Agent检查实时页面、调试问题并分析性能。开发者可把网页验证从“生成代码”推进到“运行、观察、修复”的闭环。

- **EN**：Chrome DevTools MCP exposes live browser control through both an MCP server and a CLI. Coding agents such as Claude, Cursor, and Copilot can inspect pages, debug issues, automate interactions, and analyze performance. This moves agent coding beyond code generation toward a run-observe-fix loop.

### EgoX打通人类、机器人与模拟器的操作经验

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.16728
- **TitleEN**：EgoX Unifies Cross-Embodiment Robot Demonstrations

EgoX提出跨实体操作学习框架，把人类、真实机器人和模拟器中的演示按对应的视觉观察与动作组织起来，并通过“具身梦想”预训练策略。对开发者而言，这意味着训练机器人操作模型时可更充分复用异构数据。

- **EN**：EgoX introduces a framework for learning manipulation across humans, real robots, and simulated agents by aligning semantically corresponding observations and actions. For developers, the key value is better reuse of heterogeneous demonstrations, potentially reducing the data and engineering cost of training general-purpose robotic policies.

### TurtLES提供14TB湍流数据，补齐PDE评测缺口

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.09567
- **TitleEN**：TurtLES Adds a 14TB Benchmark for Turbulent Flows

TurtLES发布面向三维湍流偏微分方程代理模型的大规模基准，包含400条轨迹、每帧数百万至千万级网格点，总规模达14TB。它为开发者评估AI替代传统流体仿真的泛化能力提供了更接近真实环境的数据基础。

- **EN**：TurtLES introduces a 14TB benchmark for machine-learning surrogates of three-dimensional turbulent flows, with 400 trajectories and millions of points per frame. It gives developers a more realistic way to evaluate whether AI models can generalize beyond simple simulation settings and accelerate computational fluid dynamics reliably.

### 神经影像基础模型向临床决策辅助迈进

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.15094
- **TitleEN**：A Foundation Model for Clinical Neuroimaging

这项工作探索面向人类神经影像的前沿机器智能系统，目标不只是识别单一影像任务，还要理解复杂检查并结合临床决策进行解释。对开发者而言，方向从通用视觉识别转向隐私数据、医学上下文与实际诊疗流程的整合。

- **EN**：This work explores a general machine-intelligence system for human neuroimaging that goes beyond narrow image interpretation. The goal is to analyze complex examinations and communicate findings in clinical decision contexts. For developers, it highlights the shift toward integrating private medical data, domain context, and real clinical workflows.
