### OpenAI 公开 Codex 安全运行架构：沙箱、审批、网络隔离全流程

- **板块**：AI 工具动态
- **来源**：OpenAI Blog
- **链接**：https://openai.com/index/running-codex-safely
- **TitleEN**：OpenAI Details Codex Security: Sandboxing, Approvals, Network Isolation

OpenAI 首次详细披露 Codex 企业级安全运行方案，包括代码沙箱隔离、多级审批机制、网络策略控制和 Agent 原生遥测系统。这套架构为企业大规模部署编程 Agent 提供了安全合规的参考范式，解决了「让 AI 写代码」最核心的信任问题。

- **EN**：OpenAI has disclosed, for the first time in detail, how it runs Codex securely for enterprises. The setup covers code sandbox isolation, multi-level approvals, network policy controls, and agent-native telemetry. It offers a reference model for deploying coding agents at scale while staying compliant, tackling the core trust problem of letting AI write code.

### Context-compiler：为 Claude Code 提供图结构代码检索能力

- **板块**：Skills 生态
- **来源**：GitHub
- **链接**：https://github.com/bytewise-ca/claude-context-compiler
- **TitleEN**：Context-compiler Brings Graph-Based Code Retrieval to Claude Code

开源工具 Context-compiler 通过构建代码依赖图，为 Claude Code 提供更精准的上下文检索能力。相比传统的向量搜索，图结构能更好地理解代码间的调用关系和依赖链路，让 Agent 在大型代码库中定位问题时更准确。

- **EN**：Context-compiler is an open-source tool that builds a code dependency graph to give Claude Code more precise context retrieval. Unlike traditional vector search, a graph structure captures call relationships and dependency chains between code. This helps agents locate issues more accurately in large codebases.

### StraTA：为 Agent 强化学习引入轨迹级策略抽象

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.06642
- **TitleEN**：StraTA Adds Trajectory-Level Strategy Abstraction to Agent RL

当前 Agent 强化学习大多是纯反应式的，在长周期决策中探索和信用分配都很弱。StraTA 提出在轨迹级别引入显式策略抽象，让 Agent 先规划再执行。对开发者的意义：这能让你的 Agent 在多步任务中更稳定，减少盲目试错，特别适合需要规划的复杂工作流。

- **EN**：Most agent reinforcement learning today is purely reactive, so exploration and credit assignment break down over long horizons. StraTA adds explicit strategy abstraction at the trajectory level, so agents plan before acting. For developers, this means more stable agents on multi-step tasks and less blind trial and error, which suits complex, planning-heavy workflows.

### EMO：通过预训练 MoE 实现模块化专家，按需加载特定能力

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.06663

现有 MoE 模型虽然有多个专家，但无法单独使用某个领域的专家（如只用代码专家），强行限制会严重掉性能。EMO 通过新的预训练方法让专家真正模块化，可以按需只加载数学、代码等特定专家。对开发者的意义：未来可以用更小显存跑大模型的特定能力，边缘设备部署成为可能。
