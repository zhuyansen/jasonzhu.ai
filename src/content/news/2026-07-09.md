- **来源**：GitHub Trending
- **链接**：https://github.com/TencentCloud/TencentDB-Agent-Memory

- **EN**：Tencent open-sourced TencentDB Agent Memory, a fully local long-term memory system using a 4-tier progressive pipeline with zero external API dependencies. It compresses tool logs into compact Mermaid diagrams for short-term memory and layers long-term recall — a practical memory solution for stateful agents.

### OpenAI质疑SWE-Bench Pro可靠性：编程评测基准噪声太大

- **板块**：AI 工具动态
- **来源**：OpenAI Blog
- **链接**：https://openai.com/index/separating-signal-from-noise-coding-evaluations
- **TitleEN**：OpenAI Challenges SWE-Bench Pro Coding Benchmark Reliability

OpenAI发布分析报告，指出热门编程评测基准SWE-Bench Pro存在严重的可靠性和准确性问题。这对AI编程工具的开发者和选型者意味着：不要盲信单一榜单排名，模型的实际编码能力可能被高估或低估，需要更多元的评测体系。

- **EN**：OpenAI published an analysis revealing reliability and accuracy issues in SWE-Bench Pro, a popular coding benchmark. For developers evaluating AI coding tools, this means single-benchmark rankings can be misleading — actual coding ability may be over- or under-estimated.
