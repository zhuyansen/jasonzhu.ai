A practical reference for using coding agents on serious projects.

### Impeccable：让AI编码Agent写出不「AI味」的前端

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/pbakaus/impeccable
- **TitleEN**：Impeccable Gives AI Coding Agents Real Design Taste

Impeccable 是面向 AI 编码 Agent 的设计规范，包含 1 个 Skill、24 条命令、浏览器实时迭代，以及 60 条确定性检测规则，专门识别 AI 生成前端的常见设计问题。一行 npx impeccable install 即可接入，定位是 Anthropic frontend-design Skill 的进阶替代，能直接改善 Agent 生成界面的质量。

- **EN**：Impeccable is a design language for AI coding agents: one skill, 24 commands, live browser iteration and 60 deterministic detector rules that catch common flaws in AI-generated frontends. It installs with npx impeccable install and positions itself as a step beyond Anthropic's frontend-design skill, directly improving the UI quality agents produce.

### e2e：用自然语言写测试，让Agent自动操作App

- **板块**：AI 工具动态
- **来源**：GitHub Trending
- **链接**：https://github.com/tester-army/e2e
- **TitleEN**：e2e: Agent-Driven End-to-End Testing in Natural Language

tester-army 开源了新一代端到端测试框架 e2e，支持 Web 和移动端 App。开发者只需用自然语言描述目标，Agent 就会自行操作应用去完成；同一个测试里还能用定位器和断言校验结果。它把 AI 的灵活性和传统断言的确定性结合起来，能大幅降低 UI 测试的编写和维护成本。

- **EN**：tester-army open-sourced e2e, an end-to-end testing framework for web and mobile apps. Developers describe a goal in natural language and an agent drives the app to reach it, then verify results with locators and assertions in the same test. Combining agent flexibility with deterministic checks could sharply cut UI test writing and maintenance costs.

### 新论文：按Agent行为规划MoE专家路由，强化学习更高效

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.07332
- **TitleEN**：Structuring MoE Expert Routing Improves Agentic RL

长任务 Agent 大多跑在稀疏混合专家（MoE）模型上，即每次只调用模型中一部分「专家」子网络。研究发现，现成 MoE 模型选择专家的方式天然对应 Agent 的行动轨迹：Agent 在不同轮次做相似的事时，调用的专家也高度重合。据此在 Agent 后训练中有意识地规划专家选择，有望让开源 Agent 模型训练更稳定、推理更高效。

- **EN**：Long-horizon agents often run on sparse mixture-of-experts (MoE) models, which activate only a subset of expert sub-networks per step. This paper finds that expert routing in off-the-shelf MoE models naturally mirrors agent trajectories, overlapping heavily across turns where the agent does similar work. Structuring expert selection during agentic post-training could make open agent models more stable to train and more efficient to run.
