### Archify：给 Claude Code/Cursor 装上「架构图生成」技能

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/tt-a1i/archify
- **TitleEN**：Archify: Agent Skill for Auto-Generating Interactive Architecture Diagrams

Archify 是一个适配 Claude Code、Cursor、Codex CLI 等 AI 编码工具的 Agent Skill，可将代码库或系统描述自动转化为带动效的交互式架构图、时序图、数据流图，输出为自包含 HTML，可直接导出高清图。让「代码 → 文档」自动化迈出实质一步。

- **EN**：Archify is an agent skill for Claude Code, Cursor, and Codex CLI that turns codebases or system descriptions into polished, interactive architecture diagrams rendered as self-contained HTML. Agents produce typed JSON IR; Archify compiles it deterministically — closing the gap between code and living documentation.

### CaSKG：用因果技能图解决 Agent 技能检索难题

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.25500
- **TitleEN**：CaSKG: Counterfactual-Causal Skill Graphs for Scalable Agent Skill Retrieval

随着 Agent 技能库越来越大，怎么高效找到「对的技能」成了难题。CaSKG 用反事实因果图来建模技能之间的依赖关系，比传统向量检索更准确地还原工作流上下文，同时控制 Context 长度。对构建复杂多步 Agent 系统的开发者来说，这是一套可直接借鉴的技能管理架构。

- **EN**：As agent skill libraries grow, retrieval becomes the bottleneck. CaSKG uses counterfactual-causal graphs to model skill dependencies, recovering workflow context more accurately than vector search while keeping prompt costs low — a directly applicable architecture for developers building multi-step agent systems.

### PILOT：让长程 Agent 在运行中实时自我优化

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.26530
- **TitleEN**：PILOT: Live Self-Improvement for Long-Horizon Agents During Execution

现有 Agent 自我改进方法都在任务结束后才处理经验，无法实时纠偏。PILOT 提出「实时自我改进」框架：在长程任务执行过程中，Agent 可同时用新经验重定向当前运行并更新持久化脚手架。对需要长时间、多步骤执行的 AI 工作流开发者有直接参考价值。

- **EN**：Most agent self-improvement methods only kick in after a task finishes. PILOT enables live self-improvement: agents use emerging experience to redirect the active run and update their persistent harness simultaneously — critical for developers building long-horizon workflows where mid-run course correction matters.

### TTPO：无需标注数据，测试时动态优化模型推理策略

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.27448
- **TitleEN**：TTPO: Test-Time Policy Optimization Without Ground-Truth Labels

传统后训练（RL/OPSD）依赖人工标注，而 TTPO 在测试时通过多数投票伪标签进行策略优化，并针对「错误投票污染教师信号」的不对称失效问题做了专项修复。开发者在没有标注预算时，也能在推理阶段持续提升模型数学推理能力。

- **EN**：TTPO enables test-time policy optimization using majority-vote pseudo-labels instead of ground-truth annotations. It specifically addresses the asymmetric failure mode where incorrect votes corrupt the training signal — letting developers boost reasoning performance at inference time without any labeling budget.
