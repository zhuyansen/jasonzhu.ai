### FLEET 论文：用熵引导采样替代温度随机，减少 LLM 重复输出、提升推理效率

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.27657
- **TitleEN**：FLEET Paper: Entropy-Guided Sampling Cuts LLM Duplicate Outputs, Boosts Accuracy

FLEET 提出用 logits 熵动态引导生成轨迹，替代传统无记忆的温度采样。核心问题：多次采样时大量结果语义重复，边际收益递减。FLEET 让每次采样都「记住」之前生成的结果再决策，对需要多路推理聚合的 Agent 和代码生成场景有直接提效价值。

- **EN**：FLEET replaces memoryless temperature sampling with entropy-aware trajectory guidance, so each new generation is informed by prior outputs. This directly addresses diminishing returns in multi-sample reasoning — highly relevant for agent workflows and code generation that rely on best-of-N sampling.
