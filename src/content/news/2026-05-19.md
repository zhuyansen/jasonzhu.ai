### Anthropic 收购 SDK 自动化初创公司 Stainless

- **来源**：TechCrunch AI

### MetaAgent-X 论文：用端到端强化学习打破多智能体系统的「冻结执行者瓶颈」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.14212

现有多 Agent 系统的痛点：设计 Agent 的「元层」可以优化，但实际干活的执行 Agent 是冻结的，无法一起训练。MetaAgent-X 用端到端强化学习同时训练「自我设计」和「自我执行」两层，打破了这个天花板。对构建复杂 Agent 工作流的开发者而言，这意味着未来 Agent 编排不再需要手工写死执行逻辑。

### Agent Harness 安全审计论文：最终输出无问题不代表过程没有越权

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.14271

研究发现 LLM Agent 的执行框架（Harness）存在严重安全盲区：Agent 给出了正确答案，但中间过程可能访问了未授权资源或向错误组件泄露上下文，而现有安全评测只看最终输出根本发现不了。这对所有在生产环境部署 Agent 的团队是一记警钟——你的 Agent 可能「表现良好但行为有问题」。
