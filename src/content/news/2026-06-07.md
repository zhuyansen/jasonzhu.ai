### OpenAI 推出 Lockdown Mode：防止敏感数据被 Prompt 注入窃取

- **板块**：AI 工具动态
- **来源**：TechCrunch AI
- **链接**：https://techcrunch.com/2026/06/06/openai-unveils-lockdown-mode-to-protect-sensitive-data-from-prompt-injection-attacks/
- **TitleEN**：OpenAI Launches Lockdown Mode to Block Prompt Injection Attacks

OpenAI 发布 Lockdown Mode，专门对抗 Prompt 注入攻击，降低 Agent 处理敏感数据时被恶意提取的风险。虽不能 100% 防御，但对企业级 Agent 部署场景意义重大——这是 OpenAI 首次在产品层面正式承认并应对 Prompt 注入威胁。

- **EN**：OpenAI introduced Lockdown Mode to counter prompt injection attacks, reducing the risk of sensitive data being maliciously extracted during agent workflows. While not a complete defense, it marks a significant milestone for enterprise agent deployments — and represents OpenAI's first formal product-level acknowledgment of prompt injection as a genuine threat.

### HF 论文：编程 Agent 在真实项目中的安全边界基准 SABER

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.01317
- **TitleEN**：SABER Benchmark Tests Whether Coding Agents Can Destroy Production

SABER 是首个专门测试「编程 Agent 在真实有状态项目中操作安全性」的基准。现有安全测试只看单次拒绝响应，SABER 则评估 Agent 执行一系列操作后工作区的最终状态——对于正在用 Claude Code 或 Cursor 做自动化部署的团队，这直接回答了「Agent 会不会搞坏生产环境」的核心问题。

- **EN**：SABER is the first benchmark evaluating coding agent safety within real, stateful software projects. Unlike existing tests that measure single-turn refusals, SABER assesses the final state of a workspace after a full sequence of agent actions — directly answering whether tools like Claude Code or Cursor could cause irreversible damage in real deployment scenarios.

### HF 论文：LLM 匿名化在 Agent 搜索时代已失效，新防御框架来了

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.30848
- **TitleEN**：New Framework Tackles LLM Re-identification in the Age of Agentic Search

当 LLM Agent 能联网搜索时，传统文本匿名化形同虚设——看似无害的上下文线索可被交叉检索还原身份。这篇论文提出新框架，在「抵抗 Agent 重识别」和「保留文本分析价值」之间寻找平衡。做数据处理、合规产品或隐私工具的开发者需重新评估现有匿名化方案。

- **EN**：When LLM agents can search the web, traditional text anonymization breaks down — seemingly innocuous context clues can be cross-referenced to re-identify individuals. This paper proposes a new framework balancing resistance to agent-driven re-identification against preserving analytical utility, prompting developers of data pipelines and privacy tools to reassess current anonymization approaches.
