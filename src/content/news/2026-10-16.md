### Context Mode把MCP工具输出压缩98%

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/mksglu/context-mode
- **TitleEN**：Context Mode Cuts MCP Context Usage

Context Mode通过沙箱、会话记忆和MCP路由，减少AI编码代理接收的原始工具输出，官方称可压缩98%。它能缓解长会话中的上下文膨胀问题，提升Claude Code等代理的持续工作能力。

- **EN**：Context Mode combines sandboxed tool output, persistent session memory, and MCP routing across 17 platforms. It claims to reduce raw context usage by up to 98%, addressing a major bottleneck for long-running coding agents such as Claude Code and making extended workflows more practical.

### PreciseCoder让代码模型少改动也能精准修复

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.18755
- **TitleEN**：PreciseCoder Improves Faithful Code Debugging

PreciseCoder指出，只用单元测试训练代码模型，虽然能提高通过率，却会诱导模型过度修改，甚至误判正确代码存在问题。新方法加入语义验证和局部修复信号，让AI更可能精准修 bug，而不是大范围重写。

- **EN**：PreciseCoder shows that training code models only against unit-test rewards can encourage unnecessary edits and hallucinated bugs in correct code. Its additional semantic and locality signals favor minimal, verified fixes, which matters for developers who need reliable automated debugging rather than broad code rewrites.
