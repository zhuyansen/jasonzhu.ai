### Vercel推出面向Agent的浏览器自动化CLI

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/vercel-labs/agent-browser
- **TitleEN**：Vercel Releases Browser Automation CLI for Agents

Vercel开源agent-browser，提供基于Rust的浏览器自动化CLI。Agent可通过可访问性树读取页面，并用元素引用逐步执行点击、输入等操作，为网页操作Agent提供更轻量、可检查的底层工具。

- **EN**：Vercel Labs released agent-browser, a Rust-based CLI for browser automation by AI agents. It exposes pages as compact accessibility trees and lets agents act on stable element references, offering developers a lightweight and inspectable foundation for web research, testing, and workflow automation.

### Cloudflare开源多阶段安全审计Agent Skill

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/cloudflare/security-audit-skill
- **TitleEN**：Cloudflare Open-Sources Multi-Stage Security Audit Skill

Cloudflare发布security-audit-skill，将侦察、覆盖率驱动的漏洞搜索、候选验证和独立复核串成多阶段流程，并输出机器可读结果。它展示了Skill如何把通用编码Agent改造成更可靠的安全审计系统。

- **EN**：Cloudflare published security-audit-skill, which coordinates reconnaissance, coverage-driven vulnerability hunting, candidate validation, independent verification, and structured reporting. The project shows how reusable skills can turn a general coding agent into a more disciplined security auditing system with machine-readable, independently checked findings.

### Google发布覆盖云产品的Agent Skills集合

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/google/skills
- **TitleEN**：Google Publishes Agent Skills for Its Cloud Ecosystem

Google开源面向Google产品和Google Cloud的Agent Skills仓库，支持通过npx skills add安装，并可按项目或全局配置。官方直接提供可复用技能，降低Agent接入云服务和企业工具的开发门槛。

- **EN**：Google released an open repository of Agent Skills for Google products and Google Cloud. Developers can install selected skills or the full collection through npx and choose project-level or global configuration, making it easier to give coding agents reliable knowledge of Google APIs and workflows.

### Anthropic公开Claude官方Agent Skills实现

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/anthropics/skills
- **TitleEN**：Anthropic Open-Sources Its Official Claude Skills

Anthropic公开Claude的官方Skills实现：通过按需加载的指令、脚本和资源，让模型在文档生成、数据分析等专业任务中遵循可复用流程。该仓库也进一步推动Agent Skills从零散提示词走向标准化组件。

- **EN**：Anthropic open-sourced its implementation of Skills for Claude. Skills package instructions, scripts, and resources that Claude loads dynamically for specialized tasks such as document creation and data analysis. The release helps move agent customization beyond ad hoc prompts toward reusable, portable components.

### 斯坦福用真实开源项目重做AI工程课程

- **板块**：AI 工具动态
- **来源**：Latent Space
- **链接**：https://latent.space/p/one_million_ai_engineer_special_how_stanford_teaches_ai-native_engineering_mihail_eric_monaco/
- **TitleEN**：Stanford Rebuilds AI Engineering Around Real Repositories

斯坦福CS146S课程开始围绕AI原生工程重新设计作业：学生需要理解陌生开源仓库、提出修改方案并提交变更，而不是只完成传统编程题。课程变化说明编码Agent正在迫使工程教育转向代码审查、系统理解和协作能力。

- **EN**：Stanford’s CS146S course is adapting to AI-native engineering by assigning students unfamiliar open-source repositories, asking them to propose changes and contribute real modifications. Instead of testing whether students can merely write code, the curriculum emphasizes repository comprehension, review, system-level reasoning, and collaboration with coding agents.

### OpenFrontiers为科研Agent建立开放问题基准

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.37739
- **TitleEN**：OpenFrontiers Builds a Benchmark for Research Agents

OpenFrontiers整理跨学科开放科研问题，并加入一批已解决数学问题作为回溯评测集，记录问题背景、研究进展与最终结果。对开发者而言，它提供了比普通问答更接近真实科研的任务和评测入口，可用于测试Research Agent的检索、推理与发现能力。

- **EN**：OpenFrontiers introduces a structured collection of open research problems across disciplines, together with retrospective benchmarks built from recently solved mathematical problems. For developers, it offers a more realistic testbed than standard question answering, enabling evaluation of research agents on retrieval, reasoning, progress tracking, and scientific rediscovery.
