### Apple 开源 container 工具：Mac 上用轻量虚拟机跑 Linux 容器

- **板块**：AI 工具动态
- **来源**：GitHub Trending
- **链接**：https://github.com/apple/container
- **TitleEN**：Apple Open-Sources 'container': Linux Containers via Lightweight VMs on Mac

Apple 开源了 container 工具，支持在 Mac（尤其 Apple Silicon）上通过轻量级虚拟机运行 Linux 容器，兼容 OCI 标准镜像。对于在 Mac 上本地运行 AI 模型、构建 Agent 沙盒环境的开发者来说，这是 Docker 之外的一个高性能原生替代方案。

- **EN**：Apple open-sourced 'container', a Swift-built tool for running OCI-compatible Linux containers as lightweight VMs on Mac, optimized for Apple Silicon. For developers building local AI model environments or agent sandboxes on Mac, this offers a native, high-performance alternative to Docker.
