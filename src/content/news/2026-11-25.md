### Beam模型发布：23B激活参数实现百万上下文推理

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.26358
- **TitleEN**：Beam MoE Model Delivers Frontier Reasoning With 1M Context

Beam 是面向编码与智能体的稀疏 MoE 模型（总参 501.3B、激活 23.4B），支持百万级上下文。它仅需同类模型 1/4 至 1/3 的推理算力即可达到前沿推理水平，大幅降低长代码库 Agent 部署成本。

- **EN**：Beam is a 501.3B-total, 23.4B-active sparse MoE model engineered for coding, reasoning, and agentic workloads with a 1M-token context window. By achieving frontier reasoning with three to four times less inference compute, it gives developers a far more cost-efficient backbone for long-context agents.

### VideoJSON：用极简JSON与编码智能体检索超长视频

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.28167
- **TitleEN**：VideoJSON Beats Complex Memory Graphs for Ultra-Long Video

针对数天乃至数周的超长视频检索，VideoJSON 抛弃复杂的记忆图谱，改用视觉模型按分钟生成极简 JSON 记录，并让编码智能体自主编写搜索程序，启发开发者用轻量索引配合代码检索替代繁琐的记忆架构。

- **EN**：Instead of relying on rigid memory graphs for multi-day video search, VideoJSON indexes each minute into a minimal JSON record and lets a coding agent write custom search programs. For developers, this shows that simple structured indexes paired with agent-written code can outperform complex memory pipelines.

### 前沿模型仅凭单段文本即可零样本溯源人类或AI作者

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.26216
- **TitleEN**：Frontier Models Unmask Human or AI Authors From One Text

研究发现，无需联网或对比样本，GPT-6.1 Sol、Claude Fable 5.2 等前沿模型仅凭单段文本即可零样本识别作者归属、所属实验室乃至具体人类写作者，提醒开发者关注内容溯源与输出匿名性风险。

- **EN**：Without tools or reference samples, frontier models such as Claude Fable 5.2, GPT-6.1 Sol, and Gemini 4 Carbon can identify from a single text whether a human or AI wrote it, which lab built it, and often which person authored it—highlighting new stakes for content attribution and anonymity.

### SMB Bench：评估智能体应对延迟后果的长期运营能力

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.28158
- **TitleEN**：SMB Bench Tests AI Agents on Delayed Operational Consequences

针对多日连续运营中“当下决策数周后才暴露后果”的难题，研究推出 90 天批发仿真环境 SMB Bench。它帮助开发者评估并训练智能体在缺货、现金流约束等延迟反馈场景下的长期规划能力，而非仅测单轮任务。

- **EN**：SMB Bench introduces a calibrated 90-day wholesale simulator to test how language model agents handle decisions whose consequences unfold weeks later, such as lost customers and cash crunches. For developers building autonomous business agents, it provides a realistic benchmark beyond isolated single-turn tasks.
