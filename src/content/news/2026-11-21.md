### System 1智能体：本地小模型用选择题可靠调用工具

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.21053
- **TitleEN**：System 1 Agents Make Local Tool Calls Reliable

本地小模型调用工具时容易编造参数，一个错误值会污染后续所有步骤。该研究用确定性编译器，把工具 schema 和用户请求转换成选项受限的选择题，模型只需做选择、不再自由生成文本。对医疗、金融等不能上云的敏感场景，这为又快又稳的本地智能体提供了一种可行方案。

- **EN**：Local LLMs often hallucinate tool-call arguments, and one bad value corrupts every later step. This paper uses a deterministic compiler to turn tool schemas and requests into constrained multiple-choice questions, so the model selects options instead of generating text. It offers a fast, reliable path to local agents for sensitive domains like healthcare that cannot use cloud models.

### Squoosh Bench用318个真实A/B测试检验AI预测

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.25200
- **TitleEN**：Squoosh Bench Tests AI on 318 Real A/B Tests

研究用 318 个运行超过 21 天的真实网站 A/B 测试，检验模拟购物者模型能否提前预测实验结果。实验中屏蔽了页面角色，也不提供实际结果。参评模型之一 Squoosh UX-1 基于真实浏览数据微调。对流量有限的出海和独立开发团队来说，这类方法有望帮助筛掉低价值实验，把流量留给更有潜力的改动。

- **EN**：Researchers evaluated whether simulated-shopper models can predict website A/B test outcomes, using 318 historical tests that ran over 21 days, with page roles masked and results withheld. One evaluated system, Squoosh UX-1, is fine-tuned on human browsing data. For traffic-limited indie teams, such forecasts could help skip low-value experiments and focus traffic on promising changes.
