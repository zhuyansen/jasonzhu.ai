### Agent Skill 结构化表示新框架：让机器真正「读懂」技能包而非只看文档

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2604.24026
- **TitleEN**：Structured Skill Representation Lets Agents Truly Parse Skill Packages

现有 Agent 的 Skill 大多还是 Markdown 文档，机器靠「猜」来理解和调用。这篇论文提出 SSL（调度-结构-逻辑）表示框架，把技能包拆解为机器可直接解析的结构化格式。对于正在构建 Skill 生态或 Agent 编排系统的开发者，这套框架可能直接影响你的 Skill 设计思路。

- **EN**：Most agent skills are still Markdown documents, so models have to guess how to interpret and invoke them. This paper proposes SSL (Scheduling-Structure-Logic), a framework that breaks skill packages down into machine-parsable structured formats. If you're building a skill ecosystem or an agent orchestration system, it could reshape how you design skills.

### 视觉语言模型「在线自校正」新方法：无需 GPT 监督，自己治自己的幻觉

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.00323
- **TitleEN**：Online Self-Correction Lets VLMs Fix Their Own Hallucinations Without GPT

主流 VLM 减少幻觉的方式是用 GPT 等强模型来「教」弱模型，但这会导致学生模型学会「猜答案」而非真正看图。这篇论文提出在线自校正机制，让模型在推理过程中自己发现并纠正幻觉，无需外部强模型监督——对多模态应用开发者而言，意味着更可靠的视觉理解输出。

- **EN**：Most vision-language models reduce hallucinations by learning from stronger models like GPT, but this can teach student models to guess answers rather than actually look at the image. This paper proposes an online self-correction mechanism that lets models detect and fix hallucinations during inference, with no external supervision. For multimodal developers, that means more reliable visual understanding.
