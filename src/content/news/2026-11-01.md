### claude-mem让Agent跨会话保留完整上下文

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/thedotmack/claude-mem
- **TitleEN**：claude-mem Brings Persistent Memory to Agents

开源项目claude-mem会记录Agent执行过程，用AI压缩并在后续会话中注入相关上下文，支持Claude Code、Codex、Gemini等多种工具。它解决了Agent每次重启都要重新理解项目的问题，为长期协作型编码工作流提供了可复用的记忆层。

- **EN**：claude-mem records agent activity, compresses it with AI, and injects relevant context into future sessions across Claude Code, Codex, Gemini, and other tools. It addresses the costly loss of project context between sessions, providing a reusable memory layer for long-running coding and automation workflows.

### EPSBench测试Agent能否把财报读成盈利预测

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.38293
- **TitleEN**：EPSBench Tests Agents on Earnings Forecasting

EPSBench用86家公司、149个财报季度构建评测，要求Agent从公告、电话会和新闻中提取证据，推算具体利润表驱动因素并给出可核验预测。它把“会总结财报”与“能完成严谨财务推理”区分开，对金融Agent的可靠性评估很有价值。

- **EN**：EPSBench evaluates agents on 149 quarters across 86 companies, requiring them to extract evidence from filings, earnings calls, and news before estimating income-statement drivers. It separates merely summarizing financial documents from performing auditable financial reasoning, offering a practical reliability test for finance-oriented agents.

### WISD用削弱版模型反向提升推理能力

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.38681
- **TitleEN**：WISD Improves Reasoning Through Weaker Self-Distillation

WISD提出一种不依赖外部教师模型的自蒸馏方法：先构造原模型的较弱版本，再利用强弱模型在同一任务上的差异作为训练信号。对开发者而言，这意味着在只有未标注提示、缺少高质量答案时，也可能低成本增强推理模型。

- **EN**：WISD improves a reasoning model without requiring an external teacher or labeled answers. It creates a weakened version of the model and uses the performance gap between the original and weakened versions as a training signal. This could make reasoning improvements cheaper when high-quality supervision is unavailable.

### 统一训练框架试图打通预训练与强化学习

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.40564
- **TitleEN**：Unified Training Reframes Foundation Model Development

论文认为预训练、中期训练、监督微调和强化学习不必依赖完全不同的算法，而可统一为对模型生成目标分布进行似然拟合。若方法成立，模型训练流程有望更简洁、目标更一致，也便于开发者理解不同训练阶段究竟在优化什么。

- **EN**：The paper argues that pretraining, midtraining, supervised fine-tuning, and reinforcement learning can be expressed as variants of one likelihood-based objective over model-generated target distributions. If validated, this could simplify training pipelines and give developers a clearer view of what each stage is actually optimizing.
