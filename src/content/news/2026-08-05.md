### LLM 天生不爱删代码：五大顶级模型删除召回率最高仅 71.7%

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.28887
- **TitleEN**：LLMs systematically avoid deleting code, top models max at 71.7% deletion recall

研究发现所有主流代码模型在修复任务中都存在「删除回避」倾向——即便任务明确要求删除代码，模型也倾向于保留。在 SWE-bench 五大顶级模型中，删除召回率最高只有 71.7%。这直接解释了为什么 AI 修复的代码能通过测试，却让代码库越来越难维护。

- **EN**：New research identifies 'deletion avoidance' in LLMs — models systematically retain code that edits should remove. Across the top five SWE-bench models, deletion recall against developer patches peaks at just 71.7%. This explains why AI-patched code passes tests but silently degrades codebase maintainability.

### Zero-Mem：Agent 长期记忆无需额外 LLM 调用，零 Token 开销新方案

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.29377
- **TitleEN**：Zero-Mem: LLM agents get persistent memory with zero extra token cost

Zero-Mem 提出一种结构化记忆访问方案，让 Agent 在长对话中维持一致性记忆，同时完全不需要额外的 LLM 调用或 Token 消耗。对于需要构建长期记忆模块的开发者而言，这意味着可以大幅降低 Agent 的推理成本，同时保留原始记忆的完整性。

- **EN**：Zero-Mem introduces memory operations for LLM agents that require zero additional LLM calls or input tokens outside final answer generation. For developers building memory-augmented agents, this approach cuts recurring inference costs while preserving full fidelity of stored context.
