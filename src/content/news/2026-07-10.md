### AgentLens：首个评估代码Agent完整执行轨迹的生产级基准

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.06624
- **TitleEN**：AgentLens: First Production-Grade Benchmark Evaluating Full Code Agent Trajectories

现有代码Agent评测只看「任务有没有通过」，AgentLens提出全新范式：评估Agent的整条执行轨迹——包括它如何遵循指令、使用工具、验证自己的工作、从错误中恢复以及与用户沟通。对做编程Agent产品的开发者而言，这意味着未来选型不能只看成功率，执行质量同样关键。

- **EN**：AgentLens introduces a new benchmark that evaluates code agents on their full execution trajectory—instruction following, tool use, self-verification, error recovery, and communication—not just pass/fail. For developers building coding agents, this shifts evaluation focus from task success to overall execution quality.

### 单步异步RL训练框架SARA：让Agent强化学习训练效率大幅提升

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.07508
- **TitleEN**：SARA: Single-Rollout Async RL Dramatically Speeds Up Agent Post-Training

传统LLM强化学习训练是同步批处理的，在长时Agent任务上效率极低。SARA提出单步异步优化框架，Rollout一完成就立即更新模型，同时兼顾训练稳定性。对开发者的意义：未来给Agent做RLHF微调的速度和效果都会显著改善，降低Post-training门槛。

- **EN**：SARA proposes a single-rollout asynchronous RL pipeline that updates LLMs as each rollout completes, solving inefficiency in long-horizon agent training. For developers, this means faster, more stable post-training for agents, lowering the barrier to fine-tuning agent models with RL.
