### FlowEvo：工作流与技能协同进化的无训练 Agent 自我提升框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.21596
- **TitleEN**：FlowEvo: Training-Free Agent Framework Where Workflows and Skills Co-Evolve

现有 Agent 系统的问题：每次任务的「成功经验」用完即丢，技能库也是离线静态的。FlowEvo 让 Agent 在推理时把成功的工作流直接编译成可调用技能，工作流和技能互相喂养持续生长。对开发者意味着：不需要额外训练，Agent 越跑越聪明，技能库自动增长。

- **EN**：FlowEvo introduces a training-free framework where LLM agents compile successful workflows into reusable callable skills at inference time. Workflows and skills co-evolve rather than being discarded or frozen offline. For developers: your agent automatically gets smarter with every run, no retraining needed.

### HSI 论文：让 Agent Harness 像代码一样持续自我重写进化

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.08466
- **TitleEN**：HSI: Agent Harnesses That Continuously Rewrite Themselves via Environment Feedback

传统 Agent 的「脚手架/Harness」部署后就冻结不变。这篇论文提出 HSI 框架：每个任务家族维护独立 Harness，Agent 根据运行环境反馈持续热替换和重写它。对开发者的价值：Agent 基础架构本身成为自适应组件，无需人工维护升级。

- **EN**：Instead of treating the agent harness as a fixed post-deployment artifact, HSI makes it task-specific and continuously rewritable via environment feedback. Each task family hot-swaps its own harness through a fixed injection seam. Practical upshot: infrastructure that maintains itself as tasks evolve.

### LLM 做嵌入到底值不值？大规模对比：最佳 LLM 与嵌入模型相差仅 0.4 分

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.12875
- **TitleEN**：LLM vs Embedding Models: Controlled Study Finds Only 0.4-Point Gap at Best

你该用 LLM 替换文本嵌入管道吗？研究对 10 个 LLM 和 26 个嵌入模型做了 37 项任务的成本感知对比，结论：顶级 LLM（Gemini 3.1 Pro，77.6分）与顶级嵌入模型（77.2分）差距仅 0.4 分，但成本和延迟差距巨大。实用结论：检索/分类任务继续用专用嵌入模型，别跟风换 LLM。

- **EN**：A rigorous cost-aware comparison of 10 LLMs and 26 embedding models across 37 tasks finds the best LLM (Gemini 3.1 Pro, 77.6) and best embedding model (77.2) differ by just 0.4 points overall. Practical takeaway: stick with specialized embedding models for retrieval and classification — the performance parity doesn't justify the cost premium of LLMs.
