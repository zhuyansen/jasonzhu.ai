Real-world tests show Legora reviewing 41 documents in minutes with 40% better accuracy, and Playco cutting manual fixes by 50%. Powerful—and controversial.

### Ponytail：让 Claude Code 像「最懒的高级工程师」一样少写代码、多干活

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/DietrichGebert/ponytail
- **TitleEN**：Ponytail: Claude Code Skill That Cuts Code Written by Up to 94%

Ponytail 是专为 Claude Code 设计的 Skill，核心理念是「最好的代码是从不写出来的代码」。在真实 FastAPI+React 项目基准测试中，平均减少 54% 代码量（最多 94%），同时降低约 20% 成本、提速 27%。已作为 Claude Code Skill 发布，对想控制 token 消耗的开发者很实用。

- **EN**：Ponytail is a Claude Code Skill that channels 'the laziest senior dev in the room'—write less, ship more. Benchmarked on real FastAPI+React repos, it cuts code volume by ~54% on average (up to 94%), reduces costs ~20%, and speeds up sessions ~27%. A practical tool for developers watching token burn.

### WHALE：同步优化模型权重与执行代码，让 AI Agent 性能上限再突破

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.00196
- **TitleEN**：WHALE: Joint Weight-Harness Optimization Unlocks Agent Performance Ceiling

现有 AI Agent 调优存在「一条腿走路」问题：要么只优化模型权重，要么只改提示/控制代码，两者互相制约。WHALE（Weight-Harness ALternating Evolution）提出交替优化权重和执行框架代码的方法，对开发者意味着：不改架构、不换模型，只需迭代调优就能显著提升 Agent 实际表现。

- **EN**：Tuning AI agents by updating model weights alone—or prompt/harness code alone—leaves performance on the table because each change shifts what the other needs. WHALE alternates between optimizing both, without changing the architecture. For developers: better agent performance from the same model, just smarter iteration.

### NeoMME：2.6 亿参数多模态多语言编码器，ColPali 级别性能、更低算力

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.01657
- **TitleEN**：NeoMME: 260M-Param Multimodal Multilingual Encoder Rivals VLM-Based Retrievers

多模态检索模型（如 ColPali）通常复用生成式大模型架构，参数臃肿。NeoMME 提出 2.6 亿/8 亿参数的原生多模态双向编码器，直接处理多语言文本和原始图像，无需独立视觉编码器。对做文档检索、RAG 或多语言多模态应用的开发者：更小的模型，更快的推理，更低的部署成本。

- **EN**：Most multimodal retrievers like ColPali repurpose heavy generative VLMs as encoders—wasteful for non-generative tasks. NeoMME introduces 260M/800M-parameter native multimodal bidirectional encoders processing text and images natively. For developers building document retrieval or multilingual multimodal apps: smaller, faster, cheaper.
