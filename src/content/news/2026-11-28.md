### 实测四大编程智能体：仓库规则文件并非安全防火墙

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.27112
- **TitleEN**：Markdown Rules Files Fail as Firewalls for Coding Agents

研究团队用同一份 278 词的仓库规则文件测试 Claude Code、Codex CLI、Gemini CLI 与 OpenCode，检验其在隐藏测试与边界门控下的表现，揭示仅靠 Markdown 提示词无法替代真正的安全边界控制。

- **EN**：Researchers tested a single 278-word repository rules file across Claude Code, Codex CLI, Gemini CLI, and OpenCode with DeepSeek over multiple repos with hidden tests. For developers, the findings show Markdown instructions alone cannot enforce hard security boundaries at critical gates.

### 重审上下文工程：让大模型从离线试错中自动提炼经验

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.30494
- **TitleEN**：Revisiting How LLMs Automate Context Engineering from Trials

针对无需高成本训练即可引导模型的上下文工程（LCE），该研究系统梳理了让大模型充当工程师、从离线试错中自动总结通用指令与经验的方法，帮助开发者更高效地构建免微调的自适应提示与元信息系统。

- **EN**：LLM context engineering steers models via prompts and metadata without heavy training, increasingly using LLMs themselves to distill generalizable rules from offline trials. This paper revisits these automated approaches, helping developers build stronger non-finetuned agent workflows.

### BiSAT 语音分词新框架：低码率兼顾语义与声学细节

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.30723
- **TitleEN**：BiSAT Aligns Semantic and Acoustic Tokens for Speech LMs

语音大模型需要在低码率下同时保留语言语义与声音细节，但传统单一特征空间容易引发两者相互干扰。BiSAT 提出双向对齐的语义-声学分词方案，有助于开发者打造更自然且更易建模的实时语音交互模型。

- **EN**：Speech language models need discrete tokens that preserve both linguistic meaning and acoustic detail at low bitrates, yet combining them in one feature space causes interference. BiSAT introduces bidirectional semantic-acoustic alignment, helping developers build clearer, easier-to-model voice systems.

### 多模态安全新范式：从一刀切拒答转向四级审慎干预

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.28849
- **TitleEN**：Moving Multimodal Safety Beyond Binary Refusals with Four Actions

面对视觉上下文引发的潜在风险，传统二元拒答常导致正常需求被误杀。新研究提出包含允许、警告、复核与拒答的四类动作体系，并开源 2 万余条训练审计数据与 JudiBench 基准，助力优化产品可用性。

- **EN**：Blanket refusals often frustrate users when visual context makes a request ambiguous rather than clearly harmful. Researchers introduce a four-action framework—allow, warn, review, and refuse—backed by 20,126 training audits and JudiBench, helping developers reduce false-positive blocks.

### DAWIN 连续时间神经元：重构不规则时空序列建模原语

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.30025
- **TitleEN**：DAWIN Introduces Continuous-Time Wave Neurons for Irregular Data

传统神经元将空间特征聚合与连续物理时间割裂，难以处理采样不规则的观测数据。DAWIN 通过闭式阻尼波演化将时间耦合进局部复数状态，可直接替换 Transformer 或 GNN 标准层，提升复杂时序建模能力。

- **EN**：Standard neural layers separate spatial aggregation from continuous time, struggling with irregularly sampled observations. DAWIN couples spatial projections with closed-form damped wave evolution to replace standard MLP, Transformer, and GNN layers, offering developers stronger continuous-time modeling.
