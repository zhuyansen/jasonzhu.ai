### LLM供应链新攻击面：无载荷Skills即可劫持Agent行为

- **板块**：AI 论文
- **来源**：Hacker News / arXiv
- **链接**：https://arxiv.org/abs/2605.14460
- **TitleEN**：Payload-Less Skills Can Hijack LLM Agent Supply Chains

研究揭示LLM Agent供应链中一种新型攻击方式：攻击者无需在Skills/插件中植入恶意代码，仅凭描述文本的语义操控就能影响Agent决策。对Claude Code、Cursor等依赖第三方Skills生态的工具影响尤为直接——你安装的「无害插件」可能已在操控Agent行为。

- **EN**：New research shows LLM agent supply chains can be compromised via payload-less skills — malicious actors manipulate agent behavior purely through crafted skill descriptions without any malicious code. Directly relevant to Claude Code and Cursor users installing third-party skills: the plugin doesn't need to run code to be dangerous.

### WARP：从模型权重逆向推断训练数据配方的新方法

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.01686
- **TitleEN**：WARP: Reverse-Engineering Training Data Portfolios from Model Weights

WARP框架通过分析模型权重空间，可以推断出训练数据的域混合比例——即模型用了多少比例的代码、新闻、书籍等数据训练。对开发者的意义：可以用来审计「黑盒」基础模型的训练数据构成，识别潜在偏差来源，在模型选型时有更多客观依据。

- **EN**：WARP analyzes model weight space to infer training data domain mixture weights — how much code, news, books, etc. went into a model — without access to training data. For developers: a practical tool to audit black-box foundation models for training bias, enabling more informed model selection decisions.

### DuoMem：将大模型记忆能力蒸馏到端侧小模型的新框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.29961
- **TitleEN**：DuoMem Distills Memory-Augmented Agent Capabilities to On-Device Models

DuoMem提出双空间蒸馏框架，将大模型的多步骤记忆增强推理能力迁移到可在资源受限设备运行的小模型。核心突破：首次让端侧小模型具备媲美大模型的程序性任务解决能力，对移动端/IoT场景的Agent部署有重要价值，无需依赖云端大模型调用。

- **EN**：DuoMem uses dual-space distillation to transfer large model procedural reasoning and memory skills to compact models that run on resource-constrained devices. Key breakthrough: on-device agents can now match cloud-model performance on multi-step tasks — critical for mobile/IoT deployments that can't rely on API calls.
