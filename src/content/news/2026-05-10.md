### Redis 创始人打造 ds4：DeepSeek v4 Flash 在 Mac 本地运行成真

- **板块**：AI 工具动态
- **来源**：X/@bindureddy
- **链接**：https://nitter.net/bindureddy/status/2052982206344409242#m
- **TitleEN**：Redis Creator's ds4 Runs DeepSeek v4 Flash Locally on Mac

Redis 创始人 Antirez 发布 ds4，专为 DeepSeek v4 Flash 定制的原生推理引擎，支持在 128GB Mac 上以 2-bit 量化本地运行这个拥有 1M 上下文窗口的准前沿模型。最大架构创新是将 KV 缓存从内存移至 SSD，彻底突破内存瓶颈，无需云端即可运行 Agent 循环。

- **EN**：Antirez, creator of Redis, released ds4, a native inference engine built for DeepSeek v4 Flash. It runs this near-frontier model with a 1M-token context window locally on a 128GB Mac using 2-bit quantization. Its key innovation moves the KV cache from RAM to SSD, removing the memory bottleneck and enabling agent loops without the cloud.

### DFlash：块扩散投机解码让大模型推理速度再上台阶

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.06627
- **TitleEN**：DFlash: Block Diffusion Speculative Decoding Speeds Up LLM Inference

DFlash 提出用块扩散模型替代传统自回归草稿模型做投机解码，能并行生成多个 token 块而非逐个预测，显著提升推理吞吐量。已适配 Gemma 4 等主流模型。对需要降低推理延迟和 API 成本的开发者，这是一个可直接集成的加速方案。

- **EN**：DFlash replaces traditional autoregressive draft models in speculative decoding with a block diffusion model. Instead of predicting one token at a time, it generates blocks of tokens in parallel, significantly boosting inference throughput. It already supports mainstream models such as Gemma 4. Developers can integrate it directly to cut inference latency and API costs.

### 数据稀缺时代来了：新缩放定律告诉你有限数据怎么用才不亏

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.01640
- **TitleEN**：New Scaling Laws Show How to Train on Limited Data

Chinchilla 定律假设每个训练 token 唯一，在数据不够用时完全失效。这篇论文用「重复过拟合惩罚」修正了缩放定律，精确量化多轮复用数据的损失代价，为数据受限场景下的预训练和微调预算分配提供可操作的决策依据。

- **EN**：The Chinchilla law assumes every training token is unique, so it breaks down when data runs short. This paper revises the scaling laws with a repetition-overfitting penalty that quantifies the cost of reusing data across multiple epochs. The result gives practitioners actionable guidance for allocating pretraining and fine-tuning budgets under data constraints.

- **板块**：AI 论文
