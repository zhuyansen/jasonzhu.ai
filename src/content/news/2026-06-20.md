### FERNme：接近零 LLM 调用的 Agent 持久记忆系统

- **板块**：Skills 生态
- **来源**：Hacker News
- **链接**：https://github.com/mirkofr/FERNme
- **TitleEN**：FERNme: Agent Memory Graph with Near-Zero LLM Calls

开发者开源了 FERNme，一个基于模糊边 Hebbian 共现规则的图式持久记忆系统。核心卖点是几乎不需要额外的 LLM 调用来维护记忆，大幅降低 Token 消耗。适合需要个性化长期记忆的 AI Agent，可让用户数据随时间积累形成个人知识图谱。

- **EN**：FERNme is an open-source graph-based persistent memory system for AI agents that uses fuzzy-edge Hebbian co-occurrence rules to maintain memory with near-zero additional LLM calls. It dramatically cuts token costs while building personalized user knowledge graphs over time—ideal for memory-augmented agents.
