### KV 缓存压缩新思路：用信息论取代注意力权重来判断 token 重要性

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.26875
- **TitleEN**：Information-Aware KV Cache Compression Beats Attention-Weight Heuristics

现有 KV 缓存压缩方案依赖注意力权重判断哪些 token 可以丢弃，但这篇论文发现注意力权重会忽略「预测不确定性」等信息论信号。新方法引入信息感知压缩机制，在长推理任务上显著降低显存占用且不损失精度——对跑长上下文本地模型的开发者直接有用。

- **EN**：This paper challenges the standard approach of using attention weights to decide which KV cache tokens to drop during long reasoning, showing that attention misses information-theoretic signals like predictive uncertainty. The proposed information-aware method cuts memory usage on long-context tasks without accuracy loss—directly useful for developers running local long-context inference.

### CoffeeBench：在多 Agent 经济体中测试 LLM 的长时程博弈能力

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.16613
- **TitleEN**：CoffeeBench: Evaluating LLM Agents in Multi-Agent Economic Systems

CoffeeBench 提出一个全新基准：让多个 LLM Agent 在模拟经济体中自主沟通、谈判、交易，测试其长时程目标追踪与多 Agent 协作能力。区别于单 Agent 与静态环境交互的传统评测，这个基准更接近真实 Agentic 应用场景，对评估 Agent 商业化部署潜力更有参考价值。

- **EN**：CoffeeBench introduces a benchmark where multiple LLM agents communicate, negotiate, and transact within a simulated economy over extended horizons. Unlike single-agent benchmarks, it mirrors real-world multi-agent deployment conditions, offering more meaningful signal for developers building production-grade agentic systems.
