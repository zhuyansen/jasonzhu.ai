Developers can reuse one skill set across agents without reconfiguring each time, sharply cutting the cost of building multi-agent workflows.

### AnyFlow：任意步数视频扩散模型，on-policy 流图蒸馏破解一致性退化难题

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.13724
- **TitleEN**：AnyFlow: Any-Step Video Diffusion via On-Policy Flow Map Distillation

现有视频生成一致性蒸馏模型在增加采样步数时质量反而下降（更多算力没有更好效果）。AnyFlow 通过 on-policy 流图蒸馏技术，让模型在任意步数下都能稳定提升质量，恢复了「多算就多好」的测试时扩展性。对需要兼顾速度和质量的视频生成应用开发者来说，这是值得跟进的架构突破。

- **EN**：Consistency-distilled video models often get worse as sampling steps increase, so more compute yields no gain. AnyFlow uses on-policy flow map distillation to improve quality reliably at any step count, restoring test-time scaling where more compute means better output. It's an architectural advance worth following for video generation developers balancing speed and quality.

### DAgger 重返 LLM Agent 训练：解决长时序任务中的「分布偏移」顽疾

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.12913
- **TitleEN**：DAgger Returns for LLM Agents, Tackling Distribution Shift in Long-Horizon Tasks

长任务 Agent 训练面临两难：监督微调数据分布和实际运行不一致，而强化学习反馈又过于稀疏。本文将经典 DAgger 算法引入 LLM Agent 时代，兼顾密集监督与 on-policy 数据分布，对正在做多步骤 Agent（如自动化工作流、代码 Agent）训练的团队有直接参考价值。

- **EN**：Training long-horizon agents involves a tradeoff: supervised fine-tuning data doesn't match real rollouts, while reinforcement learning rewards are too sparse. This paper brings the classic DAgger algorithm to LLM agents, combining dense supervision with on-policy data. It's directly relevant to teams training multi-step agents such as workflow automation or coding agents.
