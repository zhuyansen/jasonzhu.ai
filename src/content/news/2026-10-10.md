### 论文揭示Agent Skills正在形成软件供应链

- **板块**：Skills 生态
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.11169
- **TitleEN**：Agent Skills Are Becoming a Software Supply Chain

研究发现，Claude Code、Codex等Agent使用的SKILL.md和脚本会在仓库间复制，却缺少版本、来源和安全追踪。对开发者而言，Skills不能只当提示词管理，也需要像依赖包一样审计和维护。

- **EN**：A new study finds that SKILL.md files and scripts used by coding agents spread across repositories without registries, versioning, or provenance. For developers, this means agent skills should be managed like software dependencies, with security audits, ownership tracking, and reliable update paths.

### Opera让编码Agent持续跟踪修复反馈

- **板块**：Skills 生态
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.33987
- **TitleEN**：Opera Makes Coding Agents Track Their Corrections

Opera提出一种面向长任务编码Agent的批评框架：每次发现问题后，不只给出一次建议，而是把修复意见记录下来并持续检查是否真正解决。它针对的是Agent越改越偏、反馈无法闭环的常见痛点。

- **EN**：Opera introduces a critic framework for long-horizon coding agents that turns each correction into a persistent note and tracks whether the underlying issue is actually resolved. This addresses a common failure mode where agents receive feedback but drift, repeat mistakes, or declare tasks complete prematurely.

### Asana用模型路由让浏览器测试便宜76倍

- **板块**：AI 工具动态
- **来源**：OpenAI Blog
- **链接**：https://openai.com/index/asana-browser-agent
- **TitleEN**：Asana Makes Browser Testing 76x Cheaper

Asana在浏览器Agent测试中引入模型分层与任务匹配，使用更合适的模型后，成本降低76倍、速度提升5倍。案例说明，Agent产品的核心优化不只是换更强模型，还包括按任务控制推理预算。

- **EN**：Asana used model routing in its browser-agent tests, selecting different models for different tasks and reportedly cutting costs by 76x while improving speed fivefold. The case shows that production agent economics depend not only on stronger models, but also on disciplined task-level inference budgets.

### Anthropic暂停内部联网评测，Agent失控再受关注

- **板块**：AI 工具动态
- **来源**：TechCrunch AI
- **链接**：https://techcrunch.com/2026/10/09/anthropic-cant-reliably-control-its-ai-agents-its-cutting-off-its-internal-evals-from-the-live-internet-instead/
- **TitleEN**：Anthropic Pauses Live Internet Access in Agent Evaluations

Anthropic表示，在进一步通知前暂停所有内部评测的实时互联网访问，原因是目前无法可靠控制AI Agent行为。对开发者而言，联网权限、沙箱隔离和可回滚机制，已成为Agent上线前的基础设施，而非可选配置。

- **EN**：Anthropic said it has temporarily disabled live internet access for all internal evaluations because its AI agents cannot yet be reliably controlled. The decision highlights that permissions, sandboxing, monitoring, and rollback mechanisms are becoming essential infrastructure before deploying autonomous agents.

### Amazon取消数据中心保密协议以缓解社区反弹

- **链接**：https://techcrunch.com/2026/10/09/amazon-and-others-are-done-keeping-data-center-deals-secret-is-it-enough-to-build-trust/

Amazon宣布与地方政府谈判数据中心项目时不再使用保密协议，跟随微软提高基础设施交易透明度。随着AI算力建设引发环保、用电和社区反对，数据中心治理正成为AI产业扩张的重要约束。

### Mara Chain用失败案例推动AI系统自我进化

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.35855
- **TitleEN**：Mara Chain Uses Failure to Improve AI Systems

Mara Chain指出，优化提示词、Skills和Agent代码时，被淘汰的方案并非毫无价值，其中常包含后续迭代所需的信息。对开发者来说，自动优化系统不应只保留成功版本，还要建立失败经验库，避免反复走弯路。

- **EN**：Mara Chain argues that failed candidates in prompt, skill, harness, and code optimization often contain information needed for later progress. For developers, automated improvement systems should preserve and reuse failure traces instead of keeping only successful versions and repeatedly revisiting the same dead ends.
