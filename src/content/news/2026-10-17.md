### Caveman技能让编码智能体「少说话」省Token

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/JuliusBrussee/caveman
- **TitleEN**：Caveman Skill Cuts Coding Agent Tokens by Talking Less

爆火的Caveman由技能和代理组成，让编码智能体用极简的「原始人」语气输出和读取内容，代码部分保持原样。项目宣称最高可省65%的Token。其公布的测试显示：54次Claude Code运行中输入Token减少33.2%，18道题全部答对；开启Auto模式时成本降低54%，得分持平。对重度使用Claude Code的开发者来说，这是现成的降本手段。

- **EN**：Caveman, a viral skill plus proxy, makes coding agents speak and read in terse 'caveman' style while leaving code untouched. It claims up to 65% token savings. Its published tests show 33.2% fewer input tokens across 54 Claude Code runs with 18/18 correct answers, and 54% lower cost in Auto mode at the same score. Heavy agent users get a ready-made way to cut spend.

### LEASH让小模型主导电脑操作，难时再交给大模型

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.22280
- **TitleEN**：LEASH: Weak-to-Strong Escalation for Computer-Use Agents

长流程的电脑操作任务如果每一步都调用前沿大模型，成本很高；只用小模型又容易失败。LEASH让便宜的小模型默认执行任务，同时用一个每步都能低成本检查的不确定性信号，判断何时把控制权交给大模型，并在交接后继续监督大模型是否跑偏。对开发者而言，这是兼顾智能体成本和成功率的实用架构思路。

- **EN**：Running a frontier model at every step of long computer-use tasks is costly, while small models alone often fail. LEASH lets a cheap open-weight model act by default and uses an uncertainty signal cheap enough to check every step to decide when to hand off to a strong model. It also keeps overseeing the strong agent after handoff, offering a practical cost-versus-reliability design.
