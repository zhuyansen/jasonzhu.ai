### Cloudflare 开源安全审计 Skill：多阶段漏洞发现流程标准化

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/cloudflare/security-audit-skill
- **TitleEN**：Cloudflare releases open-source multi-phase security audit skill for coding agents

Cloudflare 开源了一个专为 Coding Agent 设计的安全审计 Skill，将漏洞发现流程拆解为：侦察、覆盖率导向的漏洞猎取、候选验证、结构化输出、独立记录核验、中立报告六个阶段，每个阶段由隔离 Agent 执行。这是 Cloudflare 自身漏洞发现系统的种子 Skill，为开发者提供了安全审计自动化的可复用模板。

- **EN**：Cloudflare open-sourced a coding-agent skill that orchestrates isolated agents through six phases of security auditing — from recon to neutral reporting with machine-readable, independently verified findings. This is the seed skill behind Cloudflare's own vulnerability discovery harness, offering developers a reusable template for automated security auditing.

### Builder.io 开源 Agent-Native 框架：自主任务与 UI 共享同一套 Action 定义

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/BuilderIO/agent-native
- **TitleEN**：Builder.io launches Agent-Native: one action definition powers both agent tools and UI

Builder.io 开源 TypeScript Agent 框架 Agent-Native，核心理念是「一次定义，两处复用」——每个能力以 Action 形式声明后，Agent 可将其作为工具调用，UI 代码也可直接调用，无需重复实现。解决了 Agentic 应用中 Agent 逻辑和前端逻辑割裂的痛点，适合想快速搭建既有自主能力又有操作界面的产品团队。

- **EN**：Builder.io open-sourced Agent-Native, a TypeScript framework where each capability is defined once as an action — the agent uses it as a tool, and the UI calls it from code. This eliminates the split between agent logic and frontend logic, making it easier to ship agentic apps with purpose-built interfaces without duplicating implementation.

### SiliconBench：首个专为 Apple Silicon 本地 LLM 推理设计的综合评测框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.19169
- **TitleEN**：SiliconBench benchmarks local LLM serving on Apple Silicon across speed, memory, and fidelity

现有本地 LLM 跑分几乎只看速度，SiliconBench 填补了这个空白：同时评估速度、内存占用和输出保真度三个维度，测试了 9 个 Apple Silicon 推理引擎在 Qwen3、Qwen3.5、Gemma 4 上的表现。对在 Mac 上跑本地模型的开发者极有参考价值——帮你判断哪个引擎在不牺牲质量的前提下用最少内存跑最快。

- **EN**：SiliconBench evaluates nine Apple Silicon LLM serving engines across speed, memory, and fidelity — dimensions that speed-only rankings miss. Tested on Qwen3, Qwen3.5, and Gemma 4, it's the first benchmark designed for developers running local models on Mac who need to balance performance without quality regression.

### APort Vault：首个针对 AI Agent 支付授权安全的攻击回放基准测试

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.22076
- **TitleEN**：APort Vault benchmarks AI agent payment security with 4,371 real attack replays

随着 AI Agent 开始真正触碰支付流程，安全问题变得非常紧迫。APort Vault 用来自公开 CTF 竞赛的 4,371 条真实人工攻击，对 8 家实验室的 14 个模型进行了支付授权安全评测，共完成 225,964 次评估。这是目前最接近真实攻击场景的 Agent 支付安全基准，对所有做支付相关 Agent 的开发者都应该是必读参考。

- **EN**：APort Vault replays 4,371 real human-written attacks from a public CTF event against a live payment agent, testing 14 models from 8 labs across five policy configs — totaling 225,964 evaluations. The most realistic benchmark yet for AI agent payment security, essential reading for any developer building agents that touch financial transactions.

### BI-Agent + BI-Bench：让 LLM 端到端自动完成商业智能分析全流程

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.20886
- **TitleEN**：BI-Agent and BI-Bench aim to fully automate end-to-end business intelligence workflows

传统 BI 分析需要识别相关表、数据转换、建立关联关系再回答业务问题，流程繁琐。这篇论文提出 BI-Agent 框架与配套基准 BI-Bench，让 LLM 自动完成从原始数据到业务洞察的完整链路。对做企业数据产品的独立开发者而言，这意味着「自然语言问 → 自动出图表」的路径技术可行性进一步验证。

- **EN**：BI-Agent automates the full BI workflow — table identification, data transformation, join relationships, and question answering — that previously required manual analyst work in tools like Power BI or Tableau. BI-Bench provides standardized evaluation. For developers building enterprise data products, this validates the technical feasibility of fully automated natural-language-to-insight pipelines.
