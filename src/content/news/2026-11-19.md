### 阿里开源代码审查结合规则与智能体

- **板块**：AI 工具动态
- **来源**：GitHub Trending
- **链接**：https://github.com/alibaba/open-code-review
- **TitleEN**：Alibaba Combines Deterministic Rules and Agents for Code Review

阿里 OpenCodeReview 将确定性流水线与 LLM Agent 结合，提供行级审查意见，并内置空指针、线程安全、XSS 和 SQL 注入等规则。工具兼容 OpenAI 与 Anthropic 接口，方便团队接入已有模型服务。

### 新基准评测大模型直接改写神经网络

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.18553
- **TitleEN**：WeightBench Tests Language Models as Neural Network Editors

WeightBench 用42项任务评测大模型直接读取、修复或生成其他神经网络参数的能力，而非依赖梯度训练。对开发者，它提供了检验“让模型修改模型”的统一方法，但不能据此认定传统训练已可被替代。

- **EN**：WeightBench introduces 42 tasks for evaluating whether language models can read, repair, or write other neural networks directly through their parameters, without gradient descent. For developers, it provides a structured way to test model-editing capabilities beyond ordinary code generation. The benchmark investigates an emerging approach; it does not establish that conventional training can broadly be replaced.

### 开源智能体本地重建可编辑CAD模型

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.22563
- **TitleEN**：CADMAGEDDON Reconstructs Editable CAD With Local Inference

CADMAGEDDON 是将网格重建为可编辑 CAD 的开源 Agent，可在单 GPU 系统和新一代笔记本本地运行。它把重建拆成连续的简单视觉决策，让小团队有机会在不上传专有零件数据的情况下完成模型转换。

- **EN**：CADMAGEDDON is an open-source agent that reconstructs editable CAD from meshes and can run locally on single-GPU systems and current-generation laptops. It breaks reconstruction into a sequence of simpler visual decisions. For developers building engineering tools, the practical appeal is supporting proprietary part workflows without requiring customers to send their geometry to external services.
