### Claude Fable 5.1 发布：新 SOTA 模型，缓存降价 75% 但输出贵 70%

- **板块**：AI 工具动态
- **来源**：Product Hunt AI / Latent Space
- **链接**：https://www.latent.space/p/ainews-claude-fable-mythos-51
- **TitleEN**：Claude Fable 5.1: New SOTA with 75% Cache Cut, 70% Output Price Hike

Anthropic 发布 Claude Fable 5.1，刷新多项基准测试。缓存价格暴降 75% 对大量 context 场景友好，但输出 token 涨价 70%——这意味着长输出场景（代码生成、长文写作）的成本会明显上升。开发者需要重新算账。

- **EN**：Anthropic releases Claude Fable 5.1, a new SOTA model. Cache pricing drops 75% (great for context-heavy workloads), but output tokens cost 70% more — meaning code generation and long-form writing get pricier. Developers need to recalculate their API budgets.
