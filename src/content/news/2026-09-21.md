### cua 开源：给 AI Agent 一台真正可用的电脑

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/trycua/cua
- **TitleEN**：cua: Open-Source Computer-Use Infrastructure for AI Agents

cua 提供开源桌面自动化驱动、隔离云端桌面、本地 macOS 虚拟机及专项决策模型，支持跨 OS Agent 集群（Fleet）规模化部署，并内置 benchmark 用于训练/评测/数据生成。对需要让 Agent 操控真实 GUI 的开发者来说，这是目前覆盖最全的基础设施方案。

- **EN**：cua offers open-source desktop automation drivers, isolated cloud desktops, local macOS VMs, and specialist models for computer-use agents. It supports cross-OS fleets and built-in benchmarks for training and evaluation—arguably the most complete infrastructure stack for developers building GUI-operating agents today.

It offers a more secure, enterprise-grade sandbox than raw API calls for teams deploying coding agents at scale.

### MiniMax-H3 全模态评测：多模态对齐能否提升物理世界推理？

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.18323
- **TitleEN**：MiniMax-H3 Evaluated: Does Omni-Modal Alignment Improve Physical Reasoning?

研究者系统评测了 MiniMax-H3 这一「全模态」生成模型——它在统一框架内处理文本、图像、视频、音频的理解与生成。核心问题：多模态对齐真的能让模型更好地推理物理世界吗？对开发者的启示：这是目前少有的针对全模态架构进行系统 benchmark 的工作，结论将影响多模态 Agent 的架构选择。

- **EN**：Researchers benchmark MiniMax-H3, an omni-modal model that unifies text, image, video, and audio understanding and generation in a shared latent space. The key question: does multimodal alignment actually improve physical-world reasoning? For developers building multimodal agents, this is one of the first rigorous benchmarks of a fully unified omni-modal architecture.

### FAMOS：只需稀疏视角，就能重建铰接物体的 3D 运动结构

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.20817
- **TitleEN**：FAMOS: 3D Articulated Object Modeling from Just a Few Sparse Views

FAMOS 提出从少量无序单目点云同时预测可动部件分割与关节参数，无需依赖单类别形状先验。对机器人、具身 AI 和 3D 内容生成开发者而言：这意味着在真实场景中用几张图就能建出「可操控」的 3D 物体模型，大幅降低机械臂训练和游戏资产制作的数据门槛。

- **EN**：FAMOS predicts movable-part segmentation and joint parameters from a sparse set of unordered monocular point clouds, eliminating reliance on category-level shape priors. For robotics, embodied AI, and 3D content developers, this means building manipulable 3D object models from just a handful of images—dramatically lowering the data barrier for robot training and game asset creation.
