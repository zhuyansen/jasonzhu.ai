### 新论文 SEAD：从「状态」视角重新理解 Agent 攻防

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.34518
- **TitleEN**：SEAD Paper: A State-Based Framework for Agent Attacks and Defense

研究提出 SEAD 框架，指出工具调用 Agent 的风险本质是「部分可观测的状态控制」——早期操作可能悄悄改变文件、权限等状态，导致后续看似正常的操作变得危险。这为设计更安全的 Agent 权限系统提供了理论依据，呼应了近期 Claude Code 误删文件事件引发的担忧。

- **EN**：A new SEAD framework reframes tool-using agent security as "partially observed state control"—earlier actions can silently alter files or permissions, making later routine-looking actions dangerous. This offers a theoretical basis for safer agent permission systems, echoing recent concerns after Claude Code's mass file-deletion incident.
