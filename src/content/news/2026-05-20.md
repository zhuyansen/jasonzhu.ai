### OSCAR 论文：2-bit KV Cache 量化新方案，长上下文推理成本有望大幅压缩

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.17757
- **TitleEN**：OSCAR Paper Compresses KV Cache to 2-Bit Without Accuracy Loss

为什么对开发者重要：跑长上下文 LLM 最贵的不是算力而是 KV Cache 内存。OSCAR 提出一种「离线估算注意力感知协方差结构」的方法，把 KV Cache 压缩到 2-bit 还不掉精度——相当于同样的显存能塞进 4 倍更长的上下文。对本地部署和 API 成本敏感的开发者是重大利好。

- **EN**：Running long-context LLMs is expensive mainly due to KV Cache memory, not compute. OSCAR proposes an offline attention-aware covariance estimation method that compresses KV Cache to 2-bit while preserving accuracy — effectively quadrupling the context length fitting in the same memory. A significant win for local deployment and cost-sensitive API users.
