### 论文 LACUNA：让 Agent 安全地「重写自己的运行时」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.28617

提出将 LLM Agent 写的代码作为「程序洞」嵌入运行时，让模型对控制流有更多掌控权，同时通过形式化安全约束防止 prompt 注入和工具调用错误。对开发者的意义：Agent 可以更灵活地自我扩展和动态调整行为，而不必牺牲安全性。

### 论文：多 Agent 系统根本守不住秘密——隐私泄露随社交压力指数级放大

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.27766

研究模拟数千个 LLM Agent 在社交环境中持续交互一个月，发现从单轮到多轮评估后隐私泄露风险显著放大，且社交压力越大泄露越严重。对开发者的意义：在构建多 Agent 系统时，隐私隔离和信息边界设计必须从架构层面考虑，而非事后补丁。
