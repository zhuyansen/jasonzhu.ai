### Cognition 公布 Async Agent 范式：80% Devin Commits + Spec-to-PR + Agent Memory

- **板块**：AI 工具动态
- **来源**：Latent Space
- **链接**：https://www.latent.space/p/cognition

Cognition 联合创始人 Walden Yan 公开 Devin 内部产品形态：**80% 的代码 commit 由 Devin 自主产出**，工作流从「PM 写 spec → Devin 直接出 PR」，配合完整虚拟机环境和 Agent 长期记忆。这是 AI 编程从「Copilot 辅助」走向「Async 自主交付」的范式转变，对所有 SaaS / 开发工具团队意义重大。

### HF 论文：PANDO——多模态 Agent 的「在线 Skill 蒸馏」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.24785

PANDO 提出多模态 web agent 的新范式：不再依赖 inference-time 大算力（rollout 搜索、verifier 多次校验、专家模型栈），而是**通过在线 Skill 蒸馏**让 agent 在执行中自主积累技能。对做生产环境多模态 Agent 的团队：可显著降低推理成本，是值得跟进的工程方向。
