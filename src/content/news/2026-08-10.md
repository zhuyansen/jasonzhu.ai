DataSpace 提出了一个全新基准，测试 AI Agent 能否同时查询数据库、结构化文件、长文档和多媒体等混合数据源，并输出可验证的表格结果。对开发者意义在于：现有 Agent 在「真实企业级数据混沌环境」中的能力远比单一数据源测试结果弱得多，值得重视。

### Code-Graph-RAG：用知识图谱让 AI 真正读懂你的大型代码仓库

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/vitali87/code-graph-rag
- **TitleEN**：Code-Graph-RAG: Knowledge Graph-Powered RAG for Large Monorepos

Code-Graph-RAG 用 Tree-sitter 解析多语言代码库，在 Memgraph 中构建结构化知识图谱，让 AI 能真正理解和编辑复杂 monorepo 的代码结构。与传统向量 RAG 相比，图结构保留了函数调用链和模块依赖关系，对大型项目尤为实用。

- **EN**：Code-Graph-RAG uses Tree-sitter to parse multi-language codebases and builds a Memgraph knowledge graph of code structure. Unlike vector RAG, it preserves function call chains and module dependencies — making it dramatically more effective for querying and editing large monorepos with AI.
