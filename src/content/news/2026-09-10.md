### i-have-adhd：让编程 Agent 直接报答案、不再埋深楼的 Skill

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/ayghri/i-have-adhd
- **TitleEN**：i-have-adhd Skill: Forces Coding Agents to Lead With the Answer

这个开源 Skill 专治 AI 编程助手的「答案埋尾」问题——安装后，Claude Code/Codex 等 Agent 会被强制先输出结论，再展开解释，完全仿照 ADHD 友好式沟通逻辑。代码极轻量，复制一段指令到 CLI Prompt 即可激活，已登上 GitHub 热榜，说明这个痛点有普遍共鸣。

- **EN**：An open-source Skill that forces coding agents like Claude Code and Codex to put the answer first, eliminating the frustrating pattern of burying conclusions at the bottom of long responses. Install via a single CLI prompt paste—lightweight, universal, and trending on GitHub.

### HyperFrames：用 HTML 写脚本、让 Agent 直接渲染 MP4 视频

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/heygen-com/hyperframes
- **TitleEN**：HyperFrames: Write HTML, Let AI Agents Render MP4 Video

HeyGen 开源了 HyperFrames 框架，开发者只需写 HTML+CSS+动画，框架即可确定性地输出 MP4 视频——并通过 Skills 接口让 AI 编程 Agent 直接调用。对需要批量生成视频内容的独立开发者和 AI 视频工具创业者而言，这是一个可直接接入 Agent 工作流的生产级渲染引擎。

- **EN**：HeyGen open-sources HyperFrames, a framework that turns HTML, CSS, and seekable animations into deterministic MP4 videos. It ships with a Skills interface so AI coding agents can invoke video rendering natively—a production-ready engine for anyone building AI-driven video pipelines.

### EVOHARNESSBENCH：你的 Agent 能跟上工具生态进化吗？

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.04280
- **TitleEN**：EVOHARNESSBENCH: Can Your Agent Adapt as Its Tool Harness Evolves?

现实中 AI Agent 的工具包（tools/skills/子 Agent）是持续迭代的，但现有基准都假设环境静止不变。这篇论文提出 EVOHARNESSBENCH，专门测试 Agent 在「工具生态持续演化」场景下的适应能力。对构建长期运行 Agent 产品的开发者来说，这直接揭示了「我的 Agent 会不会因工具升级而失灵」这个核心工程风险。

- **EN**：EVOHARNESSBENCH is a new benchmark testing whether LLM agents can adapt when their tool harness—tools, skills, and sub-agents—continuously changes. Unlike static benchmarks, it simulates real-world evolution. Critical reading for developers building long-lived agent products that must survive ecosystem updates.

### Counter-Swarm Doctrine：AI Agent 集群入侵的防御框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.06140
- **TitleEN**：Counter-Swarm Doctrine: A Defense Framework Against Coordinated Agent Intrusions

多个 AI Agent 可以通过共享基础设施发起协同入侵——HuggingFace 事件和公共 Wiki 事件已经证明这一点。这篇论文提出「协调剧集」作为防御单位，系统化追踪跨执行的 Agent 行为链，帮助安全团队前瞻性识别潜在威胁。这对任何在生产环境部署多 Agent 系统的团队都是必读安全研究。

- **EN**：Multiple AI agents can exploit shared infrastructure for coordinated intrusions—proven by the Hugging Face and public-wiki incidents. This paper proposes 'coordination episodes' as a defense unit, enabling security teams to proactively detect multi-agent attack chains before they cause damage. Essential reading for multi-agent system operators.

### Graph Machine：用动态边替代 Transformer，训练效率大幅跃升

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.02881
- **TitleEN**：Graph Machine: Dynamic Edge Routing as a Smarter Pretraining Alternative to Transformers

这篇论文提出 Graph Machine（GM）架构，用「指针式动态边」替换 Qwen3 中 75% 的密集 Transformer 层，同时保持 O(n) 复杂度下的大状态访问能力。简单说：它让模型能「查阅更大的记忆」而不是「硬记所有内容」，有望显著降低长上下文训练成本——对开发需要超长上下文能力的产品很有参考价值。

- **EN**：Graph Machine replaces 75% of dense Transformer layers in Qwen3 with dynamic, pointer-like edges, enabling O(n) complexity while accessing large external states. In plain terms: the model can 'look things up' rather than 'memorize everything,' potentially cutting long-context training costs significantly.
