### Activity Frames：让 Agent 记住「用户做了什么」而非只记「用户说了什么」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.05784
- **TitleEN**：Activity Frames: Agents That Remember What You Did, Not Just What You Said

论文提出一套无需模型参与的确定性管道，将被动捕获的屏幕活动编译成结构化「活动帧」记忆，让 Agent 记录用户真实操作行为而非仅对话内容。对开发者的意义：这意味着 Agent 不再需要每次重新推理用户已做过的操作，显著降低推理成本，是 Agent 长期记忆架构的重要方向。

- **EN**：This paper compiles passively captured screen activity into structured 'activity frames' using a zero-model deterministic pipeline, giving agents memory of what users actually did — not just said. For developers: agents stop re-deriving routines already performed, dramatically cutting inference costs for long-running automation.

### 机器人学习大综述：冻结权重 vs. 自写技能代码，两条路谁能走远？

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.01851
- **TitleEN**：Survey: Frozen-Weight Robot Policies vs. Agents That Write Their Own Skills

HuggingFace 推送的综述论文系统梳理了机器人学习的两条主线：将能力烧进权重的 VLA 模型 vs. 让 Agent 自己写并迭代可执行技能代码。论文重点深挖「代码即策略」方法按自我改进程度的分级，从零样本程序合成到闭环自修复再到持久技能记忆。对 AI Agent 开发者而言，这张全景图直接对应 Skills 生态当下的核心分歧。

- **EN**：A comprehensive survey organizing robot learning around the 'weights vs. skills' axis — VLA models that bake competence into frozen weights versus agents that write and refine executable skill code. The deep-dive on self-improvement degrees maps directly onto the current debate in the AI coding agent ecosystem.

### KVAE：音频、图像、视频三模态统一 Tokenizer 家族开源发布

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.05798
- **TitleEN**：KVAE: A Unified Tokenizer Family for Audio, Image, and Video Generation

KVAE 发布了一套覆盖音频（48kHz 全频带）、图像和视频的连续 Tokenizer 系列，专为后续文本条件生成任务设计。Tokenizer 质量直接影响多模态模型的学习速度和生成质量，这套统一架构对构建多模态生成应用的开发者而言是值得跟进的底层基础设施更新。

- **EN**：KVAE introduces a unified family of continuous tokenizers covering audio (48kHz full-band), images, and video, all designed for text-conditioned generation. Since tokenizer quality directly determines learning speed and output quality in multimodal models, this is a meaningful infrastructure update for multimodal app developers.
