### SkillGate：解决 Agent 长任务中「选哪个技能」的信用分配难题

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.18852
- **TitleEN**：SkillGate: Training Agents to Select the Right Skill Mid-Episode

随着 Agent 框架积累了数千个 Skill 文件，「该读哪个 Skill」本身成了决策难点。SkillGate 论文发现：现有强化学习方法因「选择器信用饥饿」问题根本学不会技能选择，并提出了针对性训练信号。对构建长任务 Agent（如 Claude Code 工作流）的开发者，这直接影响 Skills 库的实用性上限。

- **EN**：As skill libraries grow to thousands of files, choosing the right skill mid-task becomes a bottleneck. SkillGate identifies why standard RL fails at skill selection (a structural flaw called 'selector credit starvation') and proposes a fix. Directly relevant to developers building long-horizon agents like Claude Code workflows.

### Bounded Agents：多 Agent 系统中的委托安全边界论文

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.15888
- **TitleEN**：Bounded Agents: Delegation Security Framework for Multi-Agent AI Systems

该论文提出 LLM Agent 在委托任务给子 Agent 时存在权限过度传递的安全漏洞——即使每个操作单独合规，组合起来可能违规，且 prompt 注入风险随权限边界模糊而放大。对所有构建多 Agent 系统的开发者，这是目前关于 Agent 授权安全最系统的理论框架之一。

- **EN**：This paper formalizes delegation security risks in multi-agent LLM systems: agents can combine individually-permitted actions into prohibited outcomes and over-delegate authority to sub-agents. For developers building multi-agent pipelines, this provides the most systematic security framework yet for agent permission design.
