### Hindsight：让 Agent 真正「学习」而不只是「记忆」的开源记忆系统

- **板块**：AI 工具动态
- **来源**：GitHub Trending
- **链接**：https://github.com/vectorize-io/hindsight
- **TitleEN**：Hindsight: Open-Source Agent Memory That Learns, Not Just Remembers

Vectorize 开源 Hindsight，一个专为 Agent 设计的「会学习」的记忆系统。区别于传统 Agent 记忆方案只检索对话历史，Hindsight 让 Agent 从交互中提炼经验、持续改进行为。已提供论文、Benchmark 和云端版本，对构建长期自主 Agent 的开发者有较高参考价值。

- **EN**：Vectorize open-sourced Hindsight, an agent memory system focused on learning from interactions rather than just recalling history. Unlike RAG-based memory or sliding-window approaches, Hindsight extracts and applies lessons over time — making agents progressively smarter. Comes with benchmarks, a paper, and a cloud offering.

### LLM 可自动发现「有趣数学定理」：AI 的数学能力从解题迈向创造

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.28603
- **TitleEN**：LLMs Learn to Discover Mathematically Interesting Theorems, Not Just Solve Them

这篇论文探讨 LLM 能否自主发现「有趣」的数学定理，而非仅仅证明已有命题。研究者定义了「内在趣味性」指标（证明长度与定理长度之比），并训练模型主动探索数学知识空间。对开发者的意义：AI 可能开始在科学发现领域扮演主动创造者角色，而非单纯的工具。

- **EN**：Researchers trained LLMs to discover mathematically interesting theorems — not just prove them. They define 'intrinsic interestingness' as the ratio of proof length to theorem length, then optimize for it. For developers, this signals AI moving from problem-solver to active knowledge creator in scientific domains.

### AV-GRPO 论文：强化学习解决音视频联合生成的跨模态同步难题

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.29816
- **TitleEN**：AV-GRPO: RL-Based Training Fixes Cross-Modal Sync in Joint Audio-Video Generation

联合生成音频+视频的模型长期存在两个痛点：单模态质量不够高、音画同步效果差。AV-GRPO 用强化学习后训练解决这个问题，通过「模态锚定解耦扩散」分开优化音频和视频的奖励信号。对做视频生成、虚拟人或多模态内容产品的开发者有直接参考价值。

- **EN**：AV-GRPO applies reinforcement learning post-training to joint audio-video generation, using modality-anchored decoupled diffusion to separately optimize audio and video reward signals. This directly addresses poor per-modality fidelity and weak audio-visual sync — critical pain points for developers building video generation or avatar products.
