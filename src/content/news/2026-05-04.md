### FlashRT：长上下文 LLM 的提示注入与知识污染安全测试新框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2604.28157
- **TitleEN**：FlashRT: Security Testing for Prompt Injection and Knowledge Corruption in Long-Context LLMs

针对 Gemini、Qwen 等长上下文模型在 RAG 和 Agent 场景下的安全漏洞，研究者提出 FlashRT 框架，专门高效测试提示注入和知识污染攻击。对开发者的意义：你部署的 RAG 应用可能比你想象的更脆弱，这套工具可以帮你在上线前量化风险。

- **EN**：Researchers have introduced FlashRT, a framework for efficiently testing prompt injection and knowledge corruption attacks. It targets security vulnerabilities in long-context models like Gemini and Qwen when used in RAG and agent settings. For developers, the takeaway is that your RAG application may be more vulnerable than you think, and FlashRT can help you quantify that risk before launch.
