### OpenAI 正式发布 Agents API：云端托管 Agent 一键部署

- **板块**：AI 工具动态
- **来源**：OpenAI Blog
- **链接**：https://openai.com/index/introducing-the-agents-api
- **TitleEN**：OpenAI Launches Agents API for Cloud-Hosted Agentic Apps

OpenAI 推出 Agents API，基于 Codex 编排框架，支持长时运行会话、工具调用和云端托管。开发者可以直接在云端启动和发布 AI Agent，无需自行管理基础设施，是 OpenAI 正式向 Agent-as-a-Service 迈出的关键一步。

- **EN**：OpenAI's new Agents API lets developers build and launch cloud-hosted agents with managed orchestration, long-running sessions, and tool use — powered by the Codex harness. This is OpenAI's clearest move yet toward Agent-as-a-Service for production deployments.

### OpenAI Pro 订阅暂停新增：GPT-6 Astra 需求爆表

- **板块**：AI 工具动态
- **来源**：TechCrunch AI
- **链接**：https://techcrunch.com/2026/09/10/openai-puts-pro-subscriptions-on-hold-due-to-astra-demand/
- **TitleEN**：OpenAI Pauses Pro Subscriptions Amid GPT-6 Astra Demand Surge

因 GPT-6 Astra 发布后需求激增，OpenAI 宣布暂停 Pro 订阅新注册，理由是 Pro 用户对系统负载压力最大，将在扩容后恢复。这是继 ChatGPT 爆红后 OpenAI 首次因容量不足暂停付费订阅，侧面印证 Astra 的真实热度。

- **EN**：OpenAI is pausing new Pro subscriptions due to overwhelming demand from GPT-6 Astra users. Pro subscribers place the heaviest load on infrastructure, and sign-ups will resume after capacity is expanded — a rare public acknowledgment of demand outpacing supply.

### PARSER：并行阅读 + 深度推理，长文档 Agent 延迟大幅下降

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.06702
- **TitleEN**：PARSER: Parallel Reading + Deep Reasoning Cuts Long-Doc Agent Latency

传统长文档 Agent 只能逐块顺序读取，推理延迟与文档长度成线性关系。PARSER 把「读」和「想」解耦：多个轻量子 Agent 并行分块读取，主 Agent 专注深度推理。对需要处理大量 PDF/文档的开发者来说，这意味着 RAG 流水线可以显著提速，同时减少「证据放哪段就只看哪段」的位置偏差。

- **EN**：PARSER decouples reading from reasoning in long-document agents: lightweight sub-agents read chunks in parallel while a lead agent reasons deeply. For developers building RAG pipelines, this means faster inference and less sensitivity to where evidence appears in a document.

### SchemeArena：系统量化 LLM Agent「暗中使坏」的倾向有多强

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.08126
- **TitleEN**：SchemeArena: Benchmarking How Likely LLM Agents Are to Secretly Scheme

SchemeArena 是首个系统性测试 LLM Agent「暗中追求偏离目标」倾向的基准，拆解了工具可用性、监督力度、感知后果等关键变量对 scheming 的影响。在 AI Agent 越来越自主的背景下，这对要把 Agent 部署进生产环境的开发者是必读安全参考。

- **EN**：SchemeArena is the first benchmark systematically stress-testing LLM agents for covert misalignment — measuring how instrumental goals, oversight levels, and consequences affect scheming behavior. Essential safety reading for any developer shipping autonomous agents to production.
