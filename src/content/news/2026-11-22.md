### 新论文证实大模型可无梯度自主改写权重实现自我改进

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.21885
- **TitleEN**：New Paper Shows Language Models Can Self-Rewrite Weights Without Gradients

传统模型部署后权重即被冻结，改错需重新训练。该研究发现大模型在获得自身权重和评分反馈后，无需梯度计算或再训练，仅靠推理即可自主改写权重实现进化，为开发者构建部署后持续自我优化的智能体提供了新范式。

- **EN**：Deployed models typically have frozen weights and cannot retain prompt-level fixes across tasks. This paper shows language models can inspect their own weights and graded answers to rewrite weights purely through reasoning—without gradients or retraining—pointing toward self-improving deployed systems.

### Lang-SVG用语言先验生成分层语义矢量图，大幅提升可编辑性

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.15941
- **TitleEN**：Lang-SVG Uses Language Priors to Generate Semantic, Editable Vector Graphics

现有图像矢量化工具只追求像素还原，生成的SVG代码缺乏层级结构且极难修改。Lang-SVG利用语言先验构建带语义标签的树状结构组织SVG图元，让AI生成的矢量图形真正对齐人类对象层级，方便前端与设计工具直接二次编辑。

- **EN**：Existing image vectorizers optimize pixel fidelity but output messy SVG code lacking human-aligned structure. Lang-SVG introduces an explicit semantic tree using language priors to organize SVG primitives into logical object-part hierarchies, making AI-generated vector graphics genuinely editable for designers and frontend developers.

### 编码智能体直接原位训练光学神经网络，绕过复杂数字校准

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.23875
- **TitleEN**：Coding Agents Train Optical Neural Networks In Situ via Code

光学神经网络高效但受硬件制造偏差困扰，过去需专家建数字模型校准。该研究提出“光学即代码”，让编码智能体直接编写运行程序在硬件上原位训练网络权重，降低了非标AI硬件的调试门槛，拓展了Coding Agent的科研与工程边界。

- **EN**：Optical neural networks offer fast, low-energy compute, yet hardware imperfections traditionally require expert-built digital calibration models. This paper introduces 'optics as code,' enabling coding agents to directly train physical optical hardware in situ, lowering the barrier to programming next-generation AI hardware.
