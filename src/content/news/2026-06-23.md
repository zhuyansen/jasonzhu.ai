### Headroom：MCP 兼容压缩层，让 Agent 上下文 token 缩减 60-95%

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/chopratejas/headroom
- **TitleEN**：Headroom: MCP-Compatible Token Compression Cuts Agent Context by 60–95%

Headroom 是一个开源工具，在工具输出、日志、RAG 片段到达 LLM 之前先进行压缩，支持 6 种算法，可做库、代理或 MCP Server 部署，token 削减幅度达 60-95% 且答案质量不变。对于 Agent 流程成本高企的开发者来说，这是一个非常实用的降本利器。

- **EN**：Headroom compresses tool outputs, logs, RAG chunks, and files before they reach the LLM — achieving 60–95% token reduction with no quality loss. It ships as a library, proxy, or MCP server with 6 compression algorithms, making it a practical cost-cutting layer for any agent pipeline.

### SproutRAG：注意力引导树搜索，长文档 RAG 检索精度显著提升

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.18381
- **TitleEN**：SproutRAG: Attention-Guided Hierarchical RAG for Long Documents

SproutRAG 提出一种「注意力引导树搜索 + 渐进式嵌入」的 RAG 架构，解决长文档检索中粒度与上下文连贯性的两难困境。对开发者的意义：无需在索引期大量调用 LLM，也不损失跨段落语义，是构建长文档问答/研究助手时值得替换现有 RAG 方案的新选择。

- **EN**：SproutRAG introduces attention-guided tree search with progressive embeddings to solve the granularity-coherence tradeoff in long-document RAG. For developers: it avoids costly LLM calls during indexing, preserves cross-paragraph semantics, and outperforms single-level RAG — a practical upgrade for research assistants and document QA systems.
