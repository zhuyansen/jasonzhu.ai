### Gemini API 新增 Webhook 推送：告别轮询等待长任务

- **板块**：AI 工具动态
- **来源**：Google AI Blog
- **链接**：https://blog.google/innovation-and-ai/technology/developers-tools/event-driven-webhooks/
- **TitleEN**：Gemini API Adds Webhooks, Ending Polling for Long-Running Tasks

Gemini API 上线事件驱动 Webhook，长任务完成后主动推送通知，不再需要开发者反复轮询接口。对于需要跑批量推理、长文档处理的开发者来说，这直接降低了延迟和无效请求成本，工程体验大幅提升。

- **EN**：The Gemini API now supports event-driven webhooks that push a notification when a long-running task completes, so developers no longer need to repeatedly poll the endpoint. For teams running batch inference or long-document processing, this directly cuts latency and the cost of wasted requests, a major improvement to the developer experience.

### Odysseus：用强化学习让视觉语言模型打通关游戏，决策能力突破 100 轮

- **来源**：HuggingFace Papers
