### MemHub：让 AI 编程 Agent 共享持久记忆的开源方案

- **板块**：Skills 生态
- **来源**：Hacker News
- **链接**：https://news.ycombinator.com/item?id=memhub-persistent-shared-memory
- **TitleEN**：MemHub: Persistent Shared Memory for AI Coding Agents

MemHub 是一个开源工具，为 AI 编程 Agent（如 Claude Code、Cursor）提供持久化的共享内存。多个 Agent 可以读写同一套上下文，避免重复理解代码库。对多 Agent 协作开发场景来说，这可能是 context 管理的关键基础设施。

- **EN**：MemHub is an open-source tool providing persistent shared memory for AI coding agents like Claude Code and Cursor. Multiple agents can read/write shared context, avoiding redundant codebase understanding. A potential key infrastructure piece for multi-agent development.
