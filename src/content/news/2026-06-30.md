### 静态代码结构分析能让 AI Agent 更稳定吗？新研究给出肯定答案

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.26979
- **TitleEN**：Static Code Anchors Make AI Coding Agents More Stable and Reproducible

研究发现，AI 编程 Agent 在仓库中导航时高度依赖关键词搜索，却忽视调用图、继承层级等结构关系，导致每次运行结果不一致。论文提出用轻量级静态分析注入「确定性锚点」（plain-text 注释形式），让 Agent 行为更可预测、可复现。对构建生产级代码 Agent 的开发者来说极具实用价值。

- **EN**：LLM-based code agents navigate repos via keyword search but miss structural relationships like call graphs and inheritance hierarchies, making their behavior non-reproducible. This paper shows that injecting lightweight static analysis as plain-text 'deterministic anchors' significantly stabilizes agent navigation — highly practical for production-grade coding agents.

### Qwen 机器人操控基础模型：对齐技术让规模定律在机器人领域成立

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.17846
- **TitleEN**：Qwen-RobotManip: Alignment Unlocks Scaling Laws for Robotic Foundation Models

阿里 Qwen 团队发布机器人操控基础模型技术报告，核心发现是：通过统一数据格式对齐异构机器人数据，规模定律（scale）可以在机器人操控领域真正生效。这意味着「大力出奇迹」的 LLM 成功路径有望复制到具身智能，对机器人创业者和研究者均有重要参考意义。

- **EN**：Alibaba's Qwen team shows that aligning heterogeneous robotic manipulation data under a unified formulation allows scaling laws to work in robotics — mirroring how LLMs achieved generalization. This is a strong signal that the 'scale up' playbook from language models may finally transfer to embodied AI.
