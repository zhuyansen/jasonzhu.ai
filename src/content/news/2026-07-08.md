### Claude Cowork扩展至手机和网页端，编码Agent走出IDE

- **板块**：AI 工具动态
- **来源**：TechCrunch AI
- **链接**：https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/
- **TitleEN**：Claude Cowork Expands to Mobile and Web

Anthropic将Claude Cowork从桌面端扩展到移动和网页端，用户可从电脑启动任务、手机查看进度、笔记本合盖后继续运行。编码Agent正式走出IDE，开始覆盖整个办公场景，这标志着Agent从开发工具向通用工作助手的关键转型。

- **EN**：Anthropic expands Claude Cowork to mobile and web, letting users start tasks on desktop, track progress on phones, and pick up results later — even with laptops closed. This marks coding agents moving beyond IDEs into general office workflows.

- **板块**：Skills 生态
- **来源**：Google AI Blog
- **链接**：https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api/
- **TitleEN**：Gemini API Adds Background Agents and Remote MCP

Google为Gemini API的Managed Agents新增后台任务执行和远程MCP支持等能力，帮助开发者构建生产级Agent应用。远程MCP意味着Gemini Agent可直接调用外部工具链，与Claude Code的MCP生态形成正面竞争，MCP正在成为Agent互操作的事实标准。

- **EN**：Google adds background tasks, remote MCP, and more to Gemini API's Managed Agents. Remote MCP support means Gemini agents can now tap external tool chains, directly competing with Claude Code's MCP ecosystem and further cementing MCP as the de facto agent interop standard.
