### Google 官方发布 Skills 仓库，Gemini API 技能一键接入 Agent

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/google/skills
- **TitleEN**：Google Ships Official Skills Repo: Plug Gemini API Skills into Any Agent

Google 正式开源 Agent Skills 仓库，覆盖 Gemini API、Gemini Interactions API 及 Managed Agents 等能力，开发者只需 `npx skills add google/skills` 即可将 Google 全家桶接入自己的 Agent 工作流。这是继 Anthropic Skills 生态之后，Google 正式入场争夺 Agent 技能标准话语权的信号。

- **EN**：Google released an official Skills repository on GitHub, letting developers plug Gemini API skills directly into agents. The agent-skills ecosystem standard is now contested by multiple giants rather than Anthropic alone — a signal worth watching for anyone building agent tooling.

### HF 论文：SCOUT 框架——用「侦察员预判」动态分配 Prompt 注入检测器，防御效率大幅提升

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.30837

现有 Prompt 注入防御通常绑定单一检测器，存在盲区。SCOUT 框架的思路是：先用轻量模型「侦察」每个请求的风险特征，再动态决定派哪个检测器上阵甚至升级 LLM 裁判。对构建生产级 Agent 安全层的开发者来说，这种按需分配的防御架构比一刀切方案更实用。
