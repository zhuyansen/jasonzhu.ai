### Hermes Agent 开源：自我进化的 Agent，技能越用越强

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/NousResearch/hermes-agent

Nous Research 推出 Hermes Agent，内置「学习闭环」——每次对话后自动创建并优化 Skill，跨会话搜索历史记忆，逐步构建用户画像。可运行在 $5/月 VPS 或 Serverless 环境，是目前开源 Agent 中「持续自我改进」设计最完整的实现之一。

### HF 论文：只需少量样本，CORE 让模型推理能力快速跃升

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.28742

CORE（对比反思算法）让模型比较自己过去的推理过程，找出对错差异后快速修正——不需要 RLVR 那样的大规模训练，用极少样本就能在推理任务上显著提升。对独立开发者意义：微调成本可能大幅下降，小数据集也能训出强推理模型。

### HF 论文：IPT 让视觉语言模型真正「脑补」看不见的空间

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.03988

研究引入「想象感知 Token（IPT）」，让 VLM 在推理时生成虚拟视角的中间表示，解决遮挡、跨视角等空间推理难题。对开发者的意义：机器人导航、AR 场景理解、3D 应用中 VLM 的空间能力有望直接提升，无需更换底座模型。

### HF 论文：3.5 万条 GitHub 注释揭示开发者如何真实使用 AI 写代码

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.06843

研究分析了 35,361 条明确标注 AI 使用的 GitHub 代码注释，构建出首个「AI 辅助开发行为分类体系」，揭示开发者如何修改、适配 AI 生成代码。结论是：AI 输出普遍被二次改造，而非直接使用——为 Copilot/Claude Code 等工具的下一步优化方向提供了实证基础。
