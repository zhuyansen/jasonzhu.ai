### RL 驱动代码优化新突破：让执行速度成为可学习的奖励信号

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.25970
- **TitleEN**：RL for Code Optimization: Making Execution Time a Learnable Reward Signal

这篇论文解决了一个实际难题：用强化学习优化「代码速度」时，执行时间的测量噪声和奖励稀疏性会导致训练崩溃。研究者通过一套新方法让 RL 成功学会生成更快的代码。对开发者的意义：未来 AI 编程工具不只能写「正确」的代码，还能自动生成「更快」的代码。

- **EN**：This paper tackles a key obstacle in RL-based code optimization: execution time measurement noise and reward sparsity cause training to collapse. The proposed solution makes execution time a stable, learnable signal. For developers, this paves the way for AI coding tools that don't just write correct code—but automatically write faster code.

### Agent Retrieval Bench：评估编程 Agent 仓库上下文检索能力的新基准

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.24882
- **TitleEN**：Agent Retrieval Bench: New Benchmark for Coding Agent Context Retrieval

现有编程 Agent 评测只看「最终 patch 对不对」，却忽视了生成 patch 之前更关键的一步——能否从大型代码仓库里找到正确的相关文件。这篇论文提出 Agent Retrieval Bench，专门评估这一上游检索能力。对 Claude Code / Cursor 等工具的开发者：这是提升 Agent 实际效果的关键瓶颈所在。

- **EN**：Existing coding agent benchmarks only measure final patch correctness, ignoring the upstream step of finding relevant files in large repositories. Agent Retrieval Bench fills this gap with a file-level retrieval benchmark built from real coding workflows. For Claude Code/Cursor developers, this pinpoints a critical bottleneck in real-world agent performance.
