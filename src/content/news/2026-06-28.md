### 免费午餐：用 RL 训练过程中的进度优势直接为 Agent 步骤打分，无需额外奖励模型

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.26080
- **TitleEN**：Progress Advantage: Free Step-Level Scoring for LLM Agents from RL Post-Training

训练过程奖励模型（PRM）对 Agent 至关重要，但为长链任务标注步骤级奖励极其昂贵。本文发现 RL 后训练本身已内含有效的步骤评分信号——「进度优势」——无需额外训练奖励模型即可实现精细步骤评估。对开发 Agent 应用的工程师而言，这意味着更高质量的 Agent 训练成本可以大幅降低。

- **EN**：Training process reward models (PRMs) for long-horizon agents is prohibitively expensive. This paper shows RL post-training already contains effective step-level scoring signals — 'progress advantage' — eliminating the need for dedicated reward model training. For agent developers, this means higher-quality agent training at dramatically lower cost.
