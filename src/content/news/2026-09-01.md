### EvoUndo：让 LLM Agent 自我进化的同时确保「可撤销」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.28363
- **TitleEN**：EvoUndo: recoverability constraints for self-evolving LLM agents

LLM Agent 现在可以在运行时修改自己的 prompt、工具和执行环境（自我进化），但改完后可能留下无法回滚的「副作用」。EvoUndo 提出了一套框架，让每次自我修改都携带验证过的撤销方案，在反事实状态下也能安全回退。对正在构建 long-running Agent 的开发者来说，这是解决「Agent 越改越乱」问题的重要思路。

- **EN**：EvoUndo addresses a critical risk in self-evolving LLM agents: runtime self-modifications to prompts, tools, or middleware can leave irreversible side effects. The framework enforces recoverability constraints and synthesizes verified undo operations across counterfactual states—essential reading for anyone building production-grade long-running agents.

### LoopArena：专门测试 AI 做「编码循环控制器」能力的新基准

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.28281
- **TitleEN**：LoopArena: benchmarking LLMs as runtime controllers for coding agent loops

随着 Coding Agent 普及，越来越多工程师开始设计「Loop」来让 Agent 自动监控进度、分配任务、验证结果。LoopArena 是第一个专门评估模型作为 Loop 运行时控制器的基准——测的不是「写代码」，而是「管理整个 Agent 工作流」的决策质量。对构建 AI 工程流水线的开发者选模型很有参考价值。

- **EN**：LoopArena is a new benchmark evaluating LLMs not on writing code, but on managing entire coding agent loops—monitoring progress, assigning work, verifying outputs, and budget allocation. As loop-based agentic development grows, this fills a critical gap in model evaluation for AI engineering workflows.

### Sliding Window 注意力机制胜过线性注意力：长上下文推理新进展

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.28444
- **TitleEN**：Sliding-window attention outperforms linear attention for long-context LLMs

线性注意力被广泛视为解决 Transformer 二次方复杂度的「银弹」，但这篇论文给出了反直觉的结论：精心设计的滑动窗口注意力在长上下文任务中表现更好，且内存效率不输线性注意力。对正在做长文档处理、RAG 或本地部署长上下文模型的开发者有直接影响。

- **EN**：Challenging the assumption that linear attention is the future of efficient LLMs, this paper shows that well-tuned sliding-window attention outperforms linear attention on long-context tasks with comparable memory efficiency. Directly relevant to developers building long-document RAG pipelines or deploying long-context models locally.
