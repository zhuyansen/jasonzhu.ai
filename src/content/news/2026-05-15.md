### agentmemory：让 Claude Code/Cursor/Codex 等编程 Agent 拥有持久记忆

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/rohitg00/agentmemory
- **TitleEN**：agentmemory Gives Claude Code, Cursor, and Codex Persistent Memory

agentmemory 是专为编程 Agent 设计的持久记忆层，支持 Claude Code、Cursor、Gemini CLI、Codex CLI 等主流工具及所有 MCP 客户端。基于 Karpathy 的 LLM Wiki 模式扩展，加入置信度评分、知识图谱和混合搜索，彻底解决 Agent 每次会话都要重新解释上下文的痛点。

- **EN**：agentmemory is a persistent memory layer built for coding agents, supporting Claude Code, Cursor, Gemini CLI, Codex CLI, and all MCP clients. Extending Karpathy's LLM Wiki pattern with confidence scoring, knowledge graphs, and hybrid search, it eliminates the pain of re-explaining context to agents at the start of every session.

### LEAD 论文：让推理模型「说人话」——动态压缩 CoT 链路节省 40% Token

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.09806
- **TitleEN**：LEAD Paper: Dynamically Compressing Chain-of-Thought Saves 40% of Tokens

o1、DeepSeek-R1 这类推理模型越聪明越啰嗦，思维链动辄数千 Token 浪费算力。LEAD 框架通过强化学习引入「长度效率奖励」，让模型自适应调整推理深度——简单问题短答、复杂问题深想。实测在保持准确率的前提下显著压缩推理成本，对部署推理模型的开发者意义重大。

- **EN**：Reasoning models like o1 and DeepSeek-R1 are often verbose, burning thousands of tokens on chains of thought. LEAD uses reinforcement learning with a length-efficiency reward to adapt reasoning depth: brief answers for simple questions, deeper thinking for complex ones. Tests show significantly lower inference costs without sacrificing accuracy, a major benefit for developers deploying reasoning models.

### FlowCompile：首个专为多 Agent 工作流设计的「编译器优化」框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.13647
- **TitleEN**：FlowCompile: First Compiler-Style Optimization Framework for Multi-Agent Workflows

多个 LLM 子 Agent 组成的工作流该如何自动优化模型选择、推理预算和结构配置？FlowCompile 把这个问题类比为编译器优化，系统性地在准确率和延迟之间寻找最优配置。对正在搭建复杂 Agent Pipeline 的开发者来说，这是把「凭感觉调参」变成「有算法依据」的关键一步。

- **EN**：How should workflows of multiple LLM sub-agents automatically optimize model choice, reasoning budgets, and structure? FlowCompile treats this as a compiler optimization problem, systematically searching for the best balance of accuracy and latency. For developers building complex agent pipelines, it is a key step from tuning by feel to algorithm-driven configuration.
