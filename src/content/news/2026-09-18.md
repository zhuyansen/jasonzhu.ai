### CERA-MoA：路由与 Agent 协同进化，打破 MoA 范式瓶颈

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.18779
- **TitleEN**：CERA-MoA: Co-Evolving Routing and LLM Agents Breaks MoA Bottleneck

现有「多 Agent 混合」(MoA) 系统的路由策略与 Agent 微调是相互独立的，导致路由无法适应 Agent 能力变化。CERA-MoA 提出迭代强化方案，让路由器与 Agent 同步演化。对开发者的意义：构建多 Agent 系统时，路由与 Agent 能力解耦是性能天花板，这项研究提供了打破该瓶颈的实用思路。

- **EN**：CERA-MoA fixes a critical flaw in Mixture-of-Agents systems: routing strategies and agent fine-tuning have been siloed, preventing adaptive specialization. By co-evolving the router with agents iteratively, it unlocks synergistic performance gains—directly relevant for anyone building multi-agent pipelines.

### Edge0：SSD 流式推理让 35B MoE 模型跑上消费级硬件

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.18063
- **TitleEN**：Edge0: SSD Streaming Inference Brings 35B MoE Models to Consumer Hardware

35B MoE 模型在 4-bit 量化下仍有 19.5GB，普通 GPU 难以承载。Edge0 通过「预路由器」在当前层计算结束前就预测下一层需要哪些专家，提前从 SSD 加载权重，将存储延迟隐藏在计算之后。对独立开发者的意义：本地部署大型 MoE 模型（如 Mixtral 级别）变得实际可行，不再需要高端 GPU 集群。

- **EN**：Edge0 introduces a 'prerouter' that predicts which MoE experts layer N+1 needs before layer N finishes, hiding SSD read latency behind compute. This makes local inference of 35B+ MoE models on consumer hardware genuinely practical—a game-changer for indie devs running models locally.
