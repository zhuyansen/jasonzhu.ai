### 开源工具解决Agent上下文爆炸：工具输出压缩98%

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/mksglu/context-mode
- **TitleEN**：Context Mode Cuts AI Agent Tool Output by 98%

新开源项目 Context Mode 针对 MCP 工具调用的「上下文爆炸」问题，通过沙箱化工具输出（压缩达98%）、持久化会话记忆，支持17个平台的 MCP+hooks 路由，解决长会话中40%上下文被日志淹没的痛点。

- **EN**：Context Mode tackles the 'other half' of the context problem for MCP-based coding agents: sandboxing raw tool output (98% reduction) and persisting session memory across 17 platforms via MCP + hooks, fixing the issue of logs eating 40% of context in long sessions.

### 新论文MILO：让多Agent自动进化出最优「作战套件」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.38349
- **TitleEN**：MILO: Multi-Agent Evolution Auto-Discovers Agent Harnesses

简单说：现在搭建 Agent 不只是选模型，还要设计「harness」（执行框架+工具+提示词组合），这个搭配极大影响实际效果但全靠人工调试。MILO 用多Agent协同进化的方式自动搜索最优 harness 组合，减少了换模型后重复调参的人力成本，对正在搭 Agent 产品的开发者有直接参考价值。

- **EN**：In plain terms: building a good AI agent isn't just about picking a model—it's about designing the 'harness' (execution loop, tools, prompts), which hugely affects performance but is usually hand-tuned. MILO automates this search via evolving multi-agent exploration, cutting the manual re-tuning work needed every time models change—directly useful for anyone building agent products.
