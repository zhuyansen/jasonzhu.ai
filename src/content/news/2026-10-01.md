### 新论文揪出浏览器 Agent 隐私泄露新漏洞

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.32915
- **TitleEN**：New Paper Exposes Privacy Leaks in Browser-Use Agents

AgentTell 研究发现，Claude Computer Use 这类浏览器操作 Agent 在跨网站执行任务时，会无意间把上一个网站获取的隐私信息（如会员身份）通过行为侧信道泄露到下一个网站，提醒开发者在设计自动化 Agent 时要特别警惕上下文泄露。

- **EN**：The AgentTell paper shows browser-use agents (think Claude Computer Use) can inadvertently leak private info learned on one site — like a user's membership status — through behavioral side channels when acting on another site, a key privacy risk for anyone building browser automation agents.

### 能否让 Agent 为 Agent 设计可复用代码库？

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.36730
- **TitleEN**：Can AI Agents Design Code Libraries for Other Agents?

研究提出 LibraryDesignBench 基准，测试 Agent 能否为后续 Agent 设计出简洁、可复用的代码库，而不是每次都重复造轮子——这直接关系到 Claude Code Skills 这类「Agent 写给 Agent 用的工具」生态能不能良性发展。

- **EN**：The paper introduces LibraryDesignBench to test whether agents can design clean, reusable libraries for other agents to build on — instead of endlessly reimplementing the same logic. This matters directly for ecosystems like Claude Code Skills, where agents build tools for other agents.
