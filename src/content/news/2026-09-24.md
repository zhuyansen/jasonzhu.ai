### Agensh 论文：去中心化编排让 1024 个 Agent 无需主控器并发协作

- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.26781
- **TitleEN**：Agensh: Self-Organized Multi-Agent System Scales to 1,024 Concurrent Agents

论文提出 Agensh，一个无中心编排器的自组织多 Agent 框架，让最多 1024 个并发 Worker 通过协作循环自主分配任务。对开发者的意义：现有多 Agent 框架的最大瓶颈是中心调度器的吞吐上限，Agensh 的去中心化设计为构建超大规模 Agent 集群提供了新的架构思路。

- **EN**：Agensh eliminates the central orchestrator bottleneck by letting up to 1,024 concurrent agent workers self-organize via cooperative loops. For developers building large-scale multi-agent systems, this offers a concrete architectural alternative to the throughput ceiling of centralized scheduling.

### LatentPort：LLM 可直接「交接内存」给另一个更大的模型，无需重读上下文

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.25053
- **TitleEN**：LatentPort: Cross-Model Memory Handoff Between LLMs Without Replaying Context

论文首次演示了跨模型「内存直传」：4B 模型的运行时隐状态可直接传给 9B 模型继续推理，接收方无需重新读取任何上下文前缀。对开发者的意义：这意味着未来 Agent 工作流可以用小模型做快速推理、遇到复杂任务时「热切换」到大模型，大幅降低延迟和 token 消耗。

- **EN**：LatentPort demonstrates the first cross-model handoff of live recurrent memory — a 4B model passes its runtime state to a 9B model without prefix replay. For developers, this hints at future agent pipelines where small models hand off seamlessly to larger ones, cutting latency and token costs.
