### SVR-R1：让模型用「自我核查」替代外部验证器做多模态推理

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.10966
- **TitleEN**：SVR-R1: Self-Verification RL for Multimodal Reasoning Without External Verifiers

SVR-R1 提出了一种自我验证强化学习框架：模型回答问题后，用同一套权重对自己的答案给出 Yes/No 判断，答错了就再想一次。**对开发者的意义**：这套机制无需外部验证器或标注数据就能训练多模态推理能力，大幅降低构建可靠推理模型的成本门槛。

- **EN**：SVR-R1 introduces a multi-turn RL framework where a model self-verifies its own answers using the same weights — a 'No' triggers a rethink before finalizing. For developers, this means training robust multimodal reasoning models without any external verifiers or labeled correctness data, dramatically reducing the cost of building reliable reasoning pipelines.

### Agon：让两个模型互相当裁判，逼出更好的推理链

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.07690
- **TitleEN**：Agon: Competitive Cross-Model RL Where Rivals Grade Each Other's Reasoning

现有 GRPO 等强化学习方案只奖励最终答案，导致模型「越写越长却不越想越深」。Agon 让两个模型互当对手+裁判，通过竞争性评分直接优化推理过程质量。**对开发者的意义**：这是训练真正「会思考」而非「会堆字」的推理模型的新范式，有望替代人工标注的思维链。

- **EN**：Current RL methods like GRPO reward only final answers, training models to write more rather than reason better. Agon pairs two competing models that grade each other's reasoning traces, directly optimizing thinking quality. For developers fine-tuning reasoning models, this could replace expensive chain-of-thought annotations with a self-improving competitive dynamic.

### RESOURCE2SKILL：从教程视频自动蒸馏可复用 Agent 技能库

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.29538
- **TitleEN**：RESOURCE2SKILL: Distill Executable Agent Skills from Tutorial Videos Automatically

现有 Agent 技能库大多靠人工手写或从 Agent 执行轨迹提取，教程视频等多模态资源严重浪费。RESOURCE2SKILL 从视频、文章、代码仓库等资源自动蒸馏出可执行技能。**对开发者的意义**：理论上可以把任意软件操作视频转化为 Agent 可直接调用的技能，大幅提速 Agent 能力扩充。

- **EN**：RESOURCE2SKILL automatically distills multimodal human resources — tutorial videos, articles, repositories — into executable agent skills, bypassing the need for manual authoring or agent trace collection. For developers building skill libraries, this opens a path to rapidly scaling agent capabilities by converting any how-to video into reusable procedural knowledge.
