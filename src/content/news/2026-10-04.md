### 新论文X-Tree：让Agent的技能真正学进模型权重

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.32993
- **TitleEN**：X-Tree: Baking Reusable Agent Skills Into Model Weights

现有多步Agent训练把每个动作一视同仁，忽略了任务中反复出现的「子流程」；就算用LLM写的Skills放进上下文，也只是检索式复用，并不能真正泛化。X-Tree提出把这些可复用经验编码进模型权重本身，让Agent在新任务上也能自动调用已学会的套路，而不是每次从零现场摸索，对降低Agent训练和推理成本很有意义。

- **EN**：Most multi-step agent training treats every action equally, ignoring recurring sub-procedures — and even skill-in-context tricks only retrieve, never generalize. X-Tree tokenizes reusable experience directly into model weights, letting agents reuse learned routines on new tasks instead of relearning from scratch — a real step toward cheaper, more generalizable agents.

### MemFold：给长期陪伴型AI装上「紧凑记忆芯片」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.36435
- **TitleEN**：MemFold Gives Long-Term AI Assistants a Compact Memory

长期服务同一用户的AI助手需要记住哪些偏好还有效、哪些已被修改——但把记忆存成文本会让上下文越聊越长，压成固定向量又训练不到位。MemFold提出用在线策略优化训练的紧凑软记忆，既不让输入膨胀，又能真正按记忆内容行动，是个人化AI助手降本提效的关键一环。

- **EN**：An assistant serving the same user long-term must track which preferences still hold versus which got revised — but storing memory as text bloats context, while compressing it often fails to train properly. MemFold introduces a compact, on-policy-optimized soft memory that stays fixed-size while actually acting on retained info, key for scaling personalized AI assistants affordably.
