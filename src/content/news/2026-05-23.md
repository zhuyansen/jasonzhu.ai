### 论文：Agent 自我调节规划框架，让推理更高效、Token 不再白烧

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.22138
- **TitleEN**：Paper: Self-Regulating Planning Framework Cuts Agent Token Waste

这篇论文提出将 Agent 决策拆解为感知、规划、执行三层，通过「自我调节模拟规划」让 Agent 自主决定何时以及如何规划，而非无脑拉长推理链。对开发者的意义：更少 Token 消耗、更可靠的任务完成率，是构建高效长程 Agent 的重要参考架构。

- **EN**：This research proposes decomposing agent decision-making into perception, planning, and execution layers, using 'self-regulating simulated planning' to let agents autonomously decide when and how to plan rather than blindly extending reasoning chains. The result is fewer token expenditures and more reliable task completion — a valuable reference architecture for building efficient long-horizon agents.
