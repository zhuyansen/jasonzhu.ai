### GEPA-Curator：先筛失败案例再让Agent自我改进

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.37651
- **TitleEN**：GEPA-Curator Curates Failures for Self-Improving Agents

GEPA这类提示词优化器会从Agent的失败中学习，但失败原因可能是运行框架的局限、随机性或评委打分噪声，并非提示词本身有问题。这篇论文提出先筛选哪些任务值得学习，避免越优化越差。对用自动化方法调Agent提示词的开发者很实用。

- **EN**：Prompt optimizers like GEPA learn from agent failures, but many failures come from harness limits, randomness, or noisy judges rather than the prompt itself. GEPA-Curator first filters which tasks are worth learning from, so optimization does not make things worse. Practical for developers who auto-tune agent prompts.

### ProVe反转投机解码，大模型一次猜一整段

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.27815
- **TitleEN**：ProVe Flips Speculative Decoding for Faster Generation

传统投机解码由小模型逐个打草稿、大模型验证。ProVe反过来，把大模型微调成一次前向就预测一整段后续token，再用一次额外前向完成验证，验证方可以是小模型。这意味着用现有模型就可能换来更低的推理延迟，对自部署模型、关心推理成本的团队值得关注。

- **EN**：Standard speculative decoding has a small model draft tokens one by one while a large model verifies. ProVe reverses the roles: it fine-tunes the large model to propose a block of tokens in one forward pass, then verifies with one more pass, possibly using a smaller model. This could cut latency for teams self-hosting models.
