### Ponytail Skill：让Agent像「最懒的资深开发者」，代码少写54%

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/DietrichGebert/ponytail
- **TitleEN**：Ponytail Skill Cuts Claude Code Output by 54% While Keeping Features Working

Ponytail 是一个给 AI 编码 Agent 用的 Skill，核心思路是「能不写就不写」。作者用 Claude Code 在 FastAPI + React 真实仓库上做了 12 个功能任务的对照测试（Haiku 4.5，n=4），结果显示代码量减少约54%（最高94%），成本降低约20%，速度提升约27%。对开发者来说，这是少量可验证的数据，说明 Skill 可以直接影响 Agent 的编码习惯和 token 花费。

- **EN**：Ponytail is a skill for AI coding agents that pushes them to write less code. In a controlled test on a real FastAPI and React repo, Claude Code with the skill wrote about 54% less code, cost about 20% less, and ran about 27% faster across 12 tasks. For developers, it shows a skill can measurably change how an agent codes and what it costs.

### text-to-cad 插件：让 Agent 直接生成可制造的 3D 模型

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/earthtojake/text-to-cad
- **TitleEN**：text-to-cad Plugin Lets Agents Generate Manufacturable 3D Models

text-to-cad 是一个 Agent 插件，能让 Claude Code 等支持 skills 框架的工具在本地生成 STEP、GLB、STL、3MF 格式的 3D 模型。它还内置可制造性（DFM）检查，能生成工程图纸，并对接 3D 打印、钣金和 CNC 加工服务。这说明 Skills 正从写代码扩展到硬件和工程制造场景。

- **EN**：text-to-cad is a plugin that lets agents like Claude Code generate 3D models locally in STEP, GLB, STL, and 3MF formats. It includes design-for-manufacturing checks, produces engineering drawings, and connects to 3D printing and CNC services. It shows skills expanding beyond code into hardware and manufacturing.

### OpenAI 将在欧盟为 ChatGPT 文本添加水印，编辑可削弱检测

- **板块**：AI 工具动态
- **来源**：TechCrunch AI
- **链接**：https://techcrunch.com/2026/10/05/openai-will-start-watermarking-chatgpts-text-in-the-eu/
- **TitleEN**：OpenAI Adds Text Watermarks to ChatGPT in the EU Under AI Act

OpenAI 将依据欧盟 AI 法案，在欧盟地区为 ChatGPT 和 Codex 生成的文本加入水印。官方承认，对文本进行编辑会让隐形水印更难被检测，检测能力目前也优先开放给研究人员。对开发者而言，这意味着跨地区产品的输出合规会出现差异，做内容审核或溯源功能时需要考虑这一限制。

- **EN**：OpenAI will watermark ChatGPT and Codex text in the EU to comply with the AI Act. It admits that editing can make the invisible marks harder to detect, and detection access starts with researchers. For developers, output behavior will differ by region, which matters for compliance and provenance features.

### CUAWright：3K 行终端 harness，让计算机使用 Agent 直接跑 bash

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.04116
- **TitleEN**：CUAWright: A 3K-Line Terminal Harness for Computer-Use Agents

这篇论文提出 CUAWright，一个约 3K 行代码的极简终端 harness。传统电脑操作 Agent 依赖浏览器或桌面的固定工具，论文认为这限制了模型的发挥。CUAWright 让模型通过 bash 命令直接操作系统状态，并能即时构建工具。对开发者来说，这是一个值得参考的思路：与其堆大量预设 GUI 工具，不如给 Agent 一个最小可编程环境。

- **EN**：CUAWright is a minimal terminal harness of about 3K lines that lets computer-use agents operate systems through bash rather than fixed GUI tools. The authors argue this lets models build tools on the fly as coding ability improves. For developers, it suggests a minimal programmable shell may beat large sets of predefined GUI tools.
