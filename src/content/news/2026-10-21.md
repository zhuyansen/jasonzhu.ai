### BonBook推出MCP，在Claude里一键订机票

- **板块**：Skills 生态
- **来源**：Hacker News
- **链接**：https://mcp.bonbook.co/claude-setup
- **TitleEN**：BonBook MCP Enables One-Click Flight Booking in Claude

BonBook 原本是通过邮件订机票的服务，已处理数万次请求。新推出的 MCP 支持在 Claude 内查询实时航班并直接下单，无需填写表单，积分和会员等级保留，全程约35秒。这是 MCP 从信息查询走向真实交易的一个落地案例，也展示了垂直服务接入 AI 助手的新分发路径。

- **EN**：BonBook, which began as an email-based flight booking service handling tens of thousands of requests, launched an MCP that searches live flights and books them inside Claude in about 35 seconds, with no forms and loyalty points preserved. It shows MCP moving from information retrieval to real transactions, and opens a new distribution channel for vertical services.

### ai-memory让编码智能体跨厂商无缝交接任务

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/akitaonrails/ai-memory
- **TitleEN**：ai-memory Enables Cross-Vendor Handoff Between Coding Agents

这个开源项目为编码 CLI 提供长期记忆层。开发者可以中途退出 Claude Code，在同一目录启动 OpenAI Codex 继续工作，不必重新解释架构、失败过的方案和待解决问题。它针对各家智能体记忆互不相通的问题，适合同时使用多个工具或需要规避单一厂商锁定的开发者。

- **EN**：This open-source project adds a long-term memory layer for coding CLIs. Developers can quit Claude Code mid-task and continue in OpenAI Codex in the same directory without re-explaining architecture, failed approaches or open questions. It tackles siloed vendor memory and suits developers who mix tools or want to avoid lock-in.

### HDA论文拆解智能体Harness优化的真实收益

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.22466
- **TitleEN**：HDA Dissects Real Gains From Agent Harness Evolution

Harness 优化指不改模型权重，只自动调整提示词、Skills、工具和编排代码来提升智能体表现。论文提出 Harness-Delta Attribution，用来区分提升中有多少来自针对评测集的过拟合、有多少来自额外的推理算力、又有多少能真正泛化。对调 Skills 和 Prompt 的开发者来说，它提醒：评测分数上涨不等于线上效果变好。

- **EN**：Harness evolution improves agents by automatically tuning prompts, skills, tools and orchestration code without changing model weights. The paper introduces Harness-Delta Attribution to separate gains caused by benchmark overfitting, by extra inference compute, and by genuine generalization. For developers tuning skills and prompts, it warns that higher benchmark scores may not translate to production.

### TokenGate让大模型像人一样略读长上下文

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.26754
- **TitleEN**：TokenGate Lets LLMs Skim Long Contexts for Faster Prefill

TokenGate 是一个可直接接入已训练模型的小组件，让模型学会在处理长输入时只细读关键 token，跳过其余部分。这样能显著加快预填充（prefill，即模型读取输入的阶段）并节省显存。对需要把整个代码仓库或长文档塞进上下文的应用来说，这意味着更低的延迟和推理成本。

- **EN**：TokenGate is a small drop-in component that teaches existing trained models to learn which tokens to prune in long inputs, skimming most of the text and reading only what matters. This speeds up prefill, the stage where the model reads its input, and cuts memory use. For apps feeding whole repos or long documents, it means lower latency and inference cost.
