### Self-Evolving Coding Agents：会自我进化的代码 Agent，部署后也能持续成长

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.03392
- **TitleEN**：Self-Evolving Coding Agents: Agents That Keep Improving After Deployment

这篇论文系统梳理了「自我进化型编码 Agent」的研究进展——Agent 不再在部署后冻结，而是从真实开发反馈（测试失败、代码变更、修复经验）中持续学习。对开发者的意义：未来 Coding Agent 将越用越聪明，而不是每次都从零开始。

- **EN**：This paper surveys self-evolving coding agents — systems that continue improving after deployment by learning from real dev feedback like test failures and repair attempts. The key implication: future coding agents won't stay static; they'll compound experience just like human developers do.
