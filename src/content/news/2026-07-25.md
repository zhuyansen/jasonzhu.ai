### ego-lite：让你和 AI Agent 在同一浏览器里并行工作的新工具

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/citrolabs/ego-lite
- **TitleEN**：ego-lite: A Browser Where You and AI Agents Work in Parallel

ego-lite 是一款专为人机协作设计的浏览器，AI Agent 在独立的 Space 中并行处理浏览器任务，不打扰用户当前标签页，登录状态直接共享、无需重复配置。相比 browser-use 等自动化框架，它让 Agent 更接近「同事」而非「机器人」，对 Claude Code / Cursor 工作流尤其友好。

- **EN**：ego-lite is a browser that lets AI agents run tasks in parallel Spaces while you keep your own tabs. Unlike browser-use or agent-browser frameworks, it shares login state natively and reduces token overhead — a natural fit for Claude Code and Cursor power users.

### Kronos：首个开源金融 K 线基础模型，覆盖全球 45 家交易所

- **板块**：AI 论文
- **来源**：GitHub Trending
- **链接**：https://github.com/shiyu-coder/Kronos
- **TitleEN**：Kronos: First Open-Source Foundation Model for Financial Candlestick Data

Kronos 是首个专为金融 K 线（蜡烛图）训练的开源基础模型，覆盖超过 45 家全球交易所数据，已被 AAAI 2026 收录。对量化开发者来说，这意味着终于有了一个可以 fine-tune 的金融时序专用大模型，而不必把通用 LLM 硬用在结构化价格数据上。

- **EN**：Kronos is the first open-source foundation model trained specifically on financial candlestick (K-line) data from 45+ global exchanges, accepted at AAAI 2026. For quant developers, it's the first serious LLM backbone purpose-built for structured price data — no more forcing GPT onto OHLCV.

### SANA-Video 2.0：单 GPU 跑 720p 视频生成的高效扩散 Transformer

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.21553
- **TitleEN**：SANA-Video 2.0: 720p Video Generation on a Single GPU via Hybrid Attention

SANA-Video 2.0 用混合线性注意力机制（O(N) 复杂度 + 周期性 Softmax 锚点）在 5B/14B 规模下实现单 GPU 生成 720p 视频，质量媲美全 Softmax 架构。对独立开发者而言：不需要多卡集群也能跑高清视频生成，部署成本大幅下降。

- **EN**：SANA-Video 2.0 combines gated linear attention with periodic softmax anchors to generate 720p video on a single GPU at 5B and 14B scales, matching full-softmax quality. For indie developers, this dramatically lowers the hardware barrier to high-quality video generation.

### Agent 经验样本高效学习：让 LLM Agent 真正「记住」过去的教训

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.21051
- **TitleEN**：Sample-Efficient Learning from Agent Experience via Context Distillation

这篇论文提出将 Agent 自身交互历史通过上下文蒸馏内化进模型权重，解决「上下文清空后经验归零」的问题。对构建长期运行 AI Agent 的开发者来说，这意味着 Agent 可以跨会话积累真正有用的经验，而不是每次重新出发。

- **EN**：This paper proposes distilling an agent's interaction history directly into model weights, so learned experience persists after the context window clears. For developers building long-running AI agents, this means agents can genuinely accumulate expertise across sessions — not just within one conversation.
