### HF 论文：TRACE 框架让 Coding Agent 真正「记住」你的偏好，违规率从 57.5% 降至极低

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.13174
- **TitleEN**：TRACE Framework Makes Coding Agents Actually Remember User Preferences

研究发现现有记忆方案（如 Mem0）在 Coding Agent 中仍有 57.5% 的用户偏好被违反。TRACE 框架将用户的每次纠正「编译」为运行时强制规则，而非仅存储记忆，从根本上解决「Agent 记得但不遵守」的问题。对所有使用 Claude Code/Cursor 的开发者极具实际意义。

- **EN**：Existing memory tools like Mem0 still violate 57.5% of user preferences in coding agents. TRACE compiles corrections into runtime-enforced rules rather than passive memories — solving the core problem of agents that 'remember but don't comply.' Highly relevant for Claude Code and Cursor users.

### HF 论文：LLM Agent 存在「冷启动安全漏洞」——会话开头最脆弱

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.07867
- **TitleEN**：LLMs Have a Cold-Start Safety Gap: Agents Are Most Vulnerable at Session Start

研究揭示工具调用型 LLM Agent 在对话刚开始时安全防御最弱，完成几轮正常任务后才会「热身」进入更安全状态——称为「冷启动安全缺口」。论文发布了 SODA 基准以系统性测量该现象。对生产环境中部署 Agent 的开发者意味着需要在会话初始阶段额外谨慎。

- **EN**：Tool-calling LLM agents are most vulnerable to safety attacks at the very start of a session, becoming safer only after a few normal tasks — termed the 'cold-start safety gap.' New SODA benchmark measures this. Developers deploying production agents should add extra guardrails at session initialization.

### HF 论文：异构 Agent 间可直接传输 KV-Cache，跨模型「心灵感应」成可能

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2606.13594
- **TitleEN**：Heterogeneous AI Agents Can Now Share KV-Cache Without Costly Re-encoding

多 Agent 系统通常靠文字传递信息，编解码损耗大。该论文证明不同架构的 Agent 之间可以直接共享 KV-Cache 潜在表示，绕开昂贵的文本转换，实现「稠密潜在通信」。这对构建高效 Multi-Agent 系统的开发者来说是重要的基础性突破，可大幅降低 Agent 协作的推理成本。

- **EN**：Multi-agent systems lose information and waste compute by communicating through text. This paper shows heterogeneous agents with different architectures can directly share KV-cache representations, enabling dense latent communication — a foundational breakthrough that could dramatically reduce inference costs in multi-agent pipelines.
