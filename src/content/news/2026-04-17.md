### OpenAI Codex 重大升级：获得电脑控制、浏览器与图像生成能力

- **板块**：AI 工具动态
- **来源**：OpenAI Blog / TechCrunch AI
- **链接**：https://openai.com/index/codex-for-almost-everything
- **TitleEN**：OpenAI Codex Gains Computer Use, Browsing, and Image Generation

OpenAI 大幅升级 Codex，新增 computer use（桌面控制）、应用内浏览、图像生成、记忆与插件支持，直接对标 Anthropic Claude Code。此次更新让 Codex 从单纯代码补全工具演变为全能 AI 开发代理，与 Anthropic 的正面竞争全面升级。

- **EN**：OpenAI has significantly upgraded Codex with computer use (desktop control), in-app browsing, image generation, memory, and plugin support, squarely targeting Anthropic's Claude Code. The update turns Codex from a code-completion tool into a full-fledged AI development agent and sharply escalates its head-to-head rivalry with Anthropic.

### Claude Opus 4.7 发布，LiveBench 排名跻身全球第三

- **板块**：AI 工具动态
- **来源**：X/@bindureddy
- **链接**：https://nitter.net/bindureddy/status/2044813400472260905#m
- **TitleEN**：Claude Opus 4.7 Launches, Ranks Third Globally on LiveBench

Anthropic 悄然发布 Claude Opus 4.7，性能超越 Opus 4.6 高强度模式，疑似基于全新底座模型训练，可能是更大模型的蒸馏版本。新增任务预算（task budgets）机制，有助于开发者精确控制 API 调用成本，对高频应用场景意义重大。

- **EN**：Anthropic has quietly released Claude Opus 4.7, which outperforms Opus 4.6 in high-effort mode and appears to be trained on a new base model, possibly distilled from a larger one. A new task budgets feature gives developers precise control over API costs, a significant benefit for high-volume use cases.

### OpenAI Agents SDK 重大迭代：原生沙箱执行与模型原生框架上线

- **板块**：Skills 生态
- **来源**：OpenAI Blog
- **链接**：https://openai.com/index/the-next-evolution-of-the-agents-sdk
- **TitleEN**：OpenAI Agents SDK Adds Native Sandbox Execution and Model-Native Harness

OpenAI 更新 Agents SDK，引入原生沙箱执行环境（native sandbox execution）和模型原生调度框架，支持跨文件与工具的长时运行 Agent，大幅降低构建安全可靠的自动化工作流难度，是面向开发者的重要基础设施升级。

- **EN**：OpenAI has updated its Agents SDK with native sandbox execution and a model-native orchestration framework, supporting long-running agents that work across files and tools. The update makes it much easier to build safe, reliable automated workflows, a major infrastructure upgrade for developers.
