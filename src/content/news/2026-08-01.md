### OpenWork 开源上线：Claude Code / Cursor 的跨工具 Skills 共享层

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/different-ai/openwork
- **TitleEN**：OpenWork: Open-Source Skills & MCP Sharing Layer for Claude Code and Cursor

OpenWork 是 Claude Cowork 的开源替代方案，底层基于 opencode，支持 macOS/Windows/Linux。核心价值：只需在 Codex、Claude Code、Cursor 或任意兼容 Agent 里添加一个 MCP，即可跨工具、跨成员、跨机器复用同一套 Skills、MCP 和已连接服务，一次创建到处共享。

- **EN**：OpenWork is a free, open-source desktop app that lets developers share AI workflows across Claude Code, Codex, and Cursor via a single MCP. Skills, connected services, and agent configurations created once can be reused across tools, teammates, and machines — positioning it as an open alternative to Claude Cowork.

### OmniScope：多模态大模型 Token 压缩新框架，音频与视频各自独立找重点

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.23193
- **TitleEN**：OmniScope: Query-Guided Token Compression That Treats Audio and Video Independently

现有多模态大模型的 Token 压缩方法通常用一种模态来决定保留另一种模态的哪些内容，但音频和视频的关键时刻往往不重叠。OmniScope 提出无需训练的框架，让查询本身独立引导每个模态的压缩——对开发者的意义：在多模态 Agent 场景下大幅降低计算成本，同时不丢失关键答案线索。

- **EN**：OmniScope is a training-free token compression framework for omnimodal LLMs that uses the query to independently guide compression per modality, instead of letting one modality dictate what to keep in another. For developers building multi-modal agents, this means dramatically lower token costs without sacrificing answer-critical audio or video cues.

### Σ-Mem：多 Agent 系统的「可信度记忆」，让 AI 知道哪个队友靠谱

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.27958
- **TitleEN**：Σ-Mem: Reliability Memory That Tracks Which Agents to Trust in Multi-Agent Systems

现有 Agent 记忆系统只存内容，不记「谁可以信任」。Σ-Mem 引入在线可靠性记忆，追踪每个 Peer Agent 的历史能力表现和协作关系，让中心模型在无法直接验证响应时做出更理性的信任决策。对构建多 Agent 工作流（如 Claude Code 多步骤任务）的开发者有直接参考价值。

- **EN**：Σ-Mem introduces an online reliability memory for multi-agent LLM systems that tracks not just interaction content but the historical competence and trustworthiness of individual peer agents. For developers building multi-agent pipelines, this means agents can make smarter trust decisions rather than blindly accepting potentially flawed peer outputs.
