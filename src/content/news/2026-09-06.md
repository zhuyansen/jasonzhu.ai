### τ²-Bench：首个端到端 Agent 构建能力基准测试，不只跑 Agent，还要造 Agent

- **板块**：Skills 生态
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.00412
- **TitleEN**：τ²-Bench: Benchmarking End-to-End Realistic Agent Construction

τ²-Bench 提出了一个新维度：不只测试 AI Agent 执行任务的能力，还测试构建 Agent 本身的能力——从需求理解到系统设计再到部署调试。随着 Agent 生态爆发，「谁来造 Agent」正在成为和「Agent 能做什么」同等重要的问题。

- **EN**：τ²-Bench benchmarks not just running agents but building them end-to-end — from requirement understanding to system design to deployment debugging. As the agent ecosystem explodes, 'who builds agents' is becoming as important as 'what agents can do.'

### Enoki：多层级幻觉检测框架，让 LLM 在高风险场景也能上岗

- **板块**：AI 工具动态
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.00581
- **TitleEN**：Enoki: Efficient Multi-Level Hallucination Detection for High-Stakes LLM Deployment

Enoki 提出多层级幻觉检测方案：既能在 claim 级别精确定位错误，又能在 passage 级别快速筛查。现有检测器通常只在一个粒度上工作，Enoki 的多层级方法让高风险场景（医疗、法律、金融）的 LLM 部署更安全可控。对做 AI 产品的团队来说，幻觉检测正在从「nice to have」变成「must have」。

- **EN**：Enoki proposes multi-level hallucination detection — precise claim-level error localization plus fast passage-level screening. For high-stakes LLM deployment (healthcare, legal, finance), hallucination detection is shifting from 'nice to have' to 'must have.'
