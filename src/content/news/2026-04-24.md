### OpenAI 发布 GPT-5.5：指令遵循能力超越 Claude Opus 4.7

- **板块**：AI 工具动态
- **来源**：OpenAI Blog / X/@bindureddy
- **链接**：https://openai.com/index/introducing-gpt-5-5
- **TitleEN**：OpenAI Launches GPT-5.5, Beating Claude Opus 4.7 on Instruction Following

GPT-5.5 正式发布，LiveBench 评测多项指标领先，指令遵循能力被评为「极其出色」，实际表现优于 Claude Opus 4.7。但代价不菲：输出 token 定价 $30/1M，是 GPT-5.4 的两倍，也贵过 Opus 4.7。OpenAI 凭此重新夺回模型排行榜头把交椅。

- **EN**：GPT-5.5 is officially out and leads several LiveBench metrics. Its instruction following has been called 'exceptional,' outperforming Claude Opus 4.7 in practice. It comes at a steep price: output tokens cost $30 per million, double GPT-5.4 and more than Opus 4.7. With this release, OpenAI reclaims the top spot on the model leaderboards.

### VLAA-GUI：解决 AI GUI Agent「假完成」和「死循环」两大顽疾的新框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2604.21375
- **TitleEN**：VLAA-GUI Tackles False Completions and Infinite Loops in GUI Agents

做 GUI 自动化 Agent 的开发者都懂这两个痛点：Agent 明明没完成任务却宣布成功（早停），或者反复执行同一个失败操作（死循环）。VLAA-GUI 提出「何时停止、何时恢复、如何搜索」三模块架构，强制验证 UI 可观测的完成条件，对构建可靠 RPA/自动化产品的开发者有直接参考价值。

- **EN**：Anyone building GUI automation agents knows two pain points: agents that claim success before finishing a task, and agents that keep repeating the same failed action. VLAA-GUI introduces a three-module architecture covering when to stop, when to recover, and how to search. It enforces verification of completion conditions that are observable in the UI, offering direct guidance for building reliable RPA and automation products.

### DAVinCI：给 LLM 输出加「双重溯源验证」，对抗幻觉的新思路

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2604.21193
- **TitleEN**：DAVinCI: Dual Attribution and Verification to Combat LLM Hallucinations

LLM 幻觉在医疗、法律等高风险场景是硬伤。DAVinCI 框架提出「双重归因+验证」机制，让模型在生成声明时同时标注证据来源并自动核实。对做垂直行业 AI 产品（合规、医疗、法律）的开发者来说，这类可解释性框架是提升用户信任的关键工程方向。

- **EN**：LLM hallucinations are a critical flaw in high-stakes fields like healthcare and law. The DAVinCI framework introduces a dual attribution-and-verification mechanism: as the model generates claims, it cites their evidence sources and automatically fact-checks them. For developers building vertical AI products in compliance, healthcare, or law, interpretability frameworks like this are key to earning user trust.
