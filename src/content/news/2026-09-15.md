### Colibri：纯 C 实现、零依赖，让消费级硬件跑 744B–2.8T 参数 MoE 大模型

- **板块**：AI 论文
- **来源**：GitHub Trending
- **链接**：https://github.com/JustVugg/colibri
- **TitleEN**：Colibri: Run 744B–2.8T MoE Models on Consumer Hardware with Pure C

Colibri 是一个纯 C 编写、零外部依赖的轻量推理引擎，通过将存储、RAM 和 VRAM 统一为分层推理缓存（AI memory multitiering），支持在消费级和异构硬件上运行 744B 到 2.8T 参数的前沿 MoE 模型。对本地部署和边缘推理开发者而言，这是目前门槛最低、可玩性最高的超大模型本地运行方案之一。

- **EN**：Colibri is a pure C, zero-dependency inference engine that lets developers run frontier MoE models (744B to 2.8T parameters) on consumer hardware by treating storage, RAM, and VRAM as a unified inference memory hierarchy. It's arguably the most accessible path yet to running truly massive models locally without cloud costs.

### Occamy-1.0：35B 协作 Agent 专用模型，用效率换前沿推理的新思路

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.11977
- **TitleEN**：Occamy-1.0: A Cost-Efficient 35B Model Built for Multi-Step Agent Workflows

Occamy-1.0 是一个专为「协作 Agent」设计的 35B 模型，核心洞察是：大多数 Agent 工作流步骤并不需要顶级推理能力，而需要状态追踪、协调与错误恢复。通过在效率和能力之间取得帕累托最优，Occamy 为开发者提供了一个跑长流程 Agent 任务时成本远低于旗舰模型的可行替代方案。

- **EN**：Occamy-1.0 is a 35B model optimized for co-work agents that execute long, multi-step workflows. The key insight: most agent steps require state tracking and recovery, not frontier-scale reasoning. By targeting the Pareto frontier of capability vs. cost, it offers developers a far cheaper option for production agent pipelines without sacrificing reliability.
