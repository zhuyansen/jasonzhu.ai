### 新方法让Agent以潜在表示压缩工具输出

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.06500
- **TitleEN**：New Method Compresses Agent Tool Outputs Latently

论文提出让Agent直接消费工具输出的潜在表示，而不是把完整文本塞回上下文，从而减少多步任务中的token开销和噪声。若工程化成熟，复杂工作流可获得更长有效上下文、更低推理成本和更稳定的注意力分配。

- **EN**：The paper proposes representing tool observations in latent space instead of appending raw text to the model context. This could substantially reduce token usage and distraction during long agent workflows, giving developers longer effective context windows, lower inference costs, and more reliable attention allocation in multi-step tasks.

### StepX重新设计扩散模型的多教师蒸馏流程

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.04386
- **TitleEN**：StepX Rethinks Multi-Teacher Diffusion Distillation

StepX指出，扩散模型在完成能力蒸馏后再压缩到少步采样，往往会明显损失指令遵循、文字渲染和审美质量，并重新设计多教师训练流程。对开发者的价值在于，低步数图像生成不应只追求速度，还需控制能力退化。

- **EN**：StepX shows that compressing a capable diffusion model into few-step sampling can significantly degrade instruction following, text rendering, and visual quality. It redesigns multi-teacher distillation to address this tradeoff, reminding developers that fast image generation must be evaluated for capability retention, not speed alone.

### TB-MathModel为数学建模Agent提供可验证基准

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.08237
- **TitleEN**：TB-MathModel Benchmarks Verifiable Modeling Agents

TB-MathModel面向完整数学建模任务评估Agent：从现实问题抽象、提出假设，到计算解答并给出可辩护建议，同时检查答案是否可信且符合物理约束。它比只评估某一步或依赖LLM裁判更接近真实应用质量。

- **EN**：TB-MathModel evaluates agents on complete mathematical modeling tasks, including abstraction, assumptions, computation, and defensible recommendations, while checking credibility and physical feasibility. Compared with fragment-based tests or LLM-only judging, it offers developers a more realistic way to measure whether an agent can solve end-to-end analytical problems.

### Muir用敏感度门控改进线性注意力记忆

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.08376
- **TitleEN**：Muir Improves Linear Attention Memory Updates

Muir提出按更新敏感度分配门控，并改进线性注意力的匹配滤波读出机制，针对固定状态记忆在长上下文中的信息写入和擦除问题。若验证有效，可帮助开发者构建更低显存、近似线性复杂度的长序列模型。

- **EN**：Muir introduces sensitivity-aware gating and matched-filter readout for linear attention, targeting how information is erased and written into fixed-size memory states. If validated in larger systems, the approach could help developers build long-context models with lower memory use and near-linear computational scaling.
