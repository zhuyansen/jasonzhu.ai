### 字节开源 UI-TARS-desktop：多模态 Agent 桌面版正面对标 OpenAI Operator

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/bytedance/UI-TARS-desktop
- **TitleEN**：ByteDance Open-Sources UI-TARS-desktop to Rival OpenAI Operator

ByteDance 开源 TARS 多模态 Agent 栈，包含 **Agent TARS** 通用栈和 **UI-TARS-desktop** 桌面端 GUI Agent。能像 OpenAI Operator 一样直接操作浏览器、桌面应用，但完全开源、可本地部署。国产多模态 Agent 第一次在桌面操作能力上触及 OpenAI 主场。

- **EN**：ByteDance open-sourced its TARS multimodal agent stack, which includes Agent TARS, a general-purpose stack, and UI-TARS-desktop, a desktop GUI agent. Like OpenAI Operator, it can directly control browsers and desktop apps, but it is fully open source and can run locally. This is the first time a Chinese multimodal agent has competed with OpenAI on desktop control.

- **EN**：Most self-evolving LLMs still rely on LLM judges for open-ended tasks, which limits their capabilities and invites reward hacking.
