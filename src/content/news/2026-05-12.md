### 字节开源 UI-TARS-desktop：多模态 Agent 桌面版正面对标 OpenAI Operator

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/bytedance/UI-TARS-desktop

ByteDance 开源 TARS 多模态 Agent 栈，包含 **Agent TARS** 通用栈和 **UI-TARS-desktop** 桌面端 GUI Agent。能像 OpenAI Operator 一样直接操作浏览器、桌面应用，但完全开源、可本地部署。国产多模态 Agent 第一次在桌面操作能力上触及 OpenAI 主场。

### CloakBrowser 开源：源码级修改 Chromium 指纹，绕过所有反爬检测

- **板块**：Skills 生态
- **来源**：GitHub Trending

### G-Zero 论文：完全 zero-data 自我进化的 LLM 框架

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.09959

主流 self-evolving LLM 在开放任务上仍依赖 LLM judge，导致能力瓶颈和 reward hacking。G-Zero 提出 **verifier-free 协同进化框架**，用 Hint-δ 内在 reward 驱动 generator 自我提升，**完全不需要外部数据或人工标注**。对做 RL 后训练或自学习系统的开发者：这可能是「AlphaZero for LLM」式的关键拼图。
