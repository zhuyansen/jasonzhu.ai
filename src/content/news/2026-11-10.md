### CPU-ARC把已完成推理变成可复用缓存

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.09891
- **TitleEN**：CPU-ARC Reuses Agent Reasoning on CPUs

CPU-ARC提出Agent推理缓存：模型先解决一次任务，再将可复用的解法编译成可在CPU执行的缓存，后续实例无需每次重新推理。它可能减少重复调用大模型的成本，提升规则明确任务的吞吐量。

- **EN**：CPU-ARC turns completed agent reasoning into reusable caches that can execute on CPUs, allowing later task instances to reuse solutions instead of invoking an LLM from scratch. This could reduce inference costs and improve throughput for repetitive, well-structured workflows.

### LowRAM在测试时压缩KV缓存降低显存

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.07025
- **TitleEN**：LowRAM Compresses KV Cache at Runtime

LowRAM发现注意力中的Value可由对应Key预测，并在测试时为每个注意力头拟合轻量预测器，从而压缩KV缓存。该方法不依赖重新训练，有望在长上下文和高并发推理中降低显存占用、提升批处理能力。

- **EN**：LowRAM compresses the KV cache by predicting attention values from their corresponding keys with lightweight per-head predictors fitted at test time. Because it requires no retraining, the method could reduce memory use and improve batching for long-context, high-concurrency inference.

### IWIBench评估无梯度模型权重注入能力

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.08647
- **TitleEN**：IWIBench Tests Gradient-Free Weight Editing

IWIBench建立了无梯度权重注入评测框架，测试大模型能否直接修改小模型权重来改变词汇关联、输出格式或事实知识。对开发者而言，这为轻量更新模型能力提供了统一指标，也帮助判断这种模型编辑是否可靠。

- **EN**：IWIBench introduces a benchmark for gradient-free intra-weight injection, measuring whether one model can directly alter another model’s behavior, facts, or output formats. It gives developers a way to assess lightweight model editing and determine whether such updates are reliable enough for production.
