### Claude 分享链接被谷歌索引：用户私聊内容意外暴露公网

- **板块**：AI 工具动态
- **来源**：TechCrunch AI
- **链接**：https://techcrunch.com/2026/07/27/psa-your-claude-shared-chats-and-artifacts-may-have-ended-up-on-google/
- **TitleEN**：Claude Shared Chats Indexed by Google, Exposing Private Conversations

Anthropic 的「分享对话」功能生成的公开链接被 Google 和 Bing 抓取索引，导致用户认为私密的对话内容出现在搜索结果中。问题根源在于页面缺少 noindex 标签，仅靠 robots.txt 拦截爬虫远不够。目前已引发大量用户担忧，Anthropic 正在处理中。

- **EN**：Claude's 'share chat' feature generated publicly accessible links that were indexed by Google and Bing, exposing conversations users expected to be private. The root cause: shared pages lacked noindex meta tags, making robots.txt-only protection insufficient. A reminder that 'share link' doesn't mean 'controlled access.'

### Agent 上下文管理新框架：把「记忆爆炸」当架构问题而非存储问题

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.21503
- **TitleEN**：Agentic Context Management: Treat Memory Bloat as Architecture, Not Storage

这篇论文指出生产级 AI Agent 失败的主因不是推理能力不足，而是上下文管理失控——对话历史、超长 prompt、工具调用输出不断堆积导致 token 成本失控、关键信息遗漏。论文提出应把上下文视为「生命周期与架构问题」而非存储检索问题，对构建长时运行 Agent 的开发者有直接指导价值。

- **EN**：This paper argues production agent failures aren't about poor reasoning—they're about context mismanagement: ballooning histories, oversized tool outputs, and cross-turn amnesia. The fix requires treating context as a lifecycle and architecture problem, not a RAG retrieval problem. Directly actionable for anyone building long-running agents.

### Multi-Head Latent Control：让 LLM Agent 在推理时自主决定「继续/升级/调工具/放弃」

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2607.14277
- **TitleEN**：Multi-Head Latent Control: Unified Decision Interface for LLM Agents at Inference Time

现有 Agent 框架靠 prompt 路由或外部编排决定「是否升级到更强模型、是否调用工具、是否拒绝回答」，每种决策都是独立模块。这篇论文提出 Multi-Head Latent Control，在模型内部用统一的潜空间接口同时处理所有决策类型，让 Agent 行为更可靠、成本更低——对构建复杂 multi-agent 系统的工程师有参考价值。

- **EN**：Current agents handle routing, tool-calling, model escalation, and abstention through separate prompt-level or external modules. Multi-Head Latent Control proposes a unified internal latent interface for all these decisions at inference time, promising more reliable and cheaper agent behavior—highly relevant for multi-agent system builders.
