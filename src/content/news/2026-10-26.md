### IF-MAP：多智能体系统该先优化哪个Agent

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.24383
- **TitleEN**：IF-MAP Identifies Which Agent to Improve First

多智能体系统里，把每个 Agent 都调优一遍成本太高。IF-MAP 借鉴影响函数的思路，估算优化哪个 Agent 能带来最大的整体收益，而不是只盯着谁该为失败负责。开发者资源有限时，可以据此把提示词和微调预算花在刀刃上。

- **EN**：Improving every agent in a multi-agent system is expensive. IF-MAP uses influence-function ideas to estimate which agent's improvement yields the biggest system-level gain, rather than just assigning blame for failures. It helps developers spend limited prompt-tuning or fine-tuning budget where it matters most.

### T²Quant：按任务和步骤动态量化扩散语言模型

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.31198
- **TitleEN**：T²Quant: Task- and Time-Aware Quantization for Diffusion LMs

研究发现，扩散语言模型对量化的敏感度会随任务和去噪步骤变化，而且无需标注就能提前预测。据此提出的 T²Quant 采用混合精度量化，在关键步骤保留高精度。这意味着扩散模型有望在更小显存上部署，同时尽量少掉精度。

- **EN**：Researchers found that diffusion language models' sensitivity to quantization varies by task and denoising step, and that this can be predicted without labels. Their T²Quant method applies mixed precision accordingly, keeping key steps precise. It could let diffusion LMs run on less memory with minimal quality loss.

### LLM-Attacker：统一评测拆分式大模型的隐私风险

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.22722
- **TitleEN**：LLM-Attacker Unifies Privacy Red-Teaming for Split LLMs

拆分式大模型把原始文本留在客户端，只把中间表示发给服务器，但这些中间表示仍可能被还原成原文。LLM-Attacker 提供统一的红队框架，记录攻击条件并支持复现和对比。做端云协同或隐私敏感应用的开发者，可以用它检验“数据不出端”的承诺是否站得住。

- **EN**：Split LLMs keep raw text on the client and send only intermediate representations to a server, yet these can still be reconstructed into text. LLM-Attacker offers a unified red-team framework that records attack settings for reproducible comparison, helping developers verify whether 'data stays on device' privacy claims actually hold.
