### Chrome DevTools 官方 MCP：编码 Agent 可直接操控浏览器调试

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/ChromeDevTools/chrome-devtools-mcp
- **TitleEN**：Chrome DevTools Launches Official MCP for Coding Agents

Chrome DevTools 团队亲自发布官方 MCP 服务器，让 Claude Code、Cursor、Copilot 等编码 Agent 可直接控制实时 Chrome 浏览器，支持自动化操作、深度调试和性能分析。不是第三方适配，是 DevTools 官方出品，稳定性和长期维护有保障，前端调试正式进入 Agent 工作流。

- **EN**：The Chrome DevTools team has released its own official MCP server, enabling coding agents like Claude Code, Cursor, and Copilot to directly control a live Chrome browser. Capabilities include automated operations, deep debugging, and performance profiling. As a first-party release — not a community port — it guarantees stability and long-term maintenance, formally bringing browser debugging into agent workflows.

### LoREnc 论文：无需重训练，给大模型和 LoRA 适配器加密防盗

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2605.13163
- **TitleEN**：LoREnc Encrypts LLMs and LoRA Adapters Without Retraining

论文提出 LoREnc 框架，通过谱截断和补偿技术，无需重训练、无需原始数据集，即可对基础模型和 LoRA 适配器加密，防止知识产权泄露和模型恢复攻击。对部署私有微调模型的开发者来说，这是一个开箱即用的安全防护方案。

- **EN**：A new paper introduces LoREnc, a framework that encrypts base models and LoRA adapters using spectral truncation and compensation techniques — requiring no retraining and no access to the original dataset. It protects against IP leakage and model-recovery attacks, offering developers who deploy private fine-tuned models a practical, out-of-the-box security solution.

- **板块**：AI 论文
- **来源**：HuggingFace Papers
