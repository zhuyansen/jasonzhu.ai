### Gemini推出面向多模态决策的Decisions API

- **板块**：AI 工具动态
- **来源**：Google AI Blog
- **链接**：https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/
- **TitleEN**：Google Launches Gemini Decisions API

Google推出Gemini Decisions API，专门面向快速、可校准的多模态决策任务。对开发者而言，它可能减少自行搭建分类、判断和置信度校准链路的工作，适合接入业务自动化流程。

- **EN**：Google introduced the Gemini Decisions API for fast, calibrated multimodal decisions. Instead of building separate classification and confidence-calibration pipelines, developers can use a dedicated interface for business automation, visual inspection, routing, and other applications that require reliable decisions rather than open-ended text generation.

### Embodied First Exam测试编码Agent能否控制机器人

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.12177
- **TitleEN**：Embodied First Exam Tests Coding Agents

Embodied First Exam提出面向机器人的统一评测，让编码Agent自行选择控制方式，并在真实物理约束下完成任务。对开发者的重要性在于，它把“会写控制代码”与“能安全完成动作”区分开来。

- **EN**：Embodied First Exam introduces an agent-native benchmark for robotics in which coding agents choose their own control strategies under physical-world constraints. For developers, it separates the ability to generate control code from the harder requirement of reliably executing safe, effective actions across different robot platforms.

### 扩散语言模型用动态重掩码提升推理效率

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.10486
- **TitleEN**：Dynamic Remasking Improves Diffusion LM Reasoning

论文为扩散语言模型设计频率感知的动态重掩码策略，根据题目难度分配更多推理计算，而不是固定迭代次数。对开发者而言，这意味着扩散式模型有望在易题上更快、难题上更稳。

- **EN**：The paper proposes frequency-aware remasking for diffusion language models, allocating more inference computation to difficult problems instead of using a fixed decoding schedule. For developers, this suggests a practical path to make diffusion-based generation faster on easy tasks while preserving quality on challenging reasoning workloads.

### 新基准系统评估Agent机器人安全风险

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2611.14115
- **TitleEN**：LEASH Benchmarks Safety in Agentic Robotics

LEASH提出RoboRisk安全基准，包含92项模拟任务和13类风险，用于评估GPT、Claude等基础模型控制机器人时的失误。它为机器人Agent提供了比演示效果更接近实际部署的安全检查清单。

- **EN**：LEASH introduces RoboRisk, a safety benchmark with 92 simulated tasks across 13 risk categories for evaluating foundation models controlling robots. It gives developers a concrete way to test unsafe behavior, complementing capability demos with deployment-oriented checks before models are connected to physical systems.
