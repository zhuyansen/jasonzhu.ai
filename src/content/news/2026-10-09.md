### REA：一个MCP让Agent逆向分析任意应用和二进制

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/morluto/rea
- **TitleEN**：REA: One MCP to Reverse Engineer Anything with Agents

开源项目REA把逆向工程能力封装成一个MCP。编码Agent可以从应用行为一路分析到原生二进制，弄清某个功能背后的实现原理。它把原本需要专业工具链和经验的逆向工作交给Agent，适合做竞品研究、调试和安全分析的开发者。

- **EN**：REA packages reverse engineering into a single MCP server. Coding agents can analyze apps from runtime behavior down to native binaries and explain how a feature works. Work that once required specialist toolchains and expertise becomes accessible through agents, which is useful for competitive research, debugging and security analysis.

### 新论文：KV缓存存盘复用，5000万token记忆更快更省

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2610.10845
- **TitleEN**：50M-Token KV Memory on Disk Beats Recompute

研究测试了开源包galahad-kv。它把每约1.6万token的KV状态加密存到本地NVMe，之后按字节精确加载，不用重新计算。团队在单张H100上配合vLLM和Gemma 4跑了5000万token，速度和成本都优于重算。对开发者的意义在于，长上下文的Agent和RAG应用可以用更低成本获得“长期记忆”。

- **EN**：The paper tests the open-source package galahad-kv. It saves the KV state of each ~16K-token block to encrypted local NVMe and reloads it byte-exact instead of recomputing. Running 50M tokens on one H100 with vLLM and Gemma 4, it was faster and cheaper than recompute. Long-context agents and RAG apps get cheaper long-term memory.

### AutoResearch生产级实测12周：失败模式与多Agent方案

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2609.30541
- **TitleEN**：AutoResearch at Production Scale: Failures and Multi-Agent Fix

团队把Karpathy提出的AutoResearch范式（LLM反复修改训练脚本，只保留能提升指标的改动）用在生产推荐系统的embedding优化上，连续跑了12周。论文总结了在高算力成本下的典型失败模式，并提出多Agent框架。想让Agent自动做实验调参的团队可以参考这些踩坑经验。

- **EN**：The team ran Karpathy's AutoResearch paradigm, where an LLM edits training scripts and keeps only changes that improve a metric, for 12 weeks on production recommendation embeddings. The paper documents failure modes under expensive multi-GPU iterations and proposes a multi-agent framework. Teams automating experimentation with agents get practical lessons.
