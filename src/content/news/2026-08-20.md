### LEGO-RL：让编程 Agent 的强化学习直接在真实执行环境中跑通

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.17393
- **TitleEN**：LEGO-RL: Native RL Training Framework Bridging Agent Harnesses and Policy Gradients

训练编程 Agent 时，真实执行环境（agent harness）和 RL 训练框架之间存在严重错位——环境崩溃会污染奖励信号，训练与推理行为也会脱节。LEGO-RL 直接将 RL 训练嵌入原生 harness，对 Claude Code / Codex 等工具链背后的 Agent 训练方式有直接参考价值。

- **EN**：LEGO-RL solves a core problem in training coding agents: misalignment between real execution harnesses (tool calls, repo context) and RL policy updates. By embedding RL natively into the harness, it prevents reward hacking and train-inference gaps — directly relevant to anyone building or fine-tuning agentic coding systems.

### PTXBench：首个评估 LLM 优化 GPU 内核能力的基准，H100/B200 实测

- **板块**：AI 论文
- **来源**：HuggingFace Papers
- **链接**：https://huggingface.co/papers/2608.17379
- **TitleEN**：PTXBench: First Benchmark for LLMs Optimizing GPU Kernels on H100 and B200

PTXBench 专门测试 LLM 能否利用架构级 PTX 指令优化 GPU 内核（GEMM、Attention 等），在 H100 和 B200 上评估功能正确性与实际加速效果。结论是现有模型在复杂 attention backward 任务上成功率仍大幅下滑——AI 自动优化算子远未成熟，对 AI 基础设施工程师是重要参考。

- **EN**：PTXBench tests whether LLMs can use architecture-specific PTX instructions to optimize GPU kernels on H100 and B200. Results show current models still fail significantly on complex attention backward tasks — a wake-up call for anyone betting on AI-automated kernel optimization in production AI infra.
