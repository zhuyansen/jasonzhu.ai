### Apache Maka 孵化：本地优先、可恢复的 Agent 工作区

- **板块**：Skills 生态
- **来源**：GitHub Trending
- **链接**：https://github.com/apache/maka
- **TitleEN**：Apache Maka Incubating: Local-First, Recoverable AI Agent Workspace

Apache 基金会正在孵化 Maka——一个本地优先的 AI Agent 工作区，将模型消息、工具调用、权限决策等所有事件以追加日志方式记录，支持执行恢复。对开发者而言，这意味着 Agent 任务可调试、可回溯、可审计，解决了当前 Agent 框架「运行完就消失」的黑盒痛点。

- **EN**：Apache Maka (Incubating) is a local-first AI agent workspace that records all model messages, tool calls, permission decisions, and termination events as an append-only recoverable log. For developers, this solves the 'black box' problem of current agent frameworks by enabling full auditability, replay, and recovery of agent execution.
