Hugging Face 的 Learn 板块今年**偷偷加到了 12 门课**，一半是今年新出的。

跟前面九家平台都不一样——别家教你「怎么用 AI」，**HF 教你怎么自己跑、自己微调、自己发布模型**。学完，你手上是有真东西的。

**主入口**：[huggingface.co/learn](https://huggingface.co/learn)

下面精选 10 门最值得排队的课。

---

## 1. LLM Course（原 NLP Course，今年重写）

🔗 [huggingface.co/learn/llm-course](https://huggingface.co/learn/llm-course)

从「transformer 是什么」一路讲到 fine-tune + 部署上 Hub。今年完全重写过，是 HF Learn 的主干课。

## 2. Agents Course（今年新出，最 hot）

🔗 [huggingface.co/learn/agents-course](https://huggingface.co/learn/agents-course)

端到端做 agent，含 **smolagents / LlamaIndex / LangGraph** 三套实现。今年最热门的一门，做 Agent 必刷。

## 3. MCP Course（今年新出）

🔗 [huggingface.co/learn/mcp-course](https://huggingface.co/learn/mcp-course)

HF 官方 MCP 教程，跟 Anthropic 的 MCP 课互补——这边偏 HF 生态接入。

## 4. smol course（今年新出，短小精悍）

🔗 [huggingface.co/learn/smol-course](https://huggingface.co/learn/smol-course)

专讲 post-training，是大模型微调最精炼的一门。时间紧就看它。

## 5. Robotics Course（今年新出，用 LeRobot 库）

🔗 [huggingface.co/learn/robotics-course](https://huggingface.co/learn/robotics-course)

AI + 机器人入口——**这是前面九家平台全都没有的领域**。

## 6. Diffusion Course

🔗 [huggingface.co/learn/diffusion-course](https://huggingface.co/learn/diffusion-course)

想做 Stable Diffusion / Flux 二次开发的必修课。

## 7. Computer Vision Course（社区合作）

🔗 [huggingface.co/learn/computer-vision-course](https://huggingface.co/learn/computer-vision-course)

涵盖 ViT、SAM、DINO，比传统 CV 课新很多。

## 8. Audio Course

🔗 [huggingface.co/learn/audio-course](https://huggingface.co/learn/audio-course)

做语音、音乐生成、TTS 的人来这里补齐。

## 9. Deep RL Course

🔗 [huggingface.co/learn/deep-rl-course](https://huggingface.co/learn/deep-rl-course)

强化学习经典入门，配 HF 自己的训练环境。

## 10. Open-Source AI Cookbook

🔗 [huggingface.co/learn/cookbook](https://huggingface.co/learn/cookbook)

实战 notebook 合集。学完前面 9 门，来这里抄实战代码。

## HF 独有的一个杀手锏

> **所有课程都能在 Spaces 上直接跑——不用本地装环境，GPU 也是 HF 出。**

前面九家平台没有一家能做到这点。对没有本地显卡的人，这一条就足够让 HF 排进必选名单。

## 我的学习建议

1. **主干走 LLM Course**：今年重写过，是理解整个 HF 生态的地基
2. **Agents Course 优先级最高**：今年最热方向，三套 Agent 实现一次学全
3. **Robotics Course 是独门**：想进 AI + 机器人的人，这是稀缺入口
4. **Cookbook 放最后**：前 9 门建立能力，Cookbook 用来抄实战代码
5. **善用 Spaces**：没显卡也能跑完所有课，这是 HF 的最大福利
