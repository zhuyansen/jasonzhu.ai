AWS Skill Builder 是大厂里**课程数量最多**的一家——1500 门课里有 **600 门免费**。

但它的坑也最深：**直接搜索会被付费课刷屏**，免费的优质课沉在底下根本看不见。

**正确姿势**：进 [skillbuilder.aws](https://skillbuilder.aws/) 后，**第一件事**——顶部筛选器把 **Price 勾选 Free**，然后**按 Learning Plan（学习路径）走，别按 Course 单门搜**。路径里的课都是被串好的，顺序学下来不会乱。

---

## 生成式 AI 三档路径（全免费）

按你的角色选一档。

### 1. Generative AI Learning Plan for Decision Makers（非技术）

**3 门课**，面向管理者 / 决策者。讲清楚两件事：

- 生成式 AI 到底是什么
- AI 项目怎么立项、怎么评估

适合需要给老板 / 团队讲明白 GenAI 的人，全程不碰代码。

### 2. Generative AI Learning Plan for Developers（开发者）

面向工程师的核心路径。重点是：

- **Amazon Bedrock** 上手
- 模型微调
- **RAG 落地**

想在 AWS 生态里做 AI 应用的开发者，这条是主线。

### 3. Building Generative AI Applications Using Amazon Bedrock

单门重点课，端到端做一个 Bedrock 应用，覆盖：

- **Knowledge Bases**（知识库）
- **Agents**（智能体）

是路径 2 的实战延伸，想真正动手做产品的必刷。

## 我的学习建议

1. **务必走路径不走单门**：AWS 的免费课散落在 1500 门里，只有 Learning Plan 帮你串好顺序
2. **角色对应**：管理者 → Decision Makers；工程师 → Developers + Bedrock 实战课
3. **Bedrock 是 AWS 生态的核心**：想在 AWS 上做 AI 应用，Bedrock 上手 + Knowledge Bases + Agents 是绕不开的三件套
4. **DeepRacer 别错过**：强化学习抽象难学，DeepRacer 用赛车游戏化方式入门，体验极好
5. **备考资料免费，证书考试收费**：和其他大厂一样，准备阶段零成本，最后考证才花钱
