Anthropic 在 2026 年 3 月 12 日推出了 **Claude Certified Architect** 认证，配套 13 门自学课程。重点信息：

- **课程全部免费**：无订阅、无付费墙、无需注册即可开学
- **认证考 $99**：准备阶段零成本，只在最后考试要钱
- **平台入口**：[anthropic.skilljar.com](https://anthropic.skilljar.com)

下面按 **12 周路线图**整理 Weeks 1-9 的 8 门关键课程，每门都附官方直达链接。

---

## Weeks 1-2·基础阶段（Foundations）

### 1. Claude 101（Anthropic Academy · 免费）

🔗 [anthropic.skilljar.com/claude-101](https://anthropic.skilljar.com/claude-101)

涵盖 Claude 的使用模式、能力范围、Projects、Artifacts、Skills、Connectors 以及实际工作流。

> ⚠️ **即使你已经用 Claude 几个月，也建议从这里开始**——考试全程都假设你掌握这些基础知识。

### 2. AI Fluency: Framework and Foundations（Anthropic Academy · 免费）

🔗 [anthropic.skilljar.com/ai-fluency-framework](https://anthropic.skilljar.com/ai-fluency-framework-foundations)

与大学教授联合开发，讲解有效 AI 协作的**四大原则**：

- **Delegation**（委托）：什么交给 AI、什么自己做
- **Description**（描述）：怎么把意图说清楚
- **Discernment**（辨别）：怎么判断 AI 输出对错
- **Diligence**（勤奋）：人机协作中的核查责任

这是人类与 AI 合作的理论框架，帮助建立正确心态。

---

## Weeks 3-5·Claude API 应用构建（旗舰课）

### 3. Building Applications with the Claude API（Anthropic Academy · 免费 · 8.1 小时）

🔗 [anthropic.skilljar.com/claude-with-the-api](https://anthropic.skilljar.com/claude-with-the-api)

**这是整个路径的旗舰课程**。从基础 API 调用到高级 agentic 架构、RAG 管道全覆盖：

- 系统提示
- 工具调用
- 流式传输
- 认证
- 结构化输出
- 上下文管理
- 生产模式

直接对应考试 Domain 1、4、5。

> 📚 **补充资源**：[Anthropic 官方 API 文档](https://docs.anthropic.com)

## Weeks 6-7·Model Context Protocol（MCP 工具协议）

### 4. Introduction to Model Context Protocol（Anthropic Academy · 免费）

🔗 [anthropic.skilljar.com/introduction-to-mcp](https://anthropic.skilljar.com/introduction-to-mcp)

MCP 基础知识：**工具、资源、提示**。直击考试 Domain 2（Tool Design & MCP Integration）。

### 5. Model Context Protocol Advanced（Anthropic Academy · 免费）

🔗 [anthropic.skilljar.com/model-context-protocol-advanced](https://anthropic.skilljar.com/model-context-protocol-advanced)

用 Python 深度构建 MCP 服务器和客户端，包含：

- 采样
- 通知
- 文件系统访问
- 生产传输机制

> 📚 **补充资源**：[MCP 官方规范文档](https://modelcontextprotocol.io)

## Weeks 8-9·Claude Code 开发工作流

### 6. Claude Code in Action（Anthropic Academy · 免费）

🔗 [anthropic.skilljar.com/claude-code-in-action](https://anthropic.skilljar.com/claude-code-in-action)

Claude Code 完整配置：

- `CLAUDE.md` 层级结构
- 路径特定规则
- 自定义 slash commands
- Skills
- Hooks
- CI/CD 集成

### 7. Claude Code on Coursera（Vanderbilt University · 免费审计）

🔗 [coursera.org/specializations](https://www.coursera.org/specializations/generative-ai-software-engineering)

具体模块：**Claude Code: Software Engineering with Generative AI Agents**，Dr. Jules White 教授主讲，属于 "Generative AI Software Engineering Specialization"。聚焦 **AI-first 开发**和 **"Best of N" 模式**。

> 💡 **免费审计无需付费**，与 Anthropic 官方课程视角不同，建议交叉学习。

### 8. Building Skills for Claude Code（Anthropic Academy · 免费）

🔗 [anthropic.skilljar.com/building-skills-for-claude-code](https://anthropic.skilljar.com/building-skills-for-claude-code)

专门教如何**创建、配置、分发可复用的 Skills**，直接对应考试中「生产级工作流」要求。

## 我的学习建议

1. **不要跳过 Claude 101**：考试默认你掌握 Projects / Artifacts / Skills / Connectors 基础概念
2. **旗舰课要刷两遍**：Building Applications with the Claude API 信息密度极高，一遍刷不完
3. **MCP 部分必动手**：基础课看完直接搭一个 MCP server，比看 10 节理论强 10 倍
4. **Claude Code 课和 Coursera 课交替学**：两边视角不同，一个偏 Anthropic 官方实践，一个偏学院派 AI-first 工程
5. **考试 $99 物有所值**：准备过程零成本，证书可以挂简历 / LinkedIn
