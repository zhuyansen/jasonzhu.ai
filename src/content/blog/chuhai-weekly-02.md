每周数一遍 7 家收款平台（Stripe、Gumroad、Lemon Squeezy、Polar、Creem、Dodo、Paddle）上新挂出收款链接的网站，看看大家在卖什么、什么起量了、哪些需求还没人做。

## 本周数字

- 链接图本周新收录 **6,152 个卖家**，其中卖软件的 1,069 个，AI 产品 596 个。
- 看月度更稳：10 月前 18 天已收录 1.24 万个新卖家，超过 9 月全月的 1.1 万。卖软件的比例两个月都在 20% 左右，没有再往上走。
- 新一代收款平台 10 月还没过完，新卖家数已经超过 9 月全月：Polar 358 个（9 月 263），Lemon Squeezy 572 个（9 月 431），Dodo 111 个（9 月 107），Creem 55 个（9 月 44）。

> 单周数字波动很大：链接图是一批一批收录新链接的，见过每周 1,100 到 6,500 的区间。看趋势要看月度。

## 本周值得看的 5 个新产品

1. **1VideoTool**（1videotool.com，Lemon Squeezy 收款）：装在 Mac 或 Windows 上的视频工作室，让 Claude Code、Codex 这类 coding agent 通过 MCP 来操作，一句话出一条带配音和配乐的成片，文件留在本地。免费版能导出 25 条，Pro 买断 $29 到 $89。
2. **Catenary**（thecatenary.app）：给 coding agent 用的 IDE，编辑器、终端和多个 agent 在一个窗口里，每个任务单开分支和 worktree。Pro 买断 $19。
3. **Memora**（memora.aircoded.app，Polar 收款）：Mac 上录会议（麦克风加系统声音），用 Whisper 在本地转写，音频不上传，导出 Markdown 给 Obsidian。买断 €29。
4. **ReceiptRadar**（receiptradar.belkins.app）：把收据转发到一个邮箱，自动识别、按 QuickBooks 科目分好类，推成待审批的分录。目标是每月处理 50 到 500 张收据的小公司和记账员，$149/月，还在预售。
5. **GumLeaf**（getgumleaf.com）：发短信提问拿答案，能走卫星短信，没网也能问天气、急救、饮水安全。给徒步露营的人、用老人机的人。$4.99/月。

## 本周一个打法：给 coding agent 做配套，买断制收费

本周卖软件的新卖家里，大约 50 个产品的介绍直接点名 Claude Code、Codex 或 MCP。它们不做 agent 本身，做 agent 周边：

- **多 agent 工作台**：终端、看板、IDE，把几个 agent 放在一个窗口里，各开一个 worktree。
- **收拾残局**：清理 agent 在 Mac 上留下的缓存和媒体文件、会话回滚、额度用量追踪。
- **给 agent 加能力**：视频、邮件、数据库结构、记忆，做成 MCP 让 agent 调用。
- **配置文件生成器**：回答几个问题，生成 CLAUDE.md 和 AGENTS.md。

很多是本地优先、一次买断，价格在 $19 到 $89 之间。这类产品吃的是 agent 用户的具体痛点，搜索词也新、竞争少；风险是平台自己随时可能把功能做进去。

## 收款平台动态

- **Dodo Payments**：10 月 12 日的版本加了多订阅合并结账（一张发票，各自续费），新增 GCash（菲律宾）、AlipayHK 和 FPS（香港）、Touch 'n Go（马来西亚）、印度的 Apple Pay。[来源](https://dodopayments.com/blogs/newsletter-october12)
- **Polar**：10 月 8 日发文说要把产品重做成「计量、权益、计费」的底座，面向按用量收费和 agent 类产品，包括本地计量、用代码定义定价、人和机器统一成一种客户。还没有发布日期，正在招设计合作伙伴。[来源](https://polar.sh/blog/building-the-next-evolution-of-polar)
