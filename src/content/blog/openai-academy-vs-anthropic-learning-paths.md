> **结论先放：两家都免费，路径互补，省下被割韭菜报班的钱直接刷官方就行。**

两家头部 AI 公司——OpenAI 和 Anthropic——都已经把官方学习课程做成**完全免费、对所有人开放**的产品。两家的设计哲学截然不同：

- **Anthropic**：认证驱动。13 门结构化课程 + $99 工程师认证证书
- **OpenAI**：全民驱动。直播 + 录播 + 社区 + 资源库，覆盖个人到企业 IT admin

这篇按 **10 周路线图**整理 OpenAI Academy 全部 15 门课程，每门附官方直达链接，并在最后给出与 Anthropic 路径的对比清单。

**OpenAI Academy 平台入口**：[academy.openai.com](https://academy.openai.com)（需注册账号）

---

## Weeks 1-2·ChatGPT 基础（Foundations）

### 1. ChatGPT 101: A Guide to Your AI Superassistant（录播 · 44 分钟 · 免费）

🔗 [academy.openai.com](https://academy.openai.com)

OpenAI 团队亲讲，覆盖 ChatGPT 各模型、核心能力、最佳提示实践。新用户从这里开始。

### 2. ChatGPT Fundamentals（资源页 · 免费）

工作场景下 ChatGPT 基础能力速览，配合 101 视频食用。**定位类似 Anthropic 的 Claude 101**。

---

## Weeks 3-4·提示工程进阶（Prompting）

### 3. Introduction to Prompt Engineering（录播 · 免费）

由 OpenAI prompt 团队亲讲，覆盖 prompt 基本结构、常见误区、改写策略。

### 4. Mastering Prompts: The Key to Getting What You Need from ChatGPT（录播 · 免费）

Prompting 进阶，覆盖跨模型、多步任务、长上下文的提示工程。

### 5. Prompting Resource Hub（资源页 · 免费）

工作场景 prompt 模板和最佳实践，按场景分类，**可当成 prompt 速查表**用。

---

## Weeks 5-6·进阶工作流与 Skills（Workflows）

### 6. ChatGPT 102: Leveraging AI to Do Your Best Work（录播 · 40 分钟 · 免费）

进阶篇旗舰课。覆盖 **Deep Research（深度研究）、Projects（项目）、Custom GPTs（自定义 GPT）** 三大高级功能的实操。

### 7. Skills（资源页 · 免费）

把日常重复工作流变成 ChatGPT 可复用 Skill 的具体方法，**对应 Anthropic 路径里的 "Skills" 课程**。

### 8. ChatGPT for Any Role（资源页 · 免费）

不同岗位（市场 / 销售 / 设计 / 法务 / 财务 / HR）的 ChatGPT 用法清单。

## Weeks 7-8·开发者方向（Builder / Codex）

### 9. Introduction to Codex（录播 · 60 分钟 · 免费）

Codex 入门 webinar 回放。覆盖 Codex 的能力范围、安装、基本工作流，**企业部署 Codex 之前必看**。对应 Anthropic 路径里的 Claude Code in Action。

### 10. Codex Fundamentals（直播事件 · 免费）

2026 年 5 月 15 日 OpenAI 工程师直播 Codex 在企业开发场景的最佳实践，错过可看录播。

### 11. Solution Accelerator: Voice Solutions（资源页 · 免费）

用 OpenAI Realtime API 构建 voice agent 的完整方案包，含**架构图 + 代码 + 部署指南**。

## 两条路径的核心差异（一句话版）

| 维度 | Anthropic | OpenAI Academy |
|------|-----------|----------------|
| **设计哲学** | 认证驱动 | 全民驱动 |
| **课程数** | 13 门结构化 | 15+ 门 + 资源库 |
| **认证** | ✅ Claude Certified Architect（$99）| ⏳ 2026 年中陆续推出 |
| **学习路径** | 12 周线性课程 | 直播 + 录播 + 社区 + 资源 |
| **目标用户** | AI 工程师 / 开发者 | 全民 AI 素养（C 端 + 企业 + 教育 + 政府）|
| **企业 IT 部署** | 较弱 | 较强（Workspace Agents 课）|
| **MCP / Tool calling** | 强（独立 2 门课）| 中（融入开发者方向）|
| **Skills 体系** | ✅ 独立课程 | ✅ 独立资源页 |
| **行业垂直** | 偏弱 | 强（教育 / 政府 / 医疗 / 中小企业各有专题）|

## 该走哪条？两个目标两条路

**目标 1：拿一份能写进简历 / LinkedIn 的 AI 认证 → 先走 Anthropic**

13 门结构化课程 → 一张 $99 工程师认证证书，准备过程零成本。

**目标 2：我团队 / 公司怎么用好 ChatGPT → 先走 OpenAI Academy**

更强的企业 IT 视角 + 行业专题资源库，适合做内部培训和团队赋能。

**两边都免费，时间够的话两个都过一遍最好。**

---

## 我的学习节奏建议

1. **先选目标再选路径**：不要两条同时开搞，3 个月内只攻一条
2. **Anthropic 优先级**：Claude 101 → Building Apps with API → MCP（双课）→ Claude Code → Skills
3. **OpenAI 优先级**：ChatGPT 101/102 → Prompting 三件套 → 按你岗位选 ChatGPT for Any Role 对应章节
4. **认证不是终点**：考过 Claude Certified Architect 后，立刻找一个真实项目落地（个人产品 / 公司内部 tool 都行）
5. **2026 年中前**：盯紧 OpenAI 的认证发布，第一波考通常折扣 + 含金量都最优

> **两套官方课加起来 25+ 门课、几百小时内容，覆盖从「不会用 AI」到「能写进简历的 AI 工程师」全程。任何收钱超过 $200 的中文 AI 报班，本质都是在卖「免费课的中文翻版 + 一点社群陪伴」。**
