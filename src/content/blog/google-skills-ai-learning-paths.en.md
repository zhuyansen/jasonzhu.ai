Google has **completely rebranded** its veteran learning platform — **Cloud Skills Boost is now Google Skills**.

The name change is just the surface. What's really interesting is the **direction**: Google has turned AI learning into a game — think dungeon runs.

- Each learning path = one dungeon
- Each dungeon has 5 to 8 activities (stages)
- Clear the dungeon, earn a **Skill Badge** you can add directly to LinkedIn

This design transforms "learning" into "grinding for achievements," which is great news for chronic procrastinators. Here are the 3 paths beginners should start with.

**Main site**: [skills.google](https://www.skills.google/)

---

## Path 1 · Introduction to Generative AI (Start Here)

🔗 [skills.google/paths/118](https://www.skills.google/paths/118)

**5 activities**, updated just last week. Covers the two foundational pillars of generative AI:

- **LLM fundamentals**: how large language models work, what they can do, and where their limits are
- **Responsible AI**: principles for using AI responsibly, bias, and safety

> 💡 **Even if you've been using Gemini or ChatGPT for a year, start here** — this is the foundation for every other path, and it was just updated, so the content is current.

---

## Path 2 · Generative AI for Developers (Developer Track)

🔗 [skills.google/paths/183](https://www.skills.google/paths/183)

The advanced dungeon for developers. The standout feature: **it comes with Google Cloud credits** so you can run labs hands-on:

- Write real Gemini API calls
- Run generative AI experiments in an actual cloud environment
- No passive video-watching — you're actually writing code

This path is the direct counterpart to Anthropic's "Building Applications with the Claude API" — a must for anyone who wants to build AI-powered applications.

---

## Path 3 · Google AI Essentials (Most Beginner-Friendly · Non-Technical Roles)

🔗 [grow.google/ai-essentials](https://grow.google/ai-essentials/)

If you don't write code at all, this is the most accessible entry point. The focus is on **everyday work scenarios**:

- Using AI to generate ideas and brainstorm
- Speeding up research
- Drafting emails and organizing documents

Think of it as Google's equivalent of Anthropic's Claude 101 or OpenAI's ChatGPT 101 — the "first AI class" for non-technical roles in marketing, operations, HR, legal, and beyond.

---

## First Thing After Signing Up: Follow the Generative AI Tag

Once you've created a Google Skills account, **go subscribe to the "Generative AI" tag right away**.

Any new generative AI paths Google releases will automatically appear in your dashboard — no need to keep checking manually. It's essentially a "new dungeon available" notification system.

## FAQ

### What are Google Skills Badges actually good for?

You earn a Skill Badge for completing each learning path, and you can add it directly to LinkedIn. Visible AI credentials are increasingly valuable in the 2026 job market.

### Which path should a complete beginner start with?

If you code, start with Introduction to Generative AI (Path 118, 5 activities) and then move to the developer path. If you don't write code at all, go with Google AI Essentials, which focuses on everyday work scenarios.

### Is Google Skills free?

All learning paths are free. The developer-focused path (Generative AI for Developers) even includes complimentary Google Cloud credits so you can run Gemini API experiments in a real cloud environment.
