AWS Skill Builder has the **largest course catalog** of any major tech company — **600 free courses** out of 1,500.

But it's also the most treacherous: **search directly and paid courses flood the results**, pushing the best free content so far down you'll never find it.

**The right approach**: go to [skillbuilder.aws](https://skillbuilder.aws/), and **do this first** — set the **Price filter to Free** at the top, then **navigate by Learning Plan, not by individual course search**. Learning Plans string the courses together in the right order so you're never left guessing what comes next.

## 3 Generative AI Learning Paths (All Free)

Pick the track that matches your role.

### 1. Generative AI Learning Plan for Decision Makers (Non-Technical)

**3 courses**, aimed at managers and decision-makers. Covers two things clearly:

- What generative AI actually is
- How to scope and evaluate AI projects

Perfect for anyone who needs to explain GenAI to their boss or team. Zero code involved.

### 2. Generative AI Learning Plan for Developers

The core track for engineers. Focuses on:

- Getting started with **Amazon Bedrock**
- Model fine-tuning
- **Deploying RAG in production**

If you're building AI applications in the AWS ecosystem, this is your main path.

### 3. Building Generative AI Applications Using Amazon Bedrock

A single deep-dive course that walks you through building a Bedrock application end-to-end, covering:

- **Knowledge Bases**
- **Agents**

Think of it as the hands-on extension of Path 2. Essential if you want to actually ship something.
