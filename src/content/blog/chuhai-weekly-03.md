每周数一遍 8 家收款平台（Stripe、Gumroad、Lemon Squeezy、Polar、Creem、Dodo、Paddle，本周起加上 Waffo）上新挂出收款链接的网站，看看大家在卖什么、什么起量了、哪些需求还没人做。

## 本周数字

- 链接图本周新收录 **5,188 个卖家**，其中卖软件的 908 个，AI 产品 613 个。Waffo 本周还没有收录到新卖家。
- 看月度更稳：10 月前 25 天已收录 1.76 万个新卖家，9 月全月是 1.1 万。卖软件的比例两个月都在 18% 左右，软件里六成是 AI 产品，这两个比例都没变。
- 新一代收款平台 10 月的新卖家已经明显超过 9 月全月：Polar 519 个（9 月 263，接近翻倍），Lemon Squeezy 766 个（9 月 431），Dodo 168 个（9 月 107），Creem 77 个（9 月 44）。

> 单周数字波动很大：链接图是一批一批收录新链接的，见过每周 1,100 到 6,500 的区间。看趋势要看月度。

## 本周值得看的 5 个新产品

1. **Saddle**（saddle.to，Polar 收款）：一个 WordPress 插件，让 Claude、Codex、Cursor 通过 MCP 改线上网站：写页面、补 SEO 标题、更新插件、批量改 WooCommerce 价格。默认只读，删除和大改动要你点头，改完能一步撤销。按站点数年付，5 个站 $60/年起。
2. **Prompt Deck**（prompt-deck.arunbrahma.com，Polar 收款）：Mac 应用，把 Claude Code、Codex、Cursor 等 11 个 coding agent 存在本地的对话读到一个列表里，能搜、能看子 agent 的完整过程，还能统一编辑 CLAUDE.md、AGENTS.md 这类记忆文件。免费可用，Pro $29.99/年。
3. **RefCheckr**（refcheckr.pharmatools.ai，Lemon Squeezy 收款）：给医学写作者用，上传参考文献 PDF，逐条核对稿子里的说法有没有文献支撑，还能查英国药企推广规范（ABPI）。很窄的人群，但痛点具体，Pro £9/月。
4. **Foxtation**（foxtation.khaisa.studio，Polar 收款）：Mac 上按住右 Option 说话，半秒后打进任何应用，支持 23 种语言、一句话里混两种。免费版完全在本地跑 Whisper、开源；付费的 Pro 帮你去掉口头禅、改掉说错的地方。
5. **Rebel Audio**（rebelaudio.ai）：做播客的一站式工具，按删文字的方式剪音频，自动切片段、写节目介绍、配成别的语言，再发到 RSS、YouTube 和各播客平台。按每月导入的音视频小时数收费，免费版 1 小时，付费 $29/月起。

## 本周一个打法：给 agent 上闸门

上周的新软件在给 coding agent 做配套，这周这一类里冒出一个更窄的方向：管住 agent。本周卖软件的新卖家里，十来个产品卖的是这一件事：

- **动手前先等你点头**：agent 要删东西、改价格、批量改页面时先停下，你批准了才执行，能撤销。
- **留痕**：把 agent 的每次调用、回答和报错记下来，能搜、能导出，出事能查。
- **进门前过一遍**：数据发给大模型前先去掉个人信息；装 skill 前先扫一遍有没有危险指令；有人专门替你攻击自己的 agent，看它的工具调用和权限能被怎么滥用。

这个方向的买家很清楚：已经让 agent 碰到线上系统、真实数据的团队。它们卖的是「敢放手」，比再做一个 agent 工作台更容易讲清楚价值；风险和上周一样，agent 平台自己会把审批和日志做进去，最好绑在某个具体场景上（比如 WordPress、电商后台）。
