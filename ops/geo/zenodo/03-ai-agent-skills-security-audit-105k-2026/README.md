# Open-Source AI Agent Skills & MCP Servers Supply-Chain Security Audit Dataset (105,000+ Indexed Skills, 2026)

**Author**: Jason Zhu ([jasonzhu.ai](https://jasonzhu.ai) & [agentskillshub.top](https://agentskillshub.top))

**Full Security Audit Report**: https://jasonzhu.ai/en/blog/agent-skill-security-audit-200

## Key Findings
- Out of **105,000+** indexed open-source AI agent skills, MCP servers, and Codex skills, **97.8%** have never undergone any formal security audit.
- Across the **2,300+** skills evaluated under a 5-dimension supply-chain audit framework (credential exposure, hidden payloads, permission boundaries, maintainer identity, and traceability), **94.4%** passed as safe while **5.6%** triggered security warnings or rejections.
