出海选品周报 · 第 2 期（10.12 至 10.18）

我每周数一遍 7 家收款平台（Stripe、Gumroad、Lemon Squeezy、Polar、Creem、Dodo、Paddle）上新挂出收款链接的网站。本周看到的：

1. 链接图本周新收录 6,152 个卖家，1,069 个卖软件，596 个是 AI 产品。单周数字波动大，看月度：10 月前 18 天已有 1.24 万个新卖家，超过 9 月全月。卖软件的比例稳在 20% 左右。

2. 新一代收款平台 10 月还没过完就超过了 9 月全月：Polar 358 个，Lemon Squeezy 572 个，Dodo 111 个，Creem 55 个。

3. 值得看的新产品：
· 1VideoTool：让 Claude Code 通过 MCP 做视频，一句话出成片，买断 $29 起
· Catenary：给 coding agent 用的 IDE，一个任务一个 worktree，买断 $19
· Memora：Mac 本地录会议、本地转写，音频不上传，买断 €29
· ReceiptRadar：收据转发到邮箱，自动分好 QuickBooks 科目，$149/月
· GumLeaf：没网时用卫星短信提问拿答案，给徒步露营的人

4. 一个打法：给 coding agent 做配套。本周大约 50 个新软件直接点名 Claude Code、Codex 或 MCP，做的是多 agent 工作台、清理 agent 留下的缓存、额度追踪、给 agent 加能力的 MCP、CLAUDE.md 生成器。很多是本地优先、一次买断，$19 到 $89。风险是平台自己随时会把功能做进去。

5. 收款平台动态：Dodo 上线多订阅合并结账，新增 GCash、AlipayHK、FPS、Touch 'n Go 和印度 Apple Pay。Polar 宣布要重做成面向按用量收费和 agent 产品的计量计费底座，暂无发布日期。
