出海选品周报 · 第 7 期（11.16 至 11.22）

我每周数一遍 8 家收款平台（Stripe、Gumroad、Lemon Squeezy、Polar、Creem、Dodo、Paddle、Waffo）上新挂出收款链接的网站。本周看到的：

1. 链接图本周新收录 4,678 个卖家，981 个卖软件，659 个是 AI 产品。单周波动大，看月度：11 月 1 到 22 日对比 10 月同期，Polar 451 到 528，Dodo 142 到 191，Creem 70 到 97，Lemon Squeezy 从 689 降到 585。本周 Polar 193 个，最近四周里第一次超过 Lemon Squeezy。最近四周软件里 AI 产品占比从 59% 升到 66%。

2. 值得看的新产品：
· SkillsPicker：贴 GitHub 仓库，从 9 万个开源 SKILL.md 里挑适合你的 agent skills，完整清单 $9 买断
· Vois Studio：本机跑的 AI 配音，做有声书和播客，付费版不限生成次数，节日价 $15/月
· MergeAct：医院理赔提交前查必然被拒的问题，100 次 $40，科室 $199/月
· Columa：服务商的 AI 前台，输入网址一分钟后就能和它通话试用，$149/月起
· nable：每晚读云和 AI 账单，找出涨的地方，提 PR 等人批准，社区版免费

3. 一个打法：给 AI agent 留一个入口。5 个里有 3 个写了 agent 怎么用它：SkillsPicker 有命令行和 MCP，Vois 给 Claude Code 写了 skill，nable 直接在 Claude 或 Cursor 里跑。用户大半天待在 agent 里，能在那里调用的工具更容易被用起来，也多了一条被推荐的渠道。收费不用变，入口免费，钱照原来的方式收。要想清楚的是什么操作必须人点头。

4. 收款平台动态：
· Stripe 11 月 19 日：agent 通过 MCP 可以在你设的额度内转账、换汇、付供应商，公开预览，退款和提现默认要人批准
· Dodo 11 月 18 日：AI 助手和命令行改用 OAuth 登录，新出单页结账、自定义扣款重试、取消订阅时的折扣挽留
