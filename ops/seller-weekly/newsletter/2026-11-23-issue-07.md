# 出海选品周报 · 第 7 期（11 月 16 日至 11 月 22 日）

> 单周数字波动很大：链接图是一批一批收录新链接的，见过每周 1,100 到 6,500 的区间。看趋势要看月度。

## 本周值得看的 5 个新产品

1. **SkillsPicker**（skillspicker.com，Polar 收款）：贴一个 GitHub 仓库地址，它从 package.json、pyproject.toml、Dockerfile 这类文件读出你的技术栈，在 90,454 个开源许可的 SKILL.md 里挑出适合你的 agent skills（Claude Code、Cursor、Codex 都能用）。免费看匹配数和前 2 个，完整排序清单加安装命令 $9 一次买断。私有代码可以用它的命令行或 MCP 工具，只发标签名，不发代码。
2. **Vois Studio**（vois.so，Polar 收款）：在你自己电脑上跑的 AI 配音软件，做有声书、播客和旁白，Windows 和 Apple 芯片的 Mac 都能用。因为在本机生成，付费版不限生成次数，一章改五遍也不多花钱。免费版只能非商用，每天 10 次；Pro 平时 $49/月，节日价 $15/月或 $180/年。还给 Claude Code、Codex 写好了 skill，让 agent 调它的命令行批量出音频。
3. **MergeAct**（mergeact.nomoi.ai，Stripe 收款）：给医院收费部门用。理赔文件提交给 SEHA、Medicare 或商业保险之前，先查两次就诊日期重叠这类必然被拒的问题，拒付不用等几周后回来再返工。按次买：100 次 $40，200 次 $70，额度不过期；一个科室 $199/月不限次；整个收费部门的试点 $5,500/月，开发票。
4. **Columa**（columa.ai，Stripe 收款）：给水电维修这类服务商的 AI 前台，24 小时接电话和网站聊天，记下线索。试用很直接：输入你的网址，大约一分钟后就能和一个已经读过你网站的前台通电话，不用填卡。付款后邮件发一个授权码，贴进网站上的插件就自动装好。$149/月起，带预约和统一收件箱的 $349/月，给代理商转售的 $599/月。
5. **nable**（getnable.com，Stripe 收款）：盯云和 AI 账单的工具，读 AWS、Azure、GCP、OpenAI、Anthropic 等 20 家的账单，每晚跑一次，第二天早上告诉你哪里涨了、为什么，再给基础设施仓库提一个只改一处的 PR，人批准了才生效。`uvx nable` 一行装好，社区版免费、不限时，可以在 Claude 或 Cursor 里用；要托管、单点登录、团队看板的企业版另外谈价。

## 本周一个打法：给 AI agent 留一个入口

本周挑的 5 个里有 3 个，加上没进前 5 的一个 Mac 笔记应用，都专门写了 agent 怎么用它：SkillsPicker 有命令行和 MCP 工具，Vois Studio 给 Claude Code 和 Codex 写了 skill、让 agent 调命令行出音频，nable 直接在 Claude 或 Cursor 里跑。那个笔记应用 FowlNote（Polar 收款，一次买断 $14.99）首页写着 Claude Code 和 Codex 能通过命令行操作整个应用。

- **用户在 agent 里干活的时间越来越长**：写代码的人一天大半时间在 Claude Code 或 Cursor 里，能在那里直接调用的工具，比要切到网页去点的工具更容易被用起来。
- **获客多一条路**：skill、MCP 工具和命令行能被 agent 找到、推荐，也能被别人写进自己的工作流，相当于多了一个分发渠道。
- **收费方式不用变**：入口是免费的，钱照样按原来的方式收，SkillsPicker 买断 $9，Vois Studio 按月订阅，命令行是付费版才全开。

要注意的是边界：agent 能动手的地方，就要想清楚什么需要人点头。nable 默认只读、改动只提 PR 等人批准，Vois Studio 也写明 agent 执行命令前要用户同意。收款平台这周也在做同一件事，见下面。

## 收款平台动态

- **Stripe**：11 月 19 日宣布，接在 Stripe 上的 agent（通过 Stripe 的 MCP 服务器，用 Claude、Codex 这类工具）除了读 Treasury 数据，现在可以在你设的额度内转账、换汇、付供应商，目前是公开预览。两种接法：用某个员工的 OAuth 授权，每笔动钱的操作都要这个人确认；或者给 agent 单独发 API key，可以后台运行，退款、提现、对外转账默认要人批准，也可以设规则，比如 $50 以下的 ACH 转账自动过。Stripe 说已有 2.4 万多家企业在让 agent 读 Treasury 数据。原文：https://stripe.com/blog/give-your-agents-controlled-access-to-analyze-your-data-and-move-funds
- **Dodo Payments**：11 月 18 日的更新（v1.120.40）：AI 助手和 Dodo 命令行可以用 OAuth 登录，不用再存 API key，管理员能随时撤销；新出单页结账，联系方式、付款方式和付款按钮放在一页；订阅扣款失败可以自己设重试计划（30 天内最多 8 次）；用户取消订阅时可以弹一个折扣挽留；后台的 Dodo AI 能回答经营数据问题，也能发起退款，改动前要人确认。原文：https://dodopayments.com/blogs/newsletter-november18

几家平台的完整对比见：《独立开发者收款平台怎么选》。
