出海选品周报 · 第 3 期（10.19 至 10.25）

我每周数一遍 8 家收款平台（Stripe、Gumroad、Lemon Squeezy、Polar、Creem、Dodo、Paddle，本周加上 Waffo）上新挂出收款链接的网站。本周看到的：

1. 链接图本周新收录 5,188 个卖家，908 个卖软件，613 个是 AI 产品。单周数字波动大，看月度：10 月前 25 天已有 1.76 万个新卖家，9 月全月 1.1 万。卖软件的比例稳在 18% 左右。

2. 新一代收款平台 10 月明显超过 9 月全月：Polar 519 个（接近翻倍），Lemon Squeezy 766 个，Dodo 168 个，Creem 77 个。

3. 值得看的新产品：
· Saddle：WordPress 插件，让 Claude、Codex 通过 MCP 改线上网站，大改动要你点头，能撤销，$60/年起
· Prompt Deck：Mac 上把 11 个 coding agent 的本地对话放进一个列表，Pro $29.99/年
· RefCheckr：给医学写作者逐条核对说法有没有文献支撑，£9/月
· Foxtation：Mac 本地语音输入，23 种语言，免费开源
· Rebel Audio：删文字就能剪播客，自动切片段、配多语言，$29/月起

4. 一个打法：给 agent 上闸门。本周十来个新软件卖的是管住 agent：动手前先等你批准、记下每次调用方便查、数据进大模型前去掉个人信息、装 skill 前先扫一遍。卖的是「敢放手」，买家是已经让 agent 碰线上系统的团队。风险是平台自己会做，最好绑在具体场景上。

5. 收款平台动态：Dodo 上线手机数据小组件、内容审核 API、Ethoca 预警自动退款、从右到左语言结账页。
