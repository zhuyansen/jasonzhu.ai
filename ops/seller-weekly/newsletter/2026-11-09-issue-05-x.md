出海选品周报 · 第 5 期（11.2 至 11.8）

我每周数一遍 8 家收款平台（Stripe、Gumroad、Lemon Squeezy、Polar、Creem、Dodo、Paddle、Waffo）上新挂出收款链接的网站。本周看到的：

1. 链接图本周新收录 4,735 个卖家，833 个卖软件，584 个是 AI 产品。单周波动大，看四周：最近四周 2.25 万个新卖家，之前四周 1.42 万。卖软件的比例 18.4% 对 18.8%，没变；软件里 AI 产品从 58% 升到 63%。

2. 值得看的新产品：
· Drakar：Mac 原生窗口跑 Claude Code 和 Codex，用你自己的订阅，买断 $14.99
· Lume：一个快捷键弹出 AI 面板，自带 API key，买断 €6.99
· Gatekeep：给 Airbnb 房东按评价和社交账号筛客人，$29/月
· Levr：小企业贷款经纪人的工作台，经纪人免费，向贷方收钱
· Tempr：团队用 AI 的总闸门，管预算、密钥和 MCP 权限，Pro $49/月

3. 一个打法：用户自带 key，你卖一个买断的壳。本周 5 个里有 3 个不转卖模型额度，让用户用自己的 key 或已经在付的 Claude、ChatGPT 订阅，产品只卖界面和流程。不背 token 成本，价格就能低到一次买断几美元；页面上把「key 存本地、请求直连、源码公开」放在最显眼处。风险是壳容易被厂商或开源项目追平，要绑定一个具体场景做透。

4. 收款平台动态：
· Polar 上了 ChatGPT 官方插件和 Claude 的 MCP，开账号、配定价、接代码都能在对话里做
· Lemon Squeezy 发文说团队在做 Stripe Managed Payments，很快开放注册，目标是让老用户迁过去
